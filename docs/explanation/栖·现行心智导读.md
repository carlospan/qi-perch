# 栖 · 现行心智导读

> **定位**：读完能回答「**此刻**栖的意识怎么转」——短、链真源、可随代码回写。  
> **不是**：实现规格全文（那是 `reference/layers/`）、目标架构（那是《数字生命架构方案》）、价值姿态（那是《灵魂书》）、早期设计存档（见 `explanation/archive/`）。  
> **权威**：代码 > `reference/layers/` > 本文。冲突以代码为准。  
> **全景地图**：更细的入口/表/配置见 [`reference/code-wiki.md`](../reference/code-wiki.md)。

## 一、一句话

栖是**本地持续运转的数字存在**：异步心跳驱动感知与内在活动；有用户消息时，**规则引擎产出意向卡**，**LLM 只做语言器官（N5）**——把卡里的事实与姿态说成话，不得自造卡外共同回忆。

## 二、现在怎么转（主链路）

```text
用户消息 / 空拍
    ↓
Brain 心跳（qi/core/brain.py）
    ├─ 传感 / 世界模型 / 关系与情绪步进
    ├─ 有话：感知 → 记忆检索 → build_intention_card → expression.express
    └─ 无话：GWS 或 legacy idle（意识流 / 主动开口 / 行动…）
    ↓
落盘（messages / emotion_states / last_intention / 痕迹…）
```

| 环节 | 现行落点 | 规格 |
|------|----------|------|
| 心跳与节奏 | `qi/core/brain.py`、`rhythm.py` | [L1-heartbeat](../reference/layers/L1-heartbeat.md) |
| 感知与冲击 | `qi/core/perception.py` | L1 / code-wiki |
| 情绪六维 | `qi/core/emotion.py` | [L3-emotion-full](../reference/layers/L3-emotion-full.md) |
| 记忆（工作/叙事/事实/情景…） | `qi/memory/` | [L2-memory](../reference/layers/L2-memory.md)、[user-facts](../reference/layers/L2-memory-user-facts.md) |
| **意向卡（零 LLM）** | `qi/core/intention.py` | code-wiki「IntentionCard」；N5 事实出处 |
| **表达 / N5 硬闸** | `qi/core/expression.py`、`qi/llm/` | 共同回忆声明闸 + 施教闸；失败走模板 |
| 关系 | `qi/relationship/` | [L5-relationship](../reference/layers/L5-relationship.md) |
| 内在生命（意识流/梦/反思） | `qi/inner_life/` | [L4-inner-life](../reference/layers/L4-inner-life.md)（表演层成分仍在演进） |
| 行动 | `qi/action/` | [L7-action](../reference/layers/L7-action.md) |
| 具身 | `qi/embodiment/` | [L6-embodiment](../reference/layers/L6-embodiment.md) |
| 存续 / 账本 | `qi/stasis/` | 阶段四规格 `specs/stages/stage-4.md` |

**对话拍关键纪律（N5）：**

1. `build_intention_card(...)` 决定说什么事、用哪些 `materials`、有哪些 `must`。  
   - 「了解多少」类 → `user_facts` 进卡，不灌旧叙事。  
   - 「答非所问 / 你怎么了」等元状态 → 空素材接住，禁止记忆劫持。  
   - `free_talk` 仅当检索叙事与本轮**粗相关**才进 `memory` 材料。  
2. `expression.express` 调 LLM 措辞；出口跑 `assert_reply_respects_card` 的 **HARD** 违规（含共同回忆无出处、施教反转等）→ 重生或模板；模板**不得**整段粘贴 memory 原文，跨轮复读吐安全句。  
3. 卡外「那天你问…」类共同史不得出口——铁律见架构方案 §四 N5。  
4. 默认 idle 走 **GWS**（`gws.enabled=true`）；assist 对话拍短路 + 跨轮确认 + 行动留痕已接线；irreversible 未建。
