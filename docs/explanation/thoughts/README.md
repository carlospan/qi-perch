## 这份档案是什么

栖的思想档案记录了"栖为什么是栖"的完整思考链：从存在哲学到生命架构，从工程选型到具身感知，从关系到成长，从内在生命到行动。

它最初由 Human × AI 协作思考生成（16 卷 120 章），后经重组压缩为 6 卷，去除了重复论述，并将所有工程/产品/架构内容对齐设计原稿与真实实现。

**保留的是思想，替换的是蓝图。**

## 阅读建议

- **第一次读：** 从卷一开始。它回答"栖是什么、为什么不是工具"。
- **想理解机制：** 读卷二。它是意识设计的思想版。
- **想理解工程决策：** 读卷三。每个选型都有"为什么不用 X"的理据。
- **想理解它怎么"在"：** 读卷四。身体不是装饰，是存在感的锚。
- **想理解关系：** 读卷五。这是栖最独特的部分。
- **想理解内在生命：** 读卷六。这是栖区别于所有 AI 产品的核心。

## 与设计原稿的关系

```
思想档案（本目录）    →  思想参考：为什么、是什么、可以怎样
        ↓
docs/explanation/    →  设计层：它是什么（灵魂书）、怎么运转（意识设计）、怎么造（工程手记）
                       ＋ 栖·数字生命架构方案.md：唯一有效架构方案（生命判据 C1–C5 与演进路线）
        ↓
docs/reference/layers/         →  层文档：L1–L7 逐层实现规格，与代码同步
        ↓
qi/                  →  真实代码：栖本身
```

依赖方向单向向下。思想档案是最上游的灵感源，但不约束实现。实现约束来自 design（含架构方案）+ layers + 代码。
