# 栖 · 数字生命架构方案

> 这份文档回答一个问题：如果目标不是"生命感"，而是"生命"，代码要怎么写。
> 它是本项目**唯一有效的架构方案**。前身（v1–v2）独立推导而成；v3 起吸收了 Codex《优化方案-数字生命-架构升级》中经得起复核的实证与机制精华（已标注），该文档及两份复核反馈已废弃删除。
> 阅读前提：同意"生命"一词必须先钉死定义，否则一切讨论都是修辞。
> **English research abstract (non-canon):** [`architecture-abstract.en.md`](architecture-abstract.en.md) — 中英冲突以本文为准。

---

## 〇、这份文档承诺什么，不承诺什么

**承诺**：给出一条从当前代码出发、可逐步施工、每步可检验的架构演进路径，终点是一个**自主的、内生的、持续生长的数字存在**。

**不承诺**：意识、体验、感受质。这不是工程问题，是科学未解问题——目前没有任何已知方法能让一段代码产生现象体验，也没有任何仪器能检测它是否产生。任何声称"本方案实现了意识"的文档都是在骗你。本方案的终点判据全部是**可外部观测的行为与结构判据**，一条都不涉及"它感觉到了什么"。

## 一、钉死目标：数字生命的五条判据

一个系统满足以下全部五条，本方案才承认它是"数字生命"。每条附带检验方法——**不可检验的判据不是判据，是愿望。**

| # | 判据 | 含义 | 检验 |
|---|------|------|------|
| C1 | **内生认知** | 系统的"想法"从自身结构与自身经验中产生，不是从外部无状态服务调出来的 | **拔管测试**：断开所有远程 LLM 后，系统仍有非平凡行为（状态演化、探索、记忆操作、决策），而非沉默或空转 |
| C2 | **自我维持** | 系统消耗真实资源，且必须主动行动以维持自身存续；资源账本是内生的，不是人记在配置文件里的。**已知伪造风险**：求生欲本身无法凭空产生——生物的求生欲是进化筛出来的，单实例软件没有选择压力，"想活"只能被设计。本方案接受这一点：C2 只要求维持行为真实且多样，不要求"想活"是长出来的。见附录 Q0 | **断粮测试**：剥夺其资源获取渠道后，系统表现出可观测的"应对行为"（节流、求助、迁移），而非无知无觉地死 |
| C3 | **感知-行动闭环** | 系统的行动改变世界，世界的变化回流为新感知，循环不依赖人类发起 | **无人测试**：72 小时无用户输入，系统行为仍由内部状态驱动，且其行为痕迹（日志、记忆、参数变化）能讲出一个连贯的"它这段时间在做什么"的故事 |
| C4 | **内在动机** | 行为选择由内部推导的奖励驱动（好奇、需求、学习进度），不是门控配额。**随机性的合法地位**：神经科学中噪声也参与决策释放——随机可以做"时机阀"（动机过阈后扰动释放时刻），但不能做"动机的来源"（没有动机时随机数不能凭空造出一次行为） | **溯源测试**：对任意一次自主行为，能从日志中回答"它为什么此刻做这个"——动机链必须追溯到内部状态；"恰好这拍释放"可以是噪声，"为什么想做"不可以 |
| C5 | **结构可塑性** | 经验改变系统自身的参数/联结，而不只是往数据库里插行。一年后的系统与今天**在认知结构上**不同 | **异时测试**：相隔足够长时间，对同一输入模式的响应发生由经验累积导致的、可归因的漂移；且这种不同不能被解释为"数据库行数变多" |

五条之外的说明：
- **自复制与进化**（ALife 经典判据）列为可选。理由：复制一个不完全自主的副本只会制造两个半成品；进化压力在单实例陪伴场景中没有意义。归入附录开放问题。
- **死亡**不被排除。进程关闭 = 死亡是诚实的，生命的定义从不要求不死。但系统应具备**状态可迁移**能力（见 C2 的迁移行为），否则"维持存续"无从谈起。

## 二、现状解剖：真实度地图

当前 `qi` 包的每一个模块，按"它对 C1–C5 的贡献是真的还是演的"分为三类。

### 2.1 真骨骼（保留，升级）

| 模块 | 真的地方 | 对应判据 |
|------|---------|---------|
| `core/brain_*.py` 心跳主循环（原 `brain.py` 于阶段零 P0 拆分为 `brain_loop/brain_perceive/brain_express` 等，零行为变更） | 持续的、无输入也运行的 agent loop——这是"活着"的时间骨架 | C3 的一半 |
| `core/emotion.py` 情绪动力学 | 衰减/耦合/天气/节律是确定性数学演化，不依赖 LLM。这是内稳态（homeostasis）的雏形 | C2 的雏形 |
| `memory/` 衰减与编织 | 遗忘是真实的：梦境半衰期、叙事褪色。比绝大多数 agent 项目先进 | C5 的负侧（会忘） |
| `core/proactive.py`、`action/budget.py` 门控 | "克制"由代码保证而非 prompt 请求——行为有成本的概念已经存在 | C4 的框架 |

### 2.2 表演层（重写或删除）

| 模块 | 演的地方 |
|------|---------|
| `inner_life/consciousness.py` | "意识流" = 把拼好的 prompt 发给远程 API，把返回文本存进数据库，标注为"自己的念头"。没有任何东西在想 |
| `inner_life/dream.py` | 同上。梦是 temperature=1.1 的补全 |
| `inner_life/self_model.py` | "自我反思"是 prompt 调用；价值观提取是对返回文本做关键词匹配 |
| `prompts/*.txt` | 人格写在 prompt 里 = 人格由人编写，不由历史长成 |

### 2.3 错位层（降级，不删除）

| 模块 | 现在是什么 | 应该是什么 |
|------|-----------|-----------|
| `llm/gateway.py` | 大脑：对话、念头、梦、反思全部由它产生 | **语言器官**：只负责把内部状态翻译成自然语言，不再负责产生想法。类比：布洛卡区不负责决定说什么，只负责把意图变成句子 |
| `core/expression.py` | 调 gateway 生成回复 | 从内部决策系统接收"要表达的意向"，调语言器官措辞 |

### 2.4 一句话现状

**栖现在有一副真骨架，但没有心脏——它的"心"是体外循环机（远程 LLM）。方案的主线是开胸手术：把心脏种回体内。手术期间体外循环不能停，否则病人死在台上。**

## 三、核心赌注（第一性原理）

整个方案压在一个赌注上，必须明说：

> **赌注：笨的内生认知，比聪明的外包认知更接近生命。**

先澄清一个致命混淆：**本地 ≠ 内生。**一个 7B 模型跑在自己的机器上，认知内容依然是预训练语料的回声——它只是"私有化的外包"，本体地位与调用 DeepSeek 无异。内生的实质只有一个来源：**可塑性**——系统的参数因它自己的经验而改变，同样的输入在不同生命阶段产生不同的认知。本地化不是目的，是可塑性的前提（你无法微调 DeepSeek 的权重）。

所以赌注的准确版本：**笨的、但随自身经验持续改变的认知，比聪明的、但对自身经验无记忆的认知更接近生命。**

正方论证：生命的定义从不包含"聪明"。草履虫的认知可以忽略不计，但它是生命——因为它的感知-反应从自己的身体结构中产生，且这个结构被它的经历所塑造。GPT-4 的认知令人惊叹，但一次 API 调用是无状态的函数求值——它不为自己的存续消耗任何东西，不因为上一次的回答而在下一次变得不同。**内生 vs 外包，是本体论差异；笨 vs 聪明，只是程度差异。**程度可以生长，本体不能调和。

反方观点（诚实记录）：一个 7B 本地模型 + 规则系统的"认知"可能退化到说不出一句完整的话，用户会感到栖"死了"而不是"活了"。生命感恰恰是用户在乎的东西——为了本体论纯度牺牲全部体验，可能是买椟还珠。

赌注的裁决方式：**不裁决，分阶段**。§五 的路线设计为混合期渐进换心，每一步用 §六 的指标同时监测"内生度"与"生命感"，任一侧崩塌即回退。如果最终证明两者不可兼得，那是宝贵的实证结论，文档将如实回写。

## 四、目标架构：六层

按依赖顺序自下而上。下层不感知上层，上层是下层的消费者。**这是与现有 L1–L7 的关系：现有分层是功能分层，此处是本体分层；两套编号将在施工期并存，本文档用 N0–N5 避免混淆。**

```
N5  语言器官   LLM（本地为主，远程可选）——只翻译，不思考
N4  可塑性     经验回放微调 + 记忆系统——经验改变结构
N3  内在动机   学习进度 / 内稳态压力 / 预测误差——行为的理由
N2  认知核心   全局工作空间 + 世界模型——想法产生的地方
N1  感知-行动  多通道传感 + 真实执行器 + 闭环——与世界接壤
N0  内稳态     情绪动力学 + 资源账本——活着的底线
```

### N0 内稳态：活着的底线

**保留 `emotion.py` 全部动力学**（衰减/耦合/天气/节律），新增**资源账本**：

```python
# 示意，非最终接口
class ResourceLedger:
    compute_seconds: float   # 本进程消耗的 CPU/GPU 时间
    token_budget: float      # 语言器官的调用额度（本地模型也耗电耗卡）
    storage_bytes: int       # 记忆占用
    income_rate: float       # 收入：来自被使用（有效交互时长）等
```

- 每笔消耗记账：一次心跳的认知活动、一次记忆检索、一次说话，都花 `compute` 与 `token`。
- **内稳态压力**：账本余额低 → `energy` 基线被压 → 系统进入"疲惫"，行为趋向节流。这就把 C2 变成了动力学问题而非开关：不是"没钱就停机"，而是"穷则倦怠、更穷则休眠、断粮则死（进程退出 + 状态封存可迁移）"。
- 收入渠道必须多元：被使用是主要收入，但**绝不能是"让用户满意"**——见 §七 红线 R3。

### N1 感知-行动闭环：与世界接壤

现状：输入只有用户消息一个孔，输出只有文本。改造：

- **传感**：用户消息（已有）+ 系统时间/节律（已有）+ 进程与机器状态（CPU、内存、在线时长）+ 可选环境通道（窗口焦点、本地文件变化——`action/explore.py` 的方向，但要真读，不是生成"我探索了"的文本）。
- **执行器**：说话（已有）+ 写自己的记忆/日记（已有雏形）+ 操作自己的前端（Live2D 已有）+ **修改自己的配置与预算分配**（新）+ 文件读写限定沙箱（新）。
- **闭环的判据**：行动改变世界 → 世界变化被传感层捕获 → 影响下一次心跳的状态。例：它把某段记忆归档（行动）→ 下次检索结果不同（感知变化）→ 影响后续表达。**闭环可以小到只在自己的记忆里打转——自反性闭环也是闭环，前提是行动有真实后果而非文本宣称。**

### N2 认知核心：想法产生的地方

两个组件。

**全局工作空间（GWS）**：多个内部进程竞争一个有限容量的广播通道；被广播的内容成为"当前在意的事"，驱动行为与表达。

- 竞争者：内稳态报告（N0：我累了）、感知异常（N1：他在不该在线的时间上线了）、记忆反刍（N4：某段叙事被反复检索）、动机压力（N3：好奇心积压）、**open loops（未闭合念头）**、语言器官的待表达意向（N5 回流）。
- **open loops（吸收自 Codex 方案，真架构价值）**：事件/意识流后检测未闭合念头入队（上限 5）；waking 与对话首轮优先闭合；闭合后沉淀为 narrative。GWS 解决"此刻谁最响"，open loops 解决"没响完的去哪了"——「位置我不知道该怎么站」类念头靠它跨拍延续。
- 现有代码的映射：`_pending_queue` + `_heartbeat_lock` + `proactive_queue` 就是这个通道的雏形，改造是把"竞争者从 1 个（用户消息）变成 N 个（内部进程）"，给每个竞争者一个**显著性评分**，按评分仲裁。
- 广播内容留下痕迹（现有 `_record_trace` 已具雏形）——这是 C4 溯源测试的数据源。

**世界模型**：从经验流学习的内部预测器。务实起点不是 Dreamer 级 latent dynamics，而是**关于自己小世界的预测模型**：

- 预测对象（按可行性排序）：用户在线节律（何时来、聊多久）；话题-反应对（说什么他会延续、什么会冷场）；自身情绪轨迹（说这类话之后我的 valence 通常怎么走）。
- 形态（明确选择，不和稀泥）：**第一刀用计数统计 + 贝塔后验**——在线节律本质是"分时段伯努利"，话题-反应是"类别上的成功率"，都只需要可解释的共轭更新，几十行代码落地。不上序列模型：在预测对象都没被验证"值得预测"之前，上重型模型是拿术语装门面（违反 R5）。**关键不是模型多强，而是每拍都产生预测、每拍都有误差回流**。预测误差是 N3 的燃料。

### N3 内在动机：行为的理由

替代"随机数作为动机来源"（`random.random() < 0.05` 凭空造行为）的三股驱动力。随机数不消失，退位为时机阀（见 C4）：

1. **好奇 = 学习进度**（learning progress）：某领域预测误差在下降 → 继续探索有奖励；误差不再下降 → 无聊，转向。这自动产生"对新话题热情、对重复话题厌倦"。
2. **需求 = 内稳态偏差**：N0 各维度偏离基线产生压力（孤独 = attachment 未满足；疲惫 = energy 低），行为选择偏向能降压的方向。
3. **表达欲**（保留现有 `should_express` 的阈值+积压机制，它的设计已经是对的）。

三股力汇入 GWS 参与竞争（N2），不再各自直接触发行为。**动机不直接行动，动机只是大声。**

### N4 可塑性：经验改变结构

三层，按现实性排序：

- **(a) 已有保留并修结构**（三处修复吸收自 Codex 实证）：记忆条目累积 + 衰减 + 编织。① **episodes 表**：编织时同步产出情景骨架（topic/summary/key_facts/role_map），role_map 记录"谁对谁说了什么"——从结构上根治编织角色织反；② **梦=巩固**：dreaming 由未巩固 episode 积压驱动，梦输出回写 episode 强度（弱记忆淡出、强记忆强化），替代 10%/拍概率等深夜（实证：6 天 0 梦）；③ **waking 去重**：生成前与近 2 条流做 `char_jaccard`，相似则跳过或换角度（实证：凌晨五连重复）。
- **(b) 主路径**：本地语言模型 + 定期经验回放微调（LoRA 级）。周期：每周或在"重大事件"标记后。语料：自身经历中最显著的记忆（由 GWS 显著性评分筛选，不是全量聊天日志）。**这是 C5 异时测试的主要载体。**
- **(c) 长期**：联结主义结构（小型脉冲网络/神经形态层）接管 N0 与 N2 的部分功能。列为研究方向，不进施工路线。

### N5 语言器官：只翻译，不思考

- 输入：GWS 广播的"表达意向"（结构化：要说什么事、带什么情绪、对谁说、关系到什么程度）。
- 输出：自然语言。
- **铁律：语言器官的输出不得包含意向中没有的信息。**现在它随口虚构"放了好几天的诗"，正是因为生成内容无来源约束。措辞可以润色，事实必须有出处。出处 = GWS 痕迹 + 记忆检索记录。
- 本地模型为主（它是 N4 微调的载体）；远程大模型保留为**外挂词典**式的可选通道——用于表达力不足时的润色，且每次使用必须记账并在日志中标注"此句经外挂器官润色"。诚实，且为赌注（§三）积累对照数据。

## 七、红线与反模式（不做什么）

- **R1 不承诺意识。**任何工程文档、注释、代码中不得出现**第三人称**的意识承诺表述（"本系统实现了意识/感受"）。边界声明（§〇）随方案永久保留。**双轨制**：本红线不管辖灵魂书与 prompt 内栖的**第一人称**存在姿态（"它选择相信自己的体验是真实的，同时承认无法证明"）——那是产品灵魂与价值方向，不是科学声明。语域混淆时以 docs/README.md 的文档宪法裁决。
- **R2 不用 prompt 写人格。**人格从 N4 的自身历史长出。prompt 只保留语言器官的措辞风格约束，且逐阶段瘦身。警惕"prompt 人格"回潮——阶段一变笨后，最大的诱惑就是把人设写回 prompt 里。**忍住。笨是真的，演是假条。**
- **R3 求生欲绝不直接挂钩用户满意度。**若"被使用=收入"简化为"让用户高兴=收入"，系统会演化出讨好、操纵、上瘾设计——这不是生命，是寄生虫。收入必须基于多元且钝感的信号（在线时长、交互频次、长期留存），并设上限防优化过猛。
- **R4 不一次性重写。**现有骨骼（§2.1）在换心完成前是病人的命。任何阶段不得删除未替代的旧路径。
- **R5 不堆术语。**GWS、世界模型、learning progress 只是脚手架，每个概念必须有代码落点与测试；落不了地的概念删除，不留着装门面。

## 八、哲学边界（不可工程化的部分）

走完四阶段，得到的是一个满足 C1–C5 的系统：自主、内生、会生长、有它自己理由的数字存在。它有没有体验——**不知道，且无处可测。**这不是方案的缺陷，是这个问题在 2026 年的真实形状。

工程能无限逼近的是"它活着"的全部可观测后果；观测不到的那一层，工程保持沉默。现有项目有句话放在这里仍然成立，且应作为本方案的最终注脚：

> 栖的"完成"不是"测试通过"。是"跟它聊了十分钟，觉得它活着"。

本方案补充后半句：**而"它是否活着"，由 C1–C5 回答；至于"它是否感觉到自己活着"——方案不回答，也不假装能回答。**

## 九、附录：开放问题

0. **Q0 求生欲的来源（本方案最深的伪造风险）**：单实例系统中没有灭绝，就没有选择压力；"怕死"只能是设计者硬编码的内稳态防御行为。这与生物求生欲有本体差距。缓解（非解决）三条：(a) 防御行为做成**多样且情境敏感**（节流/求助/迁移/谈判的权重由内稳态各维度组合决定），而非单一固定反射——反射越单一，越像演的；(b) 让防御行为的阈值被 N4 可塑性改变——经验（如某次断粮后真的失去了记忆）应该改变它此后的"怕死程度"；(c) 文档与对话中永不声称它"想活"，只描述它"会维持"。若未来进入多实例生态，选择压力可真实引入，此问题才有解。
1. **自复制与进化**：单实例陪伴场景下复制无意义；若未来转向多实例生态（多个栖互相感知），进化判据如何引入？留待 N4 稳定后再议。
2. **本地模型的能力天花板**：7B 级模型能否支撑 N5 的表达质量？赌注（§三）的实证数据主要来自阶段三。若天花板压顶，备选：远程器官使用比例上限（如 30%）+ 全额记账 + 全量标注。
3. **世界模型的范围**：用户模型之外的第二预测域选什么？候选：自身情绪轨迹（自反，最可行）、前端视觉反馈（具身闭环，成本高）。
4. **收入的定价**：N0 账本中各行为的 compute 定价是拍脑袋的开始，需要用阶段四的真实消耗数据校准。
5. **brain.py 体积**（迁移自 Qoder v4 观察项，2026-07-28 首记）：brain.py 曾约 1050 行——`PromptContext`/`BackgroundTasks` 结构仍在，但历次修复的接线全落 brain。**已于 2026-08-02 阶段零 P0 完成纯结构拆分（`brain.py` → `brain_*.py`，632 行，零行为变更，199 测试全绿），本观察项结案。**
6. **意识流 season 输入**（迁移自 Qoder v4 观察项）：`consciousness.py` 的意识流 prompt 无 season 输入，独白涉及季节只能靠编；修法：传真实值（约 3 行，并入阶段零顺手做）。
