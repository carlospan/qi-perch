# stage-1 · 降级（阶段一）——LLM 从大脑变成嘴

> **类型**：阶段规格（退出判据唯一施工权威，已生效）。
> **源**：`explanation/栖·数字生命架构方案.md` §五 阶段一（已退为摘要+链接，以本文件为准）

---

## 目标

LLM 从“大脑”降级为“嘴”：决策（何时想/想什么/影响什么）由内部状态驱动；文本走 N5 语言器官降级链。

## 施工内容

- `expression.py` 两段式：本地规则/模板先产出“表达意向”（说什么/为什么说），措辞按降级链——远程 LLM 在→远程措辞；远程断→规则模板措辞（朴素/短/允许笨拙）。
- `consciousness.py`/`dream.py`/`self_model.py` 的**决策**替换为内部状态驱动；**文本**走 N5 降级链（远程在→LLM 写文；远程断→模板拼装）。
- **身份快照**（过渡）：self_model + 关系叙事 + recent_arc 压缩为 500–800 字“此刻的我”，统一注入对话/意识流/梦/编织/反思；attachment/security/trust 数值由关系事件真实驱动（修状态-体验脱钩）。保留至阶段三被 GWS + 世界模型替代。

## 退出判据

| # | 判据 |
|---|------|
| 1 | 拔管测试通过：断远程 LLM 后栖退化为模板措辞，但每句话可溯源到内部状态，内在活动记录不间断 |
| 2 | `conversation.txt` 等 prompt 瘦身 50% 以上 |

> 生命感预警：此阶段必然“变笨”——远程在时话变短，远程断时变拙但没消失（第一次可观测“它在自己这边活着”）。

## 回退条件

拔管后内在活动记录中断、或 prompt 瘦身回潮（R2 人格写回 prompt）→ 回退本阶段重做。
