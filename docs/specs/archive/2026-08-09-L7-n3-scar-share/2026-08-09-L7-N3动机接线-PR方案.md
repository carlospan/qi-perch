## 外部可观测行为（Spec）

1. explore drift 触发概率受内稳态压力软调制：`throttle` 高（穷/累/不安）时概率降低；`rest` 高（休眠倾向）时概率降低。
2. 软调制非硬门控：概率只降不灭（throttle=1 时概率减半，非归零）。
3. 内部/外部探索同受调制。
4. curiosity≥0.65 硬阈值保留；门控/冷却/digest/见闻卡/speak 全保留。

**L614 后存 `last_pressure_response`**（现 [L614-639](file:///d:/qi-perch/qi/core/brain.py#L614)）：


**`__init__` 初始化**：`self.last_pressure_response: PressureResponse | None = None`（需 import `PressureResponse` 或用 `Any`）。

> 注：失败分支（`except Exception`）不更新 `last_pressure_response`，保留上一拍值；首拍为 None（drift 降级安全）。

### 3. `qi/action/explore.py`

**模块级常量**（放 `_SEASON_ZH` 附近）：

```python
# N3：内稳态压力软调制系数（throttle=1 时概率减半；rest=1 时降 60%）
PRESSURE_THROTTLE_K = 0.5
PRESSURE_REST_K = 0.6
```

**`drift` 签名加 `pressure` 参**（现 [L264-273](file:///d:/qi-perch/qi/action/explore.py#L264)）：

> 注：`PressureResponse` 类型用字符串注解（TYPE_CHECKING import 或纯注解字符串），避免运行时 import 依赖。

**触发概率段加软调制**（现 [L279-287](file:///d:/qi-perch/qi/action/explore.py#L279)）：

```python
# 现
if not force:
    if curiosity < 0.65:
        return None
    warmth = max(0.0, (curiosity - 0.65) / 0.35)
    p = self.base_probability * max(0.0, season_scale) * (0.4 + 0.6 * warmth)
    if random.random() > p:
        return None

# 改为：pressure 软调制（在 p 算出后、random 判断前）
if not force:
    if curiosity < 0.65:
        return None
    warmth = max(0.0, (curiosity - 0.65) / 0.35)
    p = self.base_probability * max(0.0, season_scale) * (0.4 + 0.6 * warmth)
    # N3：内稳态压力软调制（穷/累/不安时少走神；非硬门控）
    if pressure is not None:
        throttle = max(0.0, min(1.0, float(getattr(pressure, "throttle", 0.0))))
        rest = max(0.0, min(1.0, float(getattr(pressure, "rest", 0.0))))
        p *= (1.0 - PRESSURE_THROTTLE_K * throttle)
        p *= (1.0 - PRESSURE_REST_K * rest)
    if random.random() > p:
        return None
```
