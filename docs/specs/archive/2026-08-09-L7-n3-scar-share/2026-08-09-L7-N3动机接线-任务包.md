## Spec（外部可观测行为）

1. explore drift 触发概率受内稳态压力软调制：`throttle` 高（穷/累/不安）时，走神概率降低；`throttle` 低位时维持现状。
2. **软调制非硬门控**：压力只降低概率，不完全压死 contemplative drift（「累的时候少走神」，不是「累就不走神」）。
3. 内部/外部探索同受调制（都是 drift 飘出后的子分支）。
4. `rest` 高位（休眠倾向）同样软降概率（累到想睡，更不走神）。
5. **不改变**：curiosity≥0.65 硬阈值保留（动机来源仍是好奇，压力只调制时机）；门控 / 冷却 / digest / 见闻卡 / speak 全保留。

## 实现步骤概要

1. `brain.py` L614 后存 `self.last_pressure_response = resp`（初始化 `None`，失败分支不动）。
2. `layer.py` `ActionLayer.tick` 在调 `explore.drift` 前读 `getattr(brain, "last_pressure_response", None)`，作为 `pressure` 参传入。
3. `explore.py` `drift` 签名加 `pressure: PressureResponse | None = None`；触发概率段加：
   ```python
   if pressure is not None:
       p *= (1.0 - PRESSURE_THROTTLE_K * max(0.0, min(1.0, pressure.throttle)))
       p *= (1.0 - PRESSURE_REST_K * max(0.0, min(1.0, pressure.rest)))
   ```
   常量 `PRESSURE_THROTTLE_K = 0.5`（throttle=1 时概率降一半）、`PRESSURE_REST_K = 0.6`（rest=1 时概率降 60%，累到想睡更少走神）。
4. `volition.py` explore 候选 priority 同样软调制（`pri *= (1 - 0.3 * throttle)`，比 drift 弱，避免候选被压太狠）。
5. 测试：`test_explore_pressure_modulates_probability`（构造 `pressure.throttle=1.0`，断言 drift 触发次数显著低于 `pressure=None`）；`test_explore_pressure_none_unchanged`（pressure=None 时概率与 d-3-2 一致）。
