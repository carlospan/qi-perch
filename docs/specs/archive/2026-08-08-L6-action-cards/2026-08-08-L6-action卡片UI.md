## Spec（外部行为）

栖 share 递出创作时，桌面端「谈」区能看见一张可触的卡片（创作正文 + 类型标 + 季节），紧随栖那句「我今天写了个东西……给你。」之后出现——而不是把作品正文塞进同一条语音文本里（现行 workaround）。

1. 栖在合适时机递出创作 → 谈区出现：栖的说话气泡（qi_line）+ 紧接其下的创作卡片。
2. 卡片承载创作正文（保留换行）；qi_line 只作引入，不再内联正文。
3. 卡片为会话内可见、不打扰（不弹窗 / 不闪烁）；重连后 qi_line 仍持久（`/history`），卡片本身为本次会话瞬时（创作本体仍在 L4 creations / actions 留痕，未丢）。
4. tend / explore 的 `action` 推送仍照常到达前端，但本包不在谈区渲染它们（向内动作，保持安静；留待后续「轻提示」另立包）。
