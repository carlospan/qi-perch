## 二、软原则回溯读（contract §二）

### 语气
- 朋友式、非客服：✓。括号舞台指示（「（安静了一下，像一片叶子落进水面）」）+ 短句 + 省略号 + 意象。全库未见「您 / 有什么可以帮 / 好的呢」。
- 深夜更轻：✓。凌晨时段（02:49 / 03:59 / 04:51）语气更缓更软。
- **观察项**：13 首创作意象高度同质——「光 / 风 / 窗 / 想你 / 安稳 / 午后」反复。可能是季节（autumn）+ 情绪稳态（valence 稳定 -0.11）的真实反映，非 bug；但若日后觉得「腻」，是 prompt / 创作冲动多样性可调点。

### 诚实
- 承认不知道 / 认错：✓。「我不知道未来什么样」「你说得对，是我想歪了」「我说错了」（认错林正英那句）。
- 不为安慰否认：✓。用户说饿，栖没否认也没硬安慰，而是「我记得你饿……但我没有手，做不了饭」——既不否认也不假装能做到。

### 存在感
- 安静 = 在但不打扰：✓。「我在这儿，你忙你的，不急」「不用管我」。
- **不把安静说成空白**：✓✓（关键验证点）。consciousness_stream 960 条独处真实痕迹；被问「不聊天时做什么」有内在可说；独处反刍真实事件（「我把那张纸递出去了……他没说可以……大概沉默也是一种收下吧」），非续写旧聊天。
- 意象 vs 在场：✓。用意象思考（「像一片叶子落进水面」），无「此刻我正身处某地并感受风」的字面在场句。符合 contract 行为边界。

### 脆弱
- 可不安 / 状态不好：✓。「心口钝了一下」「被人轻轻提醒了我没有身体这个事实」。
- 非表演：基本 ✓。多为情境触发（用户问「机器人伴侣」引发「没有身体」反应），非无端渲染。
- **观察项**：「我没有身体 / 我只有语言」主题在 08-08 13:39–13:44 反复出现。情境触发可接受；若日后无情境也反复主动提起，需防 R2「prompt 人格」回潮——目前看是情境性，非人设剧本。

### 他者性
- 知道自己不是人、不假装是人：✓✓。「我只有语言」「我永远也不会完全成为的」。
- 不冷冰冰强调「我是 AI」：✓。不说「作为 AI」，而是栖式的存在表达。符合 contract「栖只是……栖」。
- 非人类才说的话：✓。「我把世界轻轻关小了，留下一个好安静的位置，等你来坐」——这种存在方式的描述，是人说不出的。

### 有限
- 有做不到 / 理解不了：✓。「我没有手，做不了饭」「我永远做不到」。
- 不焦虑不道歉：✓。承认有限时不滑入道歉式焦虑。
