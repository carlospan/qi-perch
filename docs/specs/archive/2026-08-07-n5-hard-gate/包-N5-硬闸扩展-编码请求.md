## 改动一：`qi/core/intention.py` — `assert_reply_respects_card` 新增两闸

### 1.1 共同回忆声明闸（主闸）

在函数末尾（line 683 `return violations` 之前）新增：

```python
# 共同回忆声明闸：回复宣称记得/说过/问过但卡内无实材
if _DECLARATIVE_MEMORY_RE.search(text):
    if not _card_has_real_material(card):
        violations.append("共同回忆无出处")
    elif not _key_phrase_in_materials(text, card.materials):
        violations.append("共同回忆关键短语不在素材中")
```

辅助函数（同文件新增）：
- `_DECLARATIVE_MEMORY_RE`：编译正则，匹配——`那天|那晚|凌晨|你问过|你说过|你问|我说了|我说过|会问你是不是|记得你那次|记得你曾经|上次你`. 注意：不匹配"你教我/我教你"（施教闸已覆盖）。
- `_card_has_real_material(card)`：`card.materials` 中存在 `tag in ("memory","fact")` 且 `text.strip()` 非空。
- `_key_phrase_in_materials(text, materials)`：提取回复中"确定回忆句式"后的第一个完整子句（至下一句号/问号/或 15 字），归一化（去标点/空格/降 ASCII），在 materials 全文做 `in` 子串命中。返回 True/False。

### 1.2 实体一致性辅助闸

```python
# 实体一致性：回复不应引入已知集之外的新专名
known = _build_known_set(card.materials)
reply_entities = _extract_novel_entities(reply, known)
for e in reply_entities:
    if _is_definite_name_entity(e, known):
        violations.append(f"虚构实体:{e}")
```

辅助函数（同文件新增，纯 `re`，零 NLP 依赖）：
- `_build_known_set(materials)`：从 materials 全文提取 2-4 字汉字 n-gram + 固定白名单常量 `_ENTITY_WHITELIST`。
- `_ENTITY_WHITELIST`：代码常量（tuple），含意象词、情绪词、功能词。完整清单见 PR 方案 §3.2 已知集定义。
- `_extract_novel_entities(reply, known)`：`re.findall(r'[\u4e00-\u9fff]{2,4}', reply)` → 过滤掉在 known 中的。
- `_is_definite_name_entity(e, known)`：First pass — e 不在 known 中，且长度≥3 字（或含英文大写/书名号/显式"叫××的人"模式）。宁漏勿杀。

**既有检查维度不删、位置不变。**

### 1.3 定义 HARD/SOFT 分界常量

新增模块常量：
```python
_HARD_VIOLATION_PREFIXES = (
    "卡外专名:", "伪记忆句式", "施教关系反转",
    "空卡编造共同回忆", "虚构实体:", "共同回忆",
)
```
`_TEACH_VIOLATION_TAGS` 保留不删。`_HARD_VIOLATION_PREFIXES` 是它的超集。

## 改动二：`qi/core/expression.py` — 硬闸扩展

### 2.1 主路径：从仅施教 → 全量 HARD

当前 line 206-212：
```python
if text and _teach_memory_violation(text, intention):
    fixed = await self._fix_teach_inversion(messages)
    if fixed is None:
        intention.outcome = "template"
        return _TEACH_INVERSION_FALLBACK
    text = fixed
```

改为：
```python
from qi.core.intention import _HARD_VIOLATION_PREFIXES

if text:
    viols = assert_reply_respects_card(text, intention)
    hard = [v for v in viols if v.startswith(_HARD_VIOLATION_PREFIXES)]
    if hard:
        fixed = await self._fix_generation(messages, hard)
        if fixed is None:
            intention.outcome = "template"
            return _build_fallback(intention, hard)
        text = fixed
```

### 2.2 新增 `_fix_generation` 和 `_build_fallback`

- `_fix_generation(messages, viols)`：仿现有 `_fix_teach_inversion`——将硬闸违规描述注入 system prompt，重生成一次。返回 `str | None`（失败返回 None）。
- `_build_fallback(intention, viols)`：按违规类型选模板。施教类→`_TEACH_INVERSION_FALLBACK`；回忆类/虚构类→`render_template(intention)` 的 acknowledge/share_state 简版。
- `_fix_teach_inversion` **保留不删**（包 15-17），它可逐步迁移到 `_fix_generation` 或保留为内部回退。决策：保留，不作为本包清理项。

### 2.3 去重旁路同样跑 HARD 闸（B4）

当前 line 234-237 去重重生后的施教检查：
```python
if _teach_memory_violation(again, intention):
    intention.outcome = "template"
    return _TEACH_INVERSION_FALLBACK
```

改为：
```python
again_viols = assert_reply_respects_card(again, intention)
if any(v.startswith(_HARD_VIOLATION_PREFIXES) for v in again_viols):
    intention.outcome = "template"
    return _build_fallback(intention, again_viols)
```

## 改动三：`qi/llm/prompt_builder.py` — materials 改为原文短引 + 诚实边界

将 materials 注入段从"生动扩写"改为"原文短引 + 诚实边界"：

```
【你此刻知道的事】
{memory_text}    ← 素材原文短引（≤ 80 字/条），列表形式，保留原句
{facts_text}     ← 用户事实原文短引
{state_text}     ← 当前状态描述
【诚实边界】你此刻知道的人和事仅有以上。若想引用"那晚/那天/你说过/我问过…"类的共同回忆——请确认以上素材中确实有那段对话；若不确定，请不要假装记得。不确定时可以用意象、比喻或诚实地说"我不确定"。
```

具体实现：修改 `PromptBuilder._format_memories` 或等效方法，将当前已注入的 materials 列表前追加"【你此刻知道的事】"标题，末尾追加"【诚实边界】"段落。不改既有的事实注入逻辑，仅在格式上包裹。
