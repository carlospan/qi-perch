## Spec（外部行为）

1. 系统每拍维护一个「用户在线节律」预测模型：按 `(weekday, hour)` 桶统计用户在线/缺席，输出当前桶的在线概率与预测误差（surprise）。
2. surprise 作为可观测信号注入每拍 `broadcast_traces.motive_json.world_surprise`，使溯源测试能回答「这拍的好奇/探索是否来自世界模型意外」。
3. **包 9 只增信号、不接 GWS 竞争者、不改 proactive/explore 权重**（权重生效与竞争者接入归包 10）。
4. 节律后验持久化（进程重启不丢），纯标准库、零新依赖、不引第三方。

## 实现（交给 Cursor 的步骤）

### 1. 新增 `qi/world/online_rhythm.py` —— `OnlineRhythm`

- 桶 key：`(now.weekday(), now.hour)`。
- 后验存储：**直接复用 `body_memory` 表**，key = `"world.online_rhythm"`，value = `{ "buckets": { "wH": {"s": success, "f": fail}, ... } }`。无需新建表，零 schema 改动。
- 方法：
  - `async def record(self, db, *, online: bool, now)`：取当前桶，success/fail +1，写回 `set_body_memory`。
  - `def predict(self, now) -> float`：读桶计数，`P = (α+s)/(α+β+n)`，α=β=1（拉普拉斯平滑），无计数返回 0.5。
  - `def surprise(self, online: bool, now) -> float`：基于 `predict` 的对数预测误差，例如 `surprise = -log(P)` 若 online 否则 `-log(1-P)`，夹到合理范围。
  - `def snapshot(self, now) -> dict`：返回 `{"predicted_online": P, "surprise": s, "bucket": "wH"}` 供注入。
- 加载：构造时从 `set_body_memory` 读 `"world.online_rhythm"`（无则空 dict）；所有写都经 `db.set_body_memory`。

### 2. 新增 `qi/world/model.py` —— `WorldModel`

- 聚合多域（包 9 仅在线节律；包 9b 情绪轨迹后续挂入，预留 `self.domains`）。
- `def __init__(self)`：`self.online = OnlineRhythm()`。
- `async def update(self, brain, *, now)`：调 `self.online.record(brain._db, online=brain.user_online, now=now)`。
- `def snapshot(self, *, now) -> dict`：返回 `{"online_rhythm": self.online.snapshot(now)}`。

### 3. `qi/core/brain.py` 接入

- `__init__`：建 `self.world = WorldModel()`；`self.last_world = None`（类比 `self.last_sensing`）。
- `_heartbeat`（开头，传感采集之后、`determine_mode` 之前或之后均可）：加
  ```python
  try:
      await self.world.update(self, now=now)
      self.last_world = self.world.snapshot(now=now)
  except Exception:
      logger.debug("世界模型更新失败", exc_info=True)
      self.last_world = None
  ```
- 注意 `user_online` 在 `_heartbeat` 内已被 `determine_mode` 使用，节律记录用同一个 `self.user_online` 即可（在线=有对话/桌面在线信号）。

### 4. `qi/core/trace.py` `motive_snapshot` 注入

- 在 `snap` 字典里加：
  ```python
  world = getattr(brain, "last_world", None)
  if world is not None:
      snap["world_surprise"] = round(float(world.get("online_rhythm", {}).get("surprise", 0.0)), 4)
  ```
- `persist_broadcast` 调用 `motive_snapshot(brain, ...)` 无需改签名，自动带上。

### 5. 纪律红线（Cursor 必须遵守）

- **不**改 `proactive.py` / `gws.py` / `explore.py` 的任何触发逻辑（权重改动归包 10）。
- **不**新增 pip 依赖；贝塔后验手算（`math` 即可，其实只用四则）。
- fake-provider 全失败时 `world.update` 仍应推进（不依赖 LLM）——因只读写 `body_memory`，天然满足。
