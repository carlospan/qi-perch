## 逐条回应 5 个检验问题

### 1. 世界模型首域：两域并行，还是先只做在线节律？

**倾向：首域只做「用户在线节律」；自身情绪轨迹同阶段可并行，但不要塞进包 9 同一 PR。**

| 依据 | 说明 |
|------|------|
| stage-3 / §五 施工文案 | 明文「先做用户在线节律」 |
| §N2 可行性排序 | 在线节律 → 话题-反应 → 自身情绪轨迹 |
| §九 Q3 | 「自身情绪轨迹」是**第二预测域**候选里最可行者，不是否定首域 |

同意任务包「两域都进 WorldModel、不锁死单一域」的**阶段愿景**；不同意把第二域写进包 9 的必交文件与验收，以免一包膨胀、拖延 N3 燃料落地。建议任务包改为：

- **包 9（必做）**：在线节律 + surprise → WorldState / `motive_json.world_surprise`（只增信号）。  
- **包 9b 或观察项（可选并行）**：自身情绪轨迹；进度滞后不卡阶段三退出（你们已有此句，保留）。

另：包 9「高 surprise 抬升 proactive/explore 权重」与同包「不改既有 proactive 触发、等包 10」略打架——请改成：**包 9 只写旁路字段与痕迹；权重/竞争者生效放包 10。**

### 2. 经验回放训练默认不跑：是否符合「本地不常驻」？语料是否应更保守？

**倾向：训练默认隔离 ✅；语料生成不应更保守，应作为本阶段 C5 的主交付。**

与 `progress.md` / stage-3「本地模型不本机常驻、主线不阻塞」一致。CI/心跳不调 `run_training()`、可选依赖不进主 `pyproject`——同意。

语料生成 + 显著性筛选 + 版本化 + 异时快照地基，是**不占显存**的结构可塑性工程入口；再砍会让包 11 空心、判据 #1 完全无抓手。保守边界画在「真训」，不是「不产语料」。

### 3. 动机替换完整性：包 10 审计是否覆盖阶段二遗留随机动机？

**倾向：方向对，文件清单不完整——有漏。**

`qi/` 内 `import random` 抽查结论（摘要）：

| 模块 | 角色 | 包 10 是否点名 |
|------|------|----------------|
| `action/explore.py` | WHETHER 探索 | ✅ 已列 |
| `core/proactive.py` | 无 random（阈值门槛） | ✅ 已列（接 curiosity） |
| `core/brain.py` | 投递 sleep 抖动 | 时机阀，可保留 |
| `action/share.py` | 话术 choice | 表达层，可保留 |
| **`inner_life/dream.py`** | **是否做梦 30%、是否提梦 12%、加权抽 episode** | ❌ **漏** |
| **`inner_life/creativity.py`** | **是否创作 / 是否提创作** | ❌ **漏** |
| **`inner_life/consciousness.py`** | loop_backlog 时机阀（可留）；**meta 纯随机 WHETHER** | ❌ **漏 meta** |
| **`action/layer.py`** | tick 对 top intent 再掷骰 WHETHER | ❌ **漏** |
| waking / silence / self_ops / volition / gws | 基本确定论 | 无需当随机动机源改 |

**Waking 不是随机门控**（重启 + 实质消息 → 事件触发），交叉请求里的「如 waking/dream」——**dream 要改，waking 不用当动机源重做。**

请把包 10【文件】扩成至少含：`dream.py`、`creativity.py`、`consciousness.py`（meta）、`action/layer.py`；验收增加「审计表：动机源 / 时机阀 / 表达层」三栏，禁止只扫 explore/proactive。

explore 现为 **volition → layer.tick → drift** 多层 WHETHER，替换时注意别叠三条随机。

### 4. 退出判据 #1 可测性：训练默认不跑时靠什么触发？

**倾向：语料版本对比可作地基验收，不能单独冒充「异时漂移通过」。**

架构 N4-b / C5：异时测试的主载体是**参数因经验改变**（LoRA 级微调），不是「多写了几版 jsonl」。

建议任务包写死两层，避免验收时和稀泥：

| 层级 | 含义 | 谁验收 |
|------|------|--------|
| **#1-地基（包 11 必过）** | 显著性语料可版本化、两次快照可 diff、`run_training()` 可显式调用且默认不进心跳 | CI + 文档 |
| **#1-真通过（阶段三硬退出）** | 维护者**显式触发至少一次**训练（或等价参数固化）后，同类输入响应出现可归因漂移 | 维护者异时测试 |

若硬件长期无法真训：维护者应仿阶段二路 B，把 **#1-真通过降级为观察项**，并回写 `stage-3.md`——**此降级须 HITL 拍板，CodeBuddy/Cursor 不得在任务包里静默把「语料 diff」写成判据 #1 已过。**

你们「回放语料版本对比 / 维护者显式触发」二选一——**我选：地基用前者，真通过必须后者（或正式降级）。**
