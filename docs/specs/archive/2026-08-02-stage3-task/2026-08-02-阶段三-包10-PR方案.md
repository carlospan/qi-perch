## Spec（外部行为）

1. 系统内在动机从「随机数决定何时主动」改为「learning-progress 好奇驱动」：好奇来自"某域预测误差在下降/停滞"，随机数退位为**纯时机阀**（动机过阈后扰动释放时刻）。
2. 好奇作为 GWS 竞争者 `kind="curiosity"` 入场，与 respond / proactive / action / close_loop / report 同场按 salience 竞争（沿用包 7 仲裁，用户消息 `respond` 永不被压过）。
3. 随机审计三栏表落地：动机源 → curiosity 驱动；时机阀 → 保留并注释；表达层 → 保留。
4. 每拍 `broadcast_traces.motive_json` 增 `curiosity` 字段，溯源能回答"这拍为什么好奇这个"。

## 现状盘点（编码前必读，避免重复劳动）

- `emotion.curiosity` 已存在（base 0.6；`_apply_anomaly_nudge` 在 anomaly 时 +0.05）；已喂给 `action_intentions` 与 `explore.drift` —— **好奇心字段与 explore 动机源已就位**，本包重点是把它接成 GWS 竞争者 + 改造其余随机动机源。

- `Contender(kind, salience, reason)` 不可变；`gws.arbitrate` 按 salience 取最响；`collect_contenders(brain, *, pending, want_express, kind, action_type, now)` 在 `trace.py` 收集全部竞争者。

## 实现（交给 Cursor 的步骤）

### 1. 新增 `qi/motivation/curiosity.py` —— `CuriositySignal`

learning-progress 的轻量代理（不引重依赖；不训模型）：

- `__init__(self, config=None)`：读 `config["motivation"]["curiosity"]` 可调系数（默认内置）。
- `async def update(self, brain, *, now) -> float`：计算本拍 curiosity 并写回 `brain.emotion.curiosity`（沿用现有 `emotion.curiosity` 字段，不新增存储）。信号来源：
  - **世界模型意外**（包 9 已就位）：取 `brain.last_world["online_rhythm"]["surprise"]`（无则 0）——surprise 高 = 该域预测误差未降 = 好奇升。
  - **open_loop 积压变化**：积压越多越想"想通" → 好奇升（读 `brain._load_open_loops()` 长度，失败当 0）。
  - **anomaly 累积**：复用 brain 现有 `_apply_anomaly_nudge` 已涨的 curiosity（读取即可，不重复涨）。
  - 合成：`curiosity = clamp01(base_read + w_world*surprise + w_loop*loop_norm)`，权重默认 `w_world=0.5, w_loop=0.3`；base_read 取 `brain.emotion.curiosity` 当前值（保留 anomaly 贡献）。
- `def contender(self, *, now) -> Contender`：返回 `Contender(kind="curiosity", salience=self.salience(curiosity), reason="learning-progress 好奇")`，其中 `salience` 把 curiosity 值直接作 salience（已夹 0–1）。
- 不依赖 LLM（只读写 emotion / body_memory / world 旁路），fake-provider 下仍推进。

### 2. `qi/core/trace.py` —— 竞争者入场

- `salience()` 增分支：`if kind == "curiosity": return _clamp01(float(signals.get("curiosity") or 0))`。
- `collect_contenders` 签名增 `curiosity: float = 0.0` 参数；在收集末尾追加：
  ```python
  if curiosity > 0.0:
      candidates.append(Contender(
          kind="curiosity",
          salience=salience(kind="curiosity", curiosity=curiosity),
          reason="learning-progress 好奇驱动",
      ))
  ```
- `motive_snapshot` 增 `snap["curiosity"] = round(float(getattr(brain.emotion, "curiosity", 0.0)), 4)`（溯源字段）。

### 3. `qi/core/brain.py` —— 接入

- `_gws_broadcast`（约 L611）调用 `collect_contenders` 前，先：
  ```python
  from qi.motivation.curiosity import CuriositySignal
  curiosity_sig = CuriositySignal(config=self.config)
  curiosity_val = await curiosity_sig.update(self, now=now)
  ```
  并把 `curiosity=curiosity_val` 传入 `collect_contenders(...)`。
- 注意 `collect_contenders` 调用处（L619）补 `curiosity=curiosity_val`。

### 4. 随机动机源 → curiosity 驱动（按审计表）

- `dream.py` `maybe_dream`：把 `if random.random() >= self.probability: skip` 改为「curiosity 低则不梦」——`if emotion.curiosity < DREAM_CURIOSITY_MIN: skip`（新增常量 `DREAM_CURIOSITY_MIN = 0.55`，对齐 explore 阈值风格）；保留 `pick_episode_weighted` 但**加权函数 `episode_weight` 叠加 curiosity 指向**（停滞域 = 久未 dream / 低 retention 优先，可复用现有 `importance×intensity`，本包不强行改加权，仅注释"加权抽选即 curiosity 指向的停滞域"）。`render_template_dream` 的 `shuffle`/`choice` **保留**（表达层）。
- `creativity.py` `maybe_create`：WHETHER 改为 `if emotion.curiosity < CREATION_CURIOSITY_MIN and intensity < CREATION_EMOTION_THRESHOLD: return None`（即好奇或情绪高任一满足即可触发），移除纯随机 `random.random()`；`maybe_share_hint` L178 的 `random.random() > 0.25` **保留**（提起时机阀，加注释）。
- `consciousness.py` `should_trigger_meta`：改为 `return emotion.curiosity > META_CURIOSITY_MIN`（新增常量 `META_CURIOSITY_MIN = 0.5`），移除 `random.random()`；`trigger_loop_backlog` 的 `random.random()` **保留**（C4 时机阀，加注释）。

### 5. 纪律红线（Cursor 必须遵守）

- **不**改 `respond` 恒胜逻辑（用户消息永不被压过）；`curiosity` 竞争者仅在无 pending 时参与竞争。
- **不**新增 pip 依赖；learning-progress 用轻量代理（surprise + open_loop + emotion.curiosity），不引 torch/transformers。
- **保留**所有时机阀随机（layer L207 / dream shuffle / share choice / brain sleep 抖动 / creativity 提起 0.25），仅移除"随机做动机来源"的 WHETHER。
- fake-provider 全失败：`CuriositySignal.update` 不依赖 LLM（天然满足，因只读 emotion/world 旁路）。
