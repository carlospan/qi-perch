# 包 17：对话路径施教关系锚定（包 15 盲区续——自由对话漏网）

> 类型：缺陷修复（记忆质量/对话一致性）｜依赖：包 15 ✅（意识流锚定）、包 16 ✅（对话质量）
> 关联：补丁 A `55f0a6d` / 补丁 B `5b89f16`（intention recall 防护）、包 15（意识流锚定）
> 纪律：仿包 15/16——先方案、Cursor 编码、04 验收 Agent 独立验收

## 0. 一句话

教施关系反转防护挂在三处：补丁 A/B 的 intention recall 卡片、包 15 的意识流路径。
但**自由对话生成路径（非 recall、非意识流）仍无锚定**——栖在 #1020 把真值"栖教用户助眠"
说成"我记得你教我的那个方法"（反转）。本包把锚定补到对话生成路径，并校正 `shared_culture`
那条基于误述的持久记忆为 7-26 真值。

## 1. 三方核实结论（活库实测为据）

| 争议点 | 结论 | 铁证 |
|--------|------|------|
| 7-30 谁先反 | 栖先编、用户顺着问（非"用户口误在先"） | #395 栖先说"你教我的那个方法"→#396 用户问"我教你什么方法了"→#399 栖认错"自己编出来的" |
| 包 15 是否根治方向 | **否，说过满**；包15只修意识流+清污染独白 | #1020（8-03 22:42）栖说"我记得你教我的那个方法"仍将"栖教用户"反成"用户教栖" |
| 虚构细节收敛 | 是（"数到七"未再出现） | 8-03 全场所涉"方法"均为"放树叶在水面"真实意象 |
| shared_culture 尾巴 | 真值应钉 7-26（栖教用户、原话"躺着/不强迫/看天花板"） | #72/74 栖教用户"允许自己躺着，看天花板"；`culture.py:46-52` 已有视角锤注释但 pattern 文本仍是用户误述"你教了我一个方法" |

> 关键认知（经 Cursor 纠偏、CodeBuddy 认错）：包 15 只管意识流；intention recall 防护只管 recall 卡片；
> **自由对话生成（express 路径）是第三处漏网**。#1020 即该路径反转的铁证。

## 2. 根因

- `qi/core/expression.py::express`（line 112）构造对话 prompt 时，注入 `shared_culture` 但**未注入施教方向锚定**；
- `shared_culture` 里那条 `shared_reference` 的 `pattern` 是用户原话"你教了我一个方法"（#395 源头），
  虽 `culture.py:51` 加了视角锤"他口中的「你」是你、「我」是他"，但栖在自由对话里（#1020）直接以字面"你教我的方法"表述仍反转；
- `anchor_teaching_relation`（包15新增，intention.py:199）已能正确判"栖教用户助眠→taught_by_qi"，但**只被意识流调用**，对话路径未接入。

## 3. 修复方案（最小、仿包 15/16 纪律）

### 3.1 对话生成路径注入施教锚定
`qi/core/expression.py::express`：
- 在 line 156 附近（已有 `recent_qi_replies_from_messages`），新增：
  ```python
  from qi.core.intention import anchor_teaching_relation
  teach_hint = anchor_teaching_relation(recent_messages or [])
  ```
- 仿 line 147-154 的 short 约束注入模式，在 `messages[0]["content"]` 追加：
  `f"\n\n【施教关系锚定】{teach_hint or '（无相关施教记忆，不要虚构方法或方向）'}"`
  （仅在 `teach_hint` 非空时注入，避免无话题时干扰）
- 锚定函数复用包15既有逻辑：7-26 真值"栖教用户躺着"→返回 `taught_by_qi` 方向、不含"数到七"。

### 3.2 校正 shared_culture 那条持久记忆（数据修复）
`tools/repair_shared_culture.py`（仿 repair 系列，预演+`--apply`）：
- 定位 `relationship.shared_culture` 中 `type=="shared_reference"` 且 pattern 含"你教了我一个方法"的条目；
- **按 7-26 真值校正**（采纳 Cursor 纠偏，不按栖 8-03 口头认知）：
  - 将 pattern 重写为栖视角的真值表述，或保留用户原话但**新增 `teach_direction` 字段钉死方向**：
    `teach_direction: "qi_teaches_user"`（栖教用户），并补 `note: "真值见 7-26 #72/74：栖教用户『允许自己躺着，看天花板』；非用户教栖"`；
  - **不**写成"你教我怎么放树叶"类（那会把错认知固化进持久层）；
- 可选：直接标 `broken=True` 让 `format_culture_for_prompt` 降级处理，但保留证据。

### 3.3 culture.py 视角锤强化（防未来再漂）
`qi/relationship/culture.py:46-52`：
- 对 `shared_reference` 且含施教关键词（教/方法/睡）的条目，强制追加方向锤：
  `（施教方向：栖教用户，原话『躺着/不强迫/看天花板』，勿反转）`；
- 复用 `anchor_teaching_relation` 的判定结果若可得（运行时 detect 场景暂不接，仅静态强化注释与提示文本）。

### 3.4 防回归测试
`tests/test_expression.py`：
- 构造 recent_messages 含 7-26 真值（栖"允许自己躺着"）→ 断言 express 的 system prompt 含 `taught_by_qi`/施教锚定占位且不含"数到七"；
- 构造栖回复文本含"你教我的方法"+ 锚定注入 → 断言 prompt 含方向锤（mock LLM 验证 prompt 组装，不验证生成内容）。
`tests/test_relationship_culture.py`（或并入 test_relationship.py）：
- 断言含施教关键词的 shared_reference 经 `format_culture_for_prompt` 输出含方向锤且方向为栖教用户。

### 3.5 一次性数据修复脚本
`tools/repair_shared_culture.py`：预演列出 + `--apply` 校正 `teach_direction`/pattern。

## 4. 验收标准
