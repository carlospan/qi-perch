### 1. `qi/action/assist.py` detail_json 加 `content_preview`（HITL1=a）

**现状**：成功路径 detail_json = `{"op", "target_path", "digest"}`（L100-110，assist-5 新增）。

**改为**：

```python
# 留痕内容概览长度（assist-6：供 respond 追问时有事实可依，非诗意 digest）
_CONTENT_PREVIEW_LEN = 80
```
- detail_json 加 `content_preview`（原文前 80 字，清洗换行）：
```python

```

> 说明：content_preview 是**真实原文**（非 LLM 转译），respond 复述不编造（R1）；诗意 digest 保留不动（N4 观察项）。

### 2. `qi/action/layer.py` prompt_extras 对 assist 行增强（HITL1=a）

**现状**：`prompt_extras`（L436-455）对每行只注入 `summary`。

**改为**：
- 顶部 import 加 `json`（L5 附近：`import json`）
- L443-446 循环内对 `kind == "assist"` 的行解析 detail_json，行尾追加「（刚读：{文件名}——{preview}）」：

```python
        for row in rows:
            summary = str(row.get("summary") or "").strip()
            if not summary:
                continue
            line = f"- {summary}"
            # assist-6：assist 行附「刚读的文件 + 内容概览」，追问可诚实回答
            if row.get("kind") == "assist":
                detail = row.get("detail_json")
                if detail:
                    try:
                        d = json.loads(str(detail))
                    except (json.JSONDecodeError, TypeError):
                        d = {}
                    tp = str(d.get("target_path") or "").strip()
                    preview = str(d.get("content_preview") or "").strip()
                    if tp or preview:
                        name = (
                            tp.replace("\\", "/").rsplit("/", 1)[-1]
                            if tp
                            else ""
                        )
                        note = "（刚读：" + name
                        if preview:
                            note += "——" + preview
                        note += "）"
                        line += " " + note
            lines.append(line)
```

> 降级约定：detail_json 为空 / 非法 JSON / 无 target_path 与 preview → 只显示 summary（默认分支不变）；explore/share 行不走进此分支，行为不变。

