## Spec（外部可观测行为）

1. 用户说「帮我看一下 D:/notes/today.txt」→ assist-2 提取路径 + 候选进 GWS → 胜出 → confirm_gate 开口「要我看的话，说一声我就看」+ 谈区出**确认卡片**（角标「看？」、文件名、确认/取消按钮）
2. 用户点「确认」按钮（或口头说「看吧」「看」「好」「行」「确认」）→ brain 标记 confirmed=True + 复用 pending 的 op/target_path → 下一拍 execute_kind 传 confirmed=True → 真读文件 → digest 开口
3. 用户点「取消」或说「不用」「算了」→ 清 pending + 栖开口「好。」
4. 用户换话题（新消息非确认非拒绝）→ 清 pending（放弃这次确认，走新消息流程）
5. 超时：pending 存超过 **3 轮心跳**或 **5 分钟**（取先到）→ 清 pending + 栖不再追问
6. 确认后真读文件 → LLM consciousness digest → 开口「我看了看 X……」+ 谈区见闻卡（复用 explore 的 ExploreCard？不，assist result 用新卡片或纯文本）

**确认词/拒绝词辅助方法**：

```python
_CONFIRM_CUES = ("看吧", "看", "好", "行", "确认", "可以", "嗯", "yes", "ok")
_REJECT_CUES = ("不用", "算了", "不要", "取消", "no", "不用看")

def _is_confirm_cue(self, text: str) -> bool:
    t = text.strip().lower()
    return any(cue in t for cue in _CONFIRM_CUES)

def _is_reject_cue(self, text: str) -> bool:
    t = text.strip().lower()
    return any(cue in t for cue in _REJECT_CUES)
```

<template>
  <div class="assist-confirm-card paper">

import { computed } from "vue";
import type { AssistConfirmCard } from "../types";

const props = defineProps<{ card: AssistConfirmCard }>();

const fileName = computed(() => {
  // 从 target_path 提取文件名
  const parts = props.card.target_path.split(/[\\/]/);
  return parts[parts.length - 1] || props.card.target_path;
});
</script>
