# 2026-08-22 · L7 判断制取代确认门（非 irreversible）

> Cursor 单线。维护者拍板 **C**：凡非 irreversible 的 L7 帮忙，改**判断制**（接 / 拒 / 延后）；**确认只留给真危险动作**。  
> 背景：世界触达包把「从慎」落成「每次 confirm_gate + pending」，相处手感偏桌面助手；数字生命被请做事时应有**自己的判断**，不是步步 UAC。  
> 关联对话：请人上网查资料；三种口语反应（现在帮 / 没空 / 稍等）。  
> 层文档：`reference/layers/L7-action.md`（**原则 #5**：行动丰富 ≠ 功能表变长；动机分轨）。完工后回写「确认」段落。

## Spec（外部行为）

### 1. 总原则

1. **非 irreversible** 的响应式帮忙（用户开口请）：不再默认「每次确认才执行」。栖听完意图后，用**自然语言表态**三选一（可组合语气，非固定口令）：
   - **接**：愿意且此刻能动手 → 直接做，口头如「好，我看看」「嗯，我帮你瞧一眼」。
   - **拒**：不愿或关系/状态不允许 → 诚实说明，如「我这会儿顾不上」「这个我得先跟你熟一点再说」；**不假装做了**。
   - **延**：听懂但此刻忙 → 口头如「稍等，我弄完手上的再帮你看」→ **记入待办**（跨拍履约），忙完后主动或下轮用户再提时完成；**不弹确认卡等待点头**。

2. **irreversible**（发消息、花钱、对外不可逆等，见 L7 能力排序第 5 档）：**仍保留确认**——可以是同伴口吻一问，但必须有「这次真要动手」的二次核对；可复用 pending 协议，**不叠**工具腔文案。

3. **懂意思**：白话请人帮忙须能进正确能力路径（含「帮我查一下…」「你看看这个文件」「开一下那个链接」）；只有口令能通 = bug（contract「理解意图」）。

4. **结果呈现**：不限定单一 UI；允许口头摘要、见闻卡、链接、`together` 同看、creation 式卡片等——由行动结果类型决定，**不要求**统一确认卡。

5. **不主动**：用户没请时，仍不主动塞「要不要我帮你查」（contract 第 25 条不变）。判断制只作用于**被请之后**。

### 2. 纳入判断制的能力（C 范围）

| 能力 | 现行 | 目标 |
|------|------|------|
| `assist` `read_file` | friend+ 每次 confirm | 判断制；关系不够 → 拒，不 confirm 循环 |
| `open`（URL / 白名单应用） | acquaintance+ 每次 confirm | 判断制；陌生/伤疤/忙 → 拒或延 |
| `open` `allow` 写入白名单 | 候选 → confirm → 写入 | **判断制**；门槛 **friend+**；记前口头复述候选；非 irreversible |
| `disk` list / 开 D: 文件 | 每次 confirm | 判断制 |
| `write` D: 白名单 | 每次 confirm | 判断制（append/日记；覆盖风险靠白名单+判断，非每步确认） |
| `together` | 每次 confirm | 判断制 |
| `look` 邀看 | 已从宽、无叠卡 | 保持；与用户「叫停」关系分寸优先 |
| **委托式联网检索**（新） | 未实现 | **与本包同做（A）**：用户请人查公开资料 → 判断制三态；与自主 `explore` 分轨（动机：你请我帮） |

不在本包：`irreversible.py` 新建、删应用白名单、通用网页 Agent。

### 3. 判断依据（可观测，供实现与测试）

实现须能说明「为何此刻接/拒/延」，动机链追溯内部状态（C4），例如：

- **关系**：`permission.can_*` → allowed=False 时**拒**（非 confirm_required 空转）。
- **状态**：`stasis` / `dreaming` / 极低 `energy` / 高 `pressure.throttle` → **拒**或**延**。
- **忙**：本拍 `_pending_queue` 非空、GWS 高优先 respond、或已有未完成的用户委托 → **延**（入队）。
- **意愿（软）**：可对委托类请求用 volition 权重（好奇、信任、季节）；**不**用随机数当唯一理由。

延后委托：须有可查询的内存/落盘槽（如 `body_memory` 键或专用队列），含：请求摘要、时间、意图 kind；履约后清除。超时未做：诚实承认忘了/顾不上，不编造结果。

**欠账记忆（维护者 A，2026-08-22）**：延后入队；**履约成功后写 1 条 narrative**（谁请的、帮了什么、不贴用户原文/文件原文）。之后她可自然提起（如「你上午问的那个我查过了」），非通知栏提醒；仍受主动言语克制与关系门控，不刷屏。

### 4. 白话验收用例（非口令）

- 「帮我查一下量子纠缠入门资料」→ 接时真搜（配好外部源）或延/拒有合理解释；**不要求**「请确认是否搜索」。
- 「你现在忙吗，帮我看下 D 盘有啥」→ 忙则「稍等…」，不忙则列目录；**不要求**先点确认卡。
- 「帮我把这段话记进今天日记」→ bonded/acquaintance 判断后可直接写或说现在不方便。
- 「帮我给某某发微信」→ **仍须确认**（irreversible，若未实现则 failed_capability + 诚实说明）。

### 5. 委托式联网检索（本包同做）

- **触发**：用户白话请人查公开资料（非口令）；意图判别后进入 `delegate_search`（或等价 op），**不走**自主 `explore` 概率门。
- **判断**：同样接 / 拒 / 延；接则立刻 `WebSearchClient.search`（复用 Tavily 配置 `explore_external`），query 由用户意图提炼，**不**用 explore 的「走神问句」生成器。
- **开口**：成功 → 栖语气 digest（可复用 `_digest_hits` 逻辑）；失败/未配 key → 诚实「没查到 / 现在还查不了」，不编造。
- **呈现**：口头 + 可选见闻卡（`source=web_delegate` 或复用 `web`）；可进 `together` 池供「一起看」。
- **回顾**：履约成功且结果值得留痕时，进 `/history.cards`，**回顾**栏可翻（与创作/见闻同一「她经历过什么」时间轴；见 L6 §回顾、黄昏的枝 §回顾）。相处区可即时出卡，回顾为归档。
- **隐私**：不引用 user_facts、对话原文、用户文件原文作 query（对齐 explore 红线）。

### 6. `open.allow` 写白名单（判断制）

- **门槛**：`friend+`（严于普通 `open` 的 acquaintance+）；不够 → 拒，不挂 confirm。
- **记前**：口头复述候选（「你是说以后可以开这个吗？」）；用户肯定 → 写入；多候选列出让用户指认。
- **无**默认 `confirm_gate` / 叠确认卡；仍遵守懂意思（非口令）。

### 7. 架构长线约束（本包：留钩，不宣称换心）

- 每笔**委托**接/拒/延/履约：须写入可溯源痕迹（`insert_action` + `detail_json` 动机摘要，或等价 `broadcast_traces`），字段能答「为何此刻」——对齐 L7 原则「手变多，心仍要换」与 C4。
- **禁止**为委托检索单独起并行决策循环；须经 `volition` / `execute_kind` / brain 已有路径。
- LLM 仅用于：意图判别、query 提炼、digest 措辞——**不得**作为「要不要帮」的唯一黑箱；接拒延主因须为关系/状态/忙。
- 本包**不**做 N5 降级（语言器官-only）、不部署本地微调；只铺 N1 手与溯源数据面。
