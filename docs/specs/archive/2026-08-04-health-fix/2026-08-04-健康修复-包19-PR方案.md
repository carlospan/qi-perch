### 19-B · `qi/memory/facts.py` 人名门控收紧（主防线：字数形态）

改 `looks_like_person_name`（L270-313）尾段判定：

```python
    # 现状（漏网）：
    # if re.fullmatch(r"[\u4e00-\u9fff·]{1,6}", name):
    #     return True

    # 改为：
    # 1) 含「·」的少数民族长名：放宽到 3-12 字
    if "·" in name:
        return bool(re.fullmatch(r"[\u4e00-\u9fff·]{3,12}", name))
    # 2) 纯汉字名：收紧到 2-4 字（汉语姓名形态上限；
    #    实证脏数据全部 ≥5 字短语：请再解释一下/存在我本地/那今天几月几号）
    if re.fullmatch(r"[\u4e00-\u9fff]{2,4}", name):
        return True
```

- 黑名单段（L294-303）**保留不动**——作为第二道防线继续拦 2-4 字内的动词短语（如「过去拿」）。
- 同步把「请」「再」「解释」「一下」「存在」「本地」补进黑名单词元（防 2-4 字内的新组合漏网，如「再解释」3 字）。
- `len(name) > 12` 上限保留（英文名路径不变）。

**回归排查（Cursor 必做）**：跑 `tests/test_user_facts.py`，若既有用例依赖「5-6 字真名放行」，先判断该用例是否合理——真实长名应带「·」走长名路径；若属误伤合理场景，在回执中说明偏离并给出适配方案，**不擅自放宽回 {1,6}**。

### 19-C · `qi/core/brain_background.py` 后台节奏恢复

**(a) `memory_decay`（L95-104）：接入 resume 节奏（与 `culture_detection`/`user_drift` 同构）**

```python
async def memory_decay(brain: Brain) -> None:
    interval = float(brain.config.get("memory", {}).get("decay_interval", 86400))
    # 距上次褪色不足周期则补足；超期则短延迟（120s）即跑——不再要求连续挂机 24h
    await asyncio.sleep(
        await brain._resume_interval_wait("last_memory_decay", interval, 120.0)
    )
    while brain.alive:
        if not brain.alive or brain.memory is None:
            await asyncio.sleep(min(3600.0, interval))
            continue
        try:
            await brain.memory.narrative.decay()
            await brain._mark_interval_done("last_memory_decay")
        except Exception:
            logger.exception("记忆褪色后台出错")
        await asyncio.sleep(interval)
```

**(b) `narrative_weaving`（L52-82）：启动首检积压立即织**

在 `while brain.alive` 循环前置 `first_pass = True`；`pending >= backlog_threshold` 分支内：

```python
        if pending >= backlog_threshold:
            if first_pass:
                pass  # 启动即积压：不睡 backlog_interval，直接进织
            else:
                await asyncio.sleep(backlog_interval)
```

循环体尾部 `first_pass = False`。其余逻辑（check_period 分段复查、has_unprocessed_events 判定）**一字不改**。
