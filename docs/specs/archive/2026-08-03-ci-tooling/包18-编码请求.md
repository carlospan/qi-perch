## 改动一：stdout 编码重配置 + Windows 矩阵

落点：`tools/check_spec_traceability.py`（line 21-27 `from __future__ import annotations` + import 段之后）。

- 在 `import sys` 之后加：
  ```python
  if hasattr(sys.stdout, "reconfigure"):
      sys.stdout.reconfigure(encoding="utf-8", errors="replace")
  if hasattr(sys.stderr, "reconfigure"):
      sys.stderr.reconfigure(encoding="utf-8", errors="replace")
  ```
  两平台安全（ubuntu 默认 utf-8 不变；windows GBK 下 emoji 转 `?` 不崩）。

## 改动三：双 CI 合并

- **删除** `.github/workflows/ci.yml`（早期 ruff+pytest+doc-link）。
- **扩展** `.github/workflows/ci.yaml` 为唯一 CI：
  ```yaml
  name: CI
  on:
    push:
      branches: [main]
    pull_request:
  jobs:
    verify:
      strategy:
        matrix:
          os: [ubuntu-latest, windows-latest]
      runs-on: ${{ matrix.os }}
      steps:
        - uses: actions/checkout@v4
        - uses: actions/setup-python@v5
          with:
            python-version: "3.12"
        - name: Install dependencies (from lock, sanitized)
          run: |
            python -m pip install --upgrade pip
            grep -vE "^-e git\+https://github.com/carlospan/qi-perch" requirements.lock \
              | grep -vE "^-e d:\\\\" > /tmp/ci-requirements.txt
            pip install -r /tmp/ci-requirements.txt
        - name: Ruff
          run: python -m ruff check qi tests
        - name: Pytest
          run: python -m pytest -q
        - name: Doc link check
          run: python tools/check_doc_links.py
        - name: 包验收自动化（测试+ruff+diff+红线审计）
          run: python tools/verify_package.py --full
        - name: 规格可追溯性检查
          run: python tools/check_spec_traceability.py
  ```
  注意：`verify_package.py --full` 内部已跑 pytest（其 basetemp 现用系统临时区）；
  上方裸 `pytest -q` 与 `verify_package` 内的 pytest **会跑两遍**——为消除重复，
  **去掉裸 `pytest -q` 步骤**，以 `verify_package.py --full` 为唯一测试来源（它已含 pytest+ruff）。
  最终步骤：Ruff → verify_package --full（含 pytest+ruff+审计）→ doc-link → spec-trace。
  （doc-link / spec-trace 不在 verify_package 内，保留独立步骤。）
