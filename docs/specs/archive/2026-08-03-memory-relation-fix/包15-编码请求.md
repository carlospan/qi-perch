## 改动一：`qi/core/intention.py` 新增纯函数

在 `infer_recall_relation`（line 184）之后新增：

```python
_RELATION_HINT = {
    "taught_by_qi": "施教关系：栖教用户，不要反转",
    "learned_from_user": "施教关系：用户教栖，不要反转",
}

def anchor_teaching_relation(messages: list[dict]) -> str:
    """从真实对话（含 role 的 messages）推断助眠/施教方向，返回一句话锚定。

    只读 messages，不写库。无相关话题返回空串。
    - 扫含「教/方法/入睡/睡不着/呼吸/睡」的 user/assistant 消息；
    - assistant（栖）对用户说助眠建议（躺着/不强迫/看天花板/允许自己）→ taught_by_qi；
    - user 说「你教了我/这个方法」且栖发言佐证 → learned_from_user；
    - 冲突或不足 → 返回空串（不锚定，不瞎猜）。
    返回示例：'关于入睡方法：是你（栖）教给用户的，不是用户教你的；原话是
    「躺着、不强迫自己睡」，没有「数呼吸/数到七」。'
    """
```

复用既有 `_TAUGHT_BY_QI_RE` / `_LEARNED_FROM_USER_RE`（line 22-23）。
**仅新增导出函数，不改既有 recall 防护逻辑。**
