# 包 15：意识流施教关系锚定（修复补丁 A/B 的盲区）

> 类型：缺陷修复（记忆质量）｜依赖：包 12/13/14 已 ✅（阶段四退出）
> 关联：补丁 A `55f0a6d`（intention 施教关系反转）、补丁 B `5b89f16`（记忆也约束施教关系）

## 0. 一句话

施教关系反转防护只挂在「对话回复」路径（intention.py 的 recall），漏掉了「意识流」路径
（ConsciousnessStream.generate）。意识流在独白中引用「助眠方法」时把施教方向记反
（真实是栖教用户，它写成"你教我的方法"），并逐次添补虚构细节（躺着→数呼吸→数到七→
安全句子），且每次生成存回 consciousness_stream 形成自我强化的错误记忆。本包把锚定补到意识流。

## 1. 证据（来自 data/qi.db 实测）

- `consciousness_stream` 表 id=116~135 共 8 条，全部主语为「你教我的那个方法」，**方向反转**；
  方法内容逐条漂移：id116「闭上眼放慢呼吸」→ id117「数呼吸到七」→ id131「安全的句子」
  → id132「数中间那段空隙」→ id134「数到七」。真实对话（messages id=72/74）栖教用户的是
  「躺着、不强迫自己睡、看天花板」，**无"数呼吸/数到七"**，属虚构。
- 补丁 A/B 的 `_MUST_RECALL_RELATION` / `infer_recall_relation` 仅挂在 intention 卡片，
  ConsciousnessStream.generate 不读这些锚定（line 417 只 `list_recent_narratives`）。

## 2. 根因

`qi/inner_life/consciousness.py::generate()`（line 395）构造 prompt 时：
- `recent_memories`（line 417-418）只取叙事记忆喂给 LLM，**未注入施教方向**；
- 模板 `consciousness_stream.txt` 虽有"不虚构设定"软约束，但无方向锚定，LLM 凭碎片重构时
  必然方向反转 + 内容添补（生成式记忆漂移）；
- 生成结果存回 `consciousness_stream`（line 501），错误版本被后续 recall 反复强化。

## 3. 修复方案（最小、仿补丁 A/B 纪律）

### 3.1 新增施教方向锚定函数（复用既有正则，避免重复实现）

在 `qi/core/intention.py` 已存在 `_TAUGHT_BY_QI_RE` / `_LEARNED_FROM_USER_RE`（line 14-15）。
新增纯函数 `anchor_teaching_relation(messages: list[dict]) -> str`，输入真实对话
（含 role 的 messages，非栖生成的叙事），规则：
- 扫「教/方法/入睡/睡不着/呼吸/睡」话题的 user/assistant 消息；
- 若 assistant（栖）对用户说"躺着/不强迫/看天花板/允许自己"类助眠建议 → 方向 `taught_by_qi`
  （栖教用户）；
- 若 user 对栖说"你教了我/这个方法" → 方向 `learned_from_user`（用户教栖），但需与栖发言交叉验证；
- 返回一句话锚定文本，如："关于入睡方法：是你（栖）教给用户的，不是用户教你的；原话是
  「躺着、不强迫自己睡」，没有「数呼吸/数到七」。"

### 3.2 注入意识流 prompt

`ConsciousnessStream.generate`（line 417 附近）：
```python
from qi.core.intention import anchor_teaching_relation
recent_msgs = await self.db.load_recent_messages(limit=20)
relation_hint = anchor_teaching_relation(recent_msgs)
```
把 `relation_hint` 加入 `template.format(...)` 的入参。

### 3.3 模板加占位 + 硬约束

`qi/prompts/consciousness_stream.txt`：
- line 16 `记忆片段（淡背景）：{recent_memories}` 后新增一行：
  `施教关系锚定（必须遵循，不得反转）：{relation_hint}`
- 硬约束段（line 28 附近）追加：
  `引用「方法/教过的事/入睡」时，严格以施教关系锚定为准；不得把"你教我的"说成反方向，
   不得添加锚定里没有的细节（如"数到七"）。若锚定与你的印象冲突，以锚定为准。`

### 3.4 防回归测试

`tests/test_inner_life.py` 新增：
- 构造 messages：assistant 教用户「躺着不强迫自己睡」，user 说「你教了我一个方法」；
- mock LLM 返回含「你教我的方法/数到七」的拟反转文本，断言 generate 的 prompt 中
  `relation_hint` 含 `taught_by_qi` 且模板含硬约束占位（或：直接断言锚定函数对样例输出方向正确）；
- 既有 consciousness 测试不变。

## 4. 验收标准（第 11 节）

1. 意识流 prompt 含 `施教关系锚定` 占位且注入 `relation_hint`，非空。
2. `anchor_teaching_relation` 对「栖教用户助眠」样例返回 `taught_by_qi` 方向、不含「数到七」。
3. 模板硬约束句存在，LLM 若反转方向可被锚定纠正（单测断言 prompt 含约束）。
4. 全量测试通过（含新增单测），ruff 零问题。
5. 不改动 intention.py 既有 recall 防护（仅新增导出函数，无行为变更）。
