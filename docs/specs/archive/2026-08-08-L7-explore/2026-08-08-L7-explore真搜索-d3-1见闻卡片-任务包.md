## Spec

前端新增「见闻卡片」，把栖外部探索的结果渲染成谈区可见的物件——让用户**看到她瞥见了什么**，而非只听 qi_line 复述。内部沙箱扫描不渲染卡片（保持 d-1 沉默）。

## 背景

d-2 后栖外部探索会开口（qi_line=digest 栖语气复述）+ broadcast `{"type":"action","payload":{type:"explore_drift", found:{entries,query}, summary, qi_line, ...}}`。但前端 `useQi.ts` 只渲染 `creation_card`，`explore_drift`「到达不报错、不渲染」——用户只「听到」栖说看了什么，**看不到她实际瞥见的 hits**。`found.entries`（title/snippet/url）白留了。

d-3-1 补这块可见性：纯前端，后端零改（drift 已返回全字段）。

## 现状（只读核对）

- `qi/action/explore.py` drift 返回：`type:"explore_drift"` + `found`(entries/source/query) + `summary`(digest) + `qi_line`(digest) + `action_id` + `season` + `curiosity` + `source`("web"/"sandbox") + `sandbox`
- `qi/core/brain_delivery.py` L130-145：`creation_card` → qi_line 开口 + broadcast；explore（speak+qi_line）→ qi_line 开口 + broadcast（payload 已含 found）
- `desktop/src/types.ts` L38-58：`ActionPayload` 已含 `explore_drift` 形状（found/summary/action_id/season/curiosity/sandbox）——**但缺 `source`/`qi_line`/`speak` 字段**（d-1/d-2 后端新增，类型未同步）
- `desktop/src/composables/useQi.ts` L312-315：`qiWs.on("action")` 只 `creation_card → appendCard`；`explore_drift` 不渲染
- `desktop/src/components/TalkView.vue` L70-72：`m.kind==="card"` → `<ActionCard :card="m.card" />`（只 CreationCard）
- `desktop/src/components/ActionCard.vue`：只渲染 CreationCard（creation_type/content/season）

## HITL（已拍：2026-08-08）

1. ✓ **卡片正文 = a hits 溯源**：卡片正文 = hits 溯源（title 小字 faint，像「她瞥见」；URL 可点但不抢眼）；digest 由 spoken qi_line 承载，**不在卡片重复**。卡片是「瞥见的来源物件」，开口是「她的声音」——同 creation_card 的「qi_line 指向卡片」分工。（选 a 避免动后端，保纯前端 scope）
2. ✓ **内部沙箱扫不渲染卡片**：内部 `source=="sandbox"` 保持 d-1 沉默（不 speak、不卡片）；仅 `source=="web"` 渲染卡片。
3. ✓ **卡片视觉 = 纸感 + 角标「看」**：同 ActionCard 纸感（`--talk-qi-bg`/`--ember` 侧条），角标「看」，与创作卡（笔记/诗/随笔/画面）区分。

> 补丁（吸收 Cursor 交叉审查 B1，2026-08-08）：外部**空手**（`found=None` / `entries` 空）仍 `source=="web"` + broadcast，须**不入见闻卡**——仅 `entries.length > 0` 才入卡；空手只开口、不出卡。
