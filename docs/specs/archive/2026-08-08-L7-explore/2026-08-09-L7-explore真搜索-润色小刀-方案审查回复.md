## B1 关闭：`_exclude_domains` 读法对齐扁平 config

**核实**：[layer.py:90](file:///d:/qi-perch/qi/action/layer.py#L90) `WebSearchClient(config=ext)` 传入的是已剥过 `action.explore_external` 的**扁平子段**（含 `enabled/provider/api_key/cooldown_hours/probability`）。

**修订回写**（PR 方案 §2 `_exclude_domains` 读法）：

```python
# 原伪代码（错——多嵌一层，永不生效）
def _exclude_domains(self) -> list[str]:
    raw = (self.config.get("explore_external") or {}).get("exclude_domains") or []

# 改为（对齐扁平结构）
def _exclude_domains(self) -> list[str]:
    raw = self.config.get("exclude_domains") or []
    if not isinstance(raw, list):
        return []
    return [str(d).strip().lower() for d in raw if str(d).strip()]
```

**测试 config 形对齐**（PR 方案 §4 测试）：

```python
# 原（错）
cfg = {"action": {"explore_external": {"exclude_domains": ["music.apple.com"]}}}

# 改为（对齐扁平）
cfg = {"exclude_domains": ["music.apple.com", "mojim.com"]}
client = WebSearchClient(provider="tavily", api_key="k", config=cfg)
```
