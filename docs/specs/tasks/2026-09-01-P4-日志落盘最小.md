## Spec（外部行为）

1. 具身后端启动后，运行日志**落盘**到数据根下 `logs/qi.log`（控制台仍可有同等级别输出）。  
2. 轮转：单文件约 ≤5MB，保留约 3 份；默认级别 INFO。  
3. 设置页「数据文件夹」区块旁有 **「打开日志文件夹」**；本机打开 `logs/`；短说明提醒报 bug 可贴此处文件、勿随便外传可能含敏感信息的文件。  
4. **本刀不做**：脱敏过滤、日志上传、壳/前端侧单独日志、改级别 UI。
