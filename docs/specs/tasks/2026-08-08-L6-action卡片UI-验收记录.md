## 六、角标映射修正（验收后追加）

**触发**：初版验收后，Cursor 发现 `ActionCard.vue` 的 `TYPE_LABEL` 与后端 `creativity.py::_infer_type` 实际产出码不一致，请方案侧裁定（见 [角标映射裁定](2026-08-08-L6-action卡片UI-角标映射裁定.md)）。

**偏差**：
- 死映射：`prose` / `story` / `journal`（后端 [creativity.py:64-72](file:///d:/qi-perch/qi/inner_life/creativity.py#L64-L72) 从不产）。
- 缺失：`essay` / `description`（后端会产），会走兜底。
- 兜底 `length≤6 ? t : ""` 会让未知英文码泄漏进中文 UI，与方案「兜底省略」相悖。

**修正**（[ActionCard.vue:9-21](file:///d:/qi-perch/qi/embodiment/desktop/src/components/ActionCard.vue#L9-L21)）：

```typescript
const TYPE_LABEL: Record<string, string> = {
  note: "笔记",
  poem: "写",
  essay: "写",
  description: "写",
};

const typeLabel = computed(() => {
  const t = (props.card.creation_type || "").trim().toLowerCase();
  if (!t || t === "unknown") return "";
  return TYPE_LABEL[t] || "";   // 未知一律省略
});
```

**复核**：build ✓（6.37s）/ vue-tsc 零错。`TYPE_LABEL` 已读源确认与裁定一致。

**scope**：本包内 correctness 修正，非行为 / 架构变更，未开新包。细角标（诗 / 随笔 / 画面 …）若维护者想要 → 另开包（动 UI 口径），本包未做。
