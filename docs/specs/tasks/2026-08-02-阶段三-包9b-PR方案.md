## 实现（交给 Cursor 的步骤）

### 1. 新增 `qi/world/emotion_trajectory.py` —— `EmotionTrajectory`

轻量后验（纯标准库，不引重依赖）：

- 后验存储：**复用 `body_memory` 表**，key = `"world.emotion_trajectory"`，value 含每维度的近期统计（滑动均值 + 近期 delta 样本窗口）。无需新建表。
- `async def record(self, brain, *, now)`：读 `brain.emotion` 当前六维；对每个被追踪维度（默认 `valence/arousal/energy`——最易观测走向者）计算本拍 delta = 当前值 - 上一拍记录值（首拍无上一拍则只存基线，surprise=0）；用近期 delta 分布预测"下一拍 delta 符号/量级"，实际 delta 与预测不符即产生 surprise。
- `def predict_next(self, dim) -> float`：基于近期 delta 均值返回预测的下拍方向（如近期 valence 走低→预测继续微降）。
- `def surprise(self, dim, actual_delta) -> float`：实际 delta 与预测的差异度（如 `abs(actual_delta - predicted_delta)` 或对数误差），夹到合理范围。
- `def snapshot(self, now) -> dict`：返回 `{ "tracked_dims": [...], "surprise": {dim: s}, "predicted_delta": {dim: p} }`。
- 加载：构造时从 `set_body_memory` 读 `"world.emotion_trajectory"`（无则空）；所有写经 `brain._db.set_body_memory`；**不依赖 LLM**。

> 设计提示：不必做复杂贝叶斯。简单可测即可——维护每维度最近 N（如 20）个 delta 的均值与方差，`predict_next` 返回均值，`surprise = abs(actual - mean) / (std+ε)`。重点是"预测误差可溯源"，不是预测精度。

### 2. 改 `qi/world/model.py` —— 挂入 WorldModel
