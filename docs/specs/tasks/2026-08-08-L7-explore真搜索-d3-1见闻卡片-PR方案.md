## 外部可观测行为

栖外部探索触发时，谈区先出栖开口（qi_line digest 文本，d-2 已有），后出一张「见闻卡片」：纸感、角标「看」、正文为 hits 溯源（title 小字 faint，像她瞥见的来源）；digest 不在卡片重复（开口已承载）。内部沙箱扫不出卡片、不 speak（d-1 不回归）。

### 3. `composables/useQi.ts`

**3a. `appendCard` 泛化 + 按 type 分支去重**（现 L92-102；吸收 N1）

```ts
function appendCard(card: CreationCard | ExploreCard) {
  // 按 type 分支去重：creation→creation_id，explore→action_id（更稳，避免异类撞键）
  const key = card.type === "creation_card" ? `c${card.creation_id}` : `e${card.action_id}`;
  if (cards.value.some((c) => cardKey(c.card) === key)) return;
  cards.value.push({ id: uid("card"), kind: "card", card, at: Date.now() });
}
// cardKey 同上分支取键（实现侧抽小工具或内联）
```

**3b. `qiWs.on("action")` 处理 explore_drift**（现 L312-315；吸收 B1）

```ts
qiWs.on("action", (payload: ActionPayload) => {
  if (payload?.type === "creation_card") {
    appendCard(payload);
    return;
  }
  if (payload?.type === "explore_drift") {
    // HITL2：仅外部渲染卡片；HITL1a：须有 hits 才出卡
    // B1：外部空手（found=null / entries 空）仍 source=web + broadcast，但只开口、不出卡
    const entries = payload.found?.entries;
    if (payload.source === "web" && Array.isArray(entries) && entries.length > 0) {
      appendCard(payload);
    }
    // source==="sandbox" 或空手：到达不报错、不渲染卡片（空手仍开口，由 delivery 已 speak）
  }
  // tend_mark：到达不报错、不渲染
});
```
