# 2026-08-25 · 委托检索 · P0 策略

> 总 Spec：`2026-08-25-委托检索对齐Agent.md`。本包只做 **P0**。

## Spec（外部行为）

1. **多 query**：主问句之外，至少再发一条带**当前年份**的改写（若主句尚无年份）；合并去重结果。
2. **新闻向**：至少一轮带 `topic=news` + 近月 `time_range`（或等价），减轻纯维基年表霸榜。
3. **追问再搜**：用户说「刷到 / 再查 / 又听说」或对刚查过的外部话题继续打听时，**再跑检索**，不背旧摘要当闲聊。
4. **失败再搜**：首轮空结果时，用更深/更新闻向参数再试一次；仍空则诚实说没搜到。
5. **不改** P1 对照话术大改、P2 深读、P3 编排模块（另包）。
