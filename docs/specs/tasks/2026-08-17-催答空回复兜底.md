# 2026-08-17 · 催答空回复 / 空卡兜底

> Cursor 单线。范围仅表达层：用户催答时禁止再只回「……嗯。」。  
> **不做**：强迫「会教吗」类关系试探必须 yes/no；不改 `bonded` 叙事。

---

## Spec（外部行为）

1. 用户用白话催答（如「你还没回答」「没答我」）时：若本拍 LLM 空返回或只产出「……嗯。」类敷衍，须再试一拍（带催答约束）或改用**明确接住催促**的模板，**不得**最终只输出 `……嗯。`。
2. 催答模板须承认「你在催上一问」，可请用户半句点明要听哪一问；**禁止**在模板里编造对上一问的实质答案（含会/不会教找女朋友）。
3. 非催答路径：空卡 `free_talk` 原有短嗯 / `_FREE_TALK_SAFE` 行为保持不变。
4. 催答识别为启发式（辅助兜底与重试），不是行动意图唯一入口。
