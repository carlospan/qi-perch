## Spec（外部行为）

1. **设置页可「试一下」钥匙**  
   - 用户主动点按钮；**不**打开设置就自动测、**不**后台轮询  
   - 结果写在**设置页**（通 / 缺钥匙 / 连不上 / 其它短提示），**不**走她 speech、**不**进谈区气泡  
   - 探测为**后台一记极短 chat**（走现有 LLM 网关：当前 key / base_url / 模型）；**不**写入对话历史、**不**进记忆/日记/回顾  
   - **只测已保存并已热重载的配置**；表单有未保存改动时提示先保存再试，不拿草稿偷偷测  
   - 探测超时约 **15 秒**；失败文案与现有系统态分级同构子集（缺钥匙 / 连不上 / 这轮没接好等）；成功短确认；**不**露堆栈、**不**整段贴模型原文  
   - 探测须能覆盖：key 是否被接受、base_url 是否可达、当前模型配置是否大致可用  
2. **不含**：首启整页、免费云脑、改保存/热重载逻辑大翻修、口型/TTS、安装包。
