## 外部可观测行为（Spec）

1. 用户「帮我看一下 D:/x.txt」→ assist-2 链 → confirm_gate 开口 + 谈区出**确认卡片**（角标「看？」、文件名、看吧/不用按钮）
2. 用户点「看吧」或口头「看吧」→ confirmed=True → 真读文件 → digest 开口「我看了看 X……」
3. 用户点「不用」或口头「不用」→ 清 pending + 栖开口「好。」
4. 用户换话题 → 清 pending
5. pending 超 5 分钟或 3 轮心跳 → 清
6. assist digest 开口为纯文本（不出见闻卡，HITL3）

**辅助方法**（brain 类内）：

```python
_CONFIRM_CUES = ("看吧", "看", "好", "行", "确认", "可以", "嗯", "yes", "ok")
_REJECT_CUES = ("不用", "算了", "不要", "取消", "no", "不用看")

def _is_confirm_cue(self, text: str) -> bool:
    t = text.strip().lower()
    return any(cue in t for cue in self._CONFIRM_CUES)

def _is_reject_cue(self, text: str) -> bool:
    t = text.strip().lower()
    return any(cue in t for cue in self._REJECT_CUES)
```
