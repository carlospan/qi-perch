## B1 关闭：trace 去掉 assist continue

**核实**：[trace.py L446-447](file:///d:/qi-perch/qi/core/trace.py#L446) `if it.kind == "assist": continue` —— assist 候选被显式跳过，不进 GWS candidates。

这是 volition 候选桩时的旧逻辑（「本阶段不执行」注释）。assist-1 已接执行骨架，assist-2 补触发链，应放行进 GWS。

**修订回写**（PR §3 trace）：

```python
# 现 L445-447
for it in intents:
    if it.kind == "assist":
        continue
    candidates.append(...)

# 改为：assist 放行进 GWS（响应式候选）
for it in intents:
    candidates.append(
        Contender(
            kind=f"action:{it.kind}",
            salience=salience_action(priority=it.priority),
            reason=it.reason or it.kind,
        )
    )
```

> 注：assist priority=0.85，与 respond 竞争 GWS（respond 永不被压过，包 7 不变式）。assist 胜出需用户明确请求 + respond 不优先——符合「响应式」语义。

B1 已关闭。

## B2 关闭：相对路径正则修正

**核实**：我的正则 `r"([\w./-]+\.txt|\.md|\.json|\.csv|\.log|\.py|\.js|\.ts)"` —— `|\.md` 是独立分支（匹配字面 `.md` 而非 `note.md`），`note.md` 会被 group 捕获成 `.md`。

**修订回写**（PR §1 volition 正则）：

```python
# 原（bug）
_PATH_PATTERNS = [
    ...
    re.compile(r"([\w./-]+\.txt|\.md|\.json|\.csv|\.log|\.py|\.js|\.ts)", re.I),
]

# 改为：扩展名合并为非捕获组
_PATH_PATTERNS = [
    ...
    re.compile(r"([\w./-]+\.(?:txt|md|json|csv|log|py|js|ts))", re.I),
]
```

B2 已关闭。

## B3 关闭：last_assist_request 消费

**核实**：brain 存 `last_assist_request` 但无消费——每拍 GWS 胜出 assist 后，last_assist_request 仍在，下一拍 idle 会再次读 → 反复 confirm_gate「说一声我就看」。

**裁定**：execute_kind 调 assist 后清空 last_assist_request（消费一次）。

**修订回写**（PR §2 brain execute_kind）：

```python
action_result = await self.action.execute_kind(
    action_type,
    ...
    op=op,
    target_path=target_path,
    confirmed=False,
)
# B3：assist 消费一次后清空，防 idle 反复 confirm_gate
if action_type == "assist":
    self.last_assist_request = None
```

> 注：只清 last_assist_request，不清 last_user_message（后者有其他用途如感知上下文）。消费后下一拍若用户再发新消息，receive_user_message 重新解析存新值。

B3 已关闭。

async def test_assist_request_consumed_after_execute_kind(self, brain_with_llm, tmp_path):

        brain_with_llm.relationship_stage,
        brain_with_llm._current_season(),

        mode="awake",
        op="read_file",
        target_path=str(tmp_path / "note.txt"),

    )
    # 3. B3：消费后清空
    assert brain_with_llm.last_assist_request is None
