## Spec（外部可观测行为）

1. 行动执行后，若 outcome ∈ {`failed_judgment`, `overstepped`}，自动调 `db.save_scar` 形成伤疤。
2. 伤疤 `origin_event` 带 `[action:{kind}]` 标记，供 `scar_blocks_kind` / `scar_caution_multiplier` 识别。
3. 未愈同类伤疤 → `scar_blocks_kind` 返回 True → 该类行动被暂时阻断（手缩回去）。
4. 伤疤 severity 按 outcome 分级：`failed_judgment` = 0.3（中等）、`overstepped` = 0.7（严重）。
5. `trust_before` 从关系层读取（`relationship.state.trust`）。

### 缺口

1. **无接线**：[layer.py tick/execute_kind](file:///d:/qi-perch/qi/action/layer.py) 拿到 `result` 后存 `last_result`，**没检查 outcome 触发 save_scar**

### 难点

伤疤接线的真实问题不是"接线"，是**触发源**——怎么判定"做了但不该在这时给你看"（failed_judgment）或"做了不该做的事"（overstepped）？

## 触发源选项（HITL 拍板）

| 选项 | 触发源 | 范围 | 真实度 |
|------|--------|------|--------|
| **A** | 只接骨架（layer 检查 outcome → save_scar）；触发源留 assist/irreversible | 最小 | 现状无伤疤生成，骨架通了 |
| **B** | 骨架 + 用户反馈触发（感知层识别"你刚才不该…"）| 中 | 真实伤疤来源（关系驱动）|
| **C** | 骨架 + explore digest 编造自检（LLM 评估 digest）| 中 | 自动，但判定难、成本高 |

**倾向 A**：理由——
- 最小、不扩大范围、符合"一次一包"
- 骨架通了后，assist（用户拒绝确认 → overstepped）和 irreversible 会自然产出触发源
- 用户反馈触发（B）涉及感知层改动，应另开包（感知包，非行动包）
- digest 自检（C）判定难、可能误判，应观察相处后再决定

**A 的局限**：现状无真实伤疤生成，验收只能用测试构造 failed_judgment outcome 验证接线。但骨架通了，后续 assist 落地时触发源自然出现。

## 实现步骤概要

1. `layer.py` 新增私有方法 `_maybe_save_scar(result, kind, now)`：
   ```python
   async def _maybe_save_scar(self, result: dict, kind: str, now: datetime) -> None:
       outcome = result.get("outcome")
       if not outcome_creates_scar(outcome):
           return
       severity = 0.7 if outcome == OUTCOME_OVERSTEPPED else 0.3
       trust_before = float(getattr(self._relationship_state, "trust", 0.5) or 0.5)  # 需接线
       origin = f"[action:{kind}] {result.get('summary', '')[:80]}"
       try:
           scar_id = await self.db.save_scar(
               origin_event=origin,
               severity=severity,
               trust_before=trust_before,
           )
           result["created_scar"] = scar_id
       except Exception:
           logger.debug("save_scar 失败", exc_info=True)
   ```
2. `tick` + `execute_kind` 在 `self.last_result = result` 前调 `await self._maybe_save_scar(result, kind, now)`。
3. `trust_before` 接线：ActionLayer 需持有 relationship state 引用，或 brain 调 tick/execute_kind 时传 `trust` 参（**R1 风险**，见下）。
