## Spec（外部可观测行为）

1. **纯响应式**：用户要她开，她才走 open；**绝不自主**打开链接或应用（自主邀看世界留给 `together`）。
2. **从慎**：未确认前不真开。确认像同伴问一句（「现在开吗？」），不是系统权限腔。确认卡 + 口头确认均可（复用 assist 确认协议；**超时同 assist：约 5 分钟或 3 轮心跳，取先到**）。与 assist 共用「同一时刻只挂一份待确认」：**新请求替换旧请求**，文案须标明当前在问哪一件。待确认期间：肯定义（「开吧 / 好 / 行」等）→ 执行；拒绝义（「算了 / 别开」等）→ 取消——**同样懂意思，不靠死口令**。
3. **能开什么**  
   - **URL**：仅 `http` / `https`；一次消息多个链接时只开**一个**（通常第一个）。拒 `file://` 等其它协议。  
   - **应用**：查**唯一真源白名单**（持久化；见下）。名单外不硬开，老实说，可引导「以后要不要让我帮你开」。
4. **白名单真源**  
   - 运行时只认一份可写名单（建议 `body_memory` key，如 `open_app_whitelist`）。  
   - **空名单起步**（无 yaml 叠加、无代码硬编码常驻表）。  
   - **授权（allow）**：意图为 allow → 解析/猜测应用候选（**开始菜单 `.lnk` + 常见安装目录浅搜** + `where`；不做全盘扫）→ **再确认**（路径/命令写清楚）→ 你点头后写入名单。对白不用「教」；用户说「教会你开」仍可懂。  
     - 多个候选时：确认卡列出**最多 3 个**供选择；找不到则诚实说明，不瞎写入、不瞎开。  
   - **删除白名单**（「以后别帮我开某某」）——**要做，本包不做**，另开小刀。
5. **意图理解（重）**  
   - **懂意思，不靠口令**（契约软原则）。不靠死记触发句。  
   - 轻启发式只负责「值不值得问模型」；弱/含糊候选交 **LLM 结构化判别**：`open` / `open_and_look` / `allow` / `neither`（可附目标；旧名 `teach` 读入时归一为 `allow`）。  
   - 强信号可短路（清晰 `https://…` + 纯打开义 → `open`；「看看这个链接」类 → `open_and_look`）。  
   - 含糊则**问清一句**，不猜错就动手或写入。  
   - 「打开」与「授权进名单」必须分开；不确定时宁可问，不要既写又开。
6. **关系**：`acquaintance+`（与 look 同）；仍每次确认。更早阶段不真开。
7. **成功**：真打开后**轻开口**一句（同伴感，非「已为您打开」）。**是否再 look**：由意图决定——用户只表达「打开/帮我开」→ **只开不瞥**；表达「看看/瞧瞧这个链接（或类似想知道上面是什么）」→ 打开后再 look 一眼（复用 look；等窗口起来；瞥失败只承认开了，不编内容）。意图含糊则问清，不默认瞥。失败打开 → `failed_capability`，说清楚，不编造已打开。
8. **防抖**：确认后同一目标短时间内只开一次（防连点）。
9. **kind**：独立 `kind=open`；确认协议复用 assist（卡类型可共用或轻扩）。
10. **系统浏览器 / 系统启动**：开在用户的世界里，不塞进栖窗内嵌浏览器冒充。**本包 Windows 先行**；其它 OS：URL 尽量用通用方式打开，应用候选/启动可降级或跳过并诚实说明。
11. **不做（本包）**  
    - 静默开、任意进程、网页多步 Agent、自主开  
    - `list_dir` / 扫盘 / 打开本地文件（见下文「另开刀」）  
    - 删白名单、write、together、irreversible  
    - 通用读网页 / 抓 HTML（瞥屏 ≠ 读源码）

## 背景与现状

- 冻结：open = 确认后开 URL / 白名单应用；行动从慎。  
- 可复用：assist 的 `confirm_gate` / `pending_*_confirmation` / `AssistConfirmCard` / 口头确认与超时。  
- 现行无 `kind=open`、无应用白名单持久化、无 allow 路径。  
- assist 仅 `read_file`（须明确路径）；**不能**列目录——故本包也不做「打开本地文件」。

## 另开刀（文档记一笔 · 本包不编码）

| 项 | 说明 |
|----|------|
| **`list_dir`（列目录）** | **不算 open**。动机：模糊指认本地文件的前提；归属更近 assist/盘感知。须从慎（确认后、只列点名目录）。有它再议「打开本地文件」。 |
| **打开本地文件** | 默认程序打开某路径；依赖完整路径或先有 `list_dir`。 |
| **删除白名单** | 「以后别帮我开某某」→ 确认 → 从名单移除。 |
| **allow 对话写入的发现体验润色** | 失败口吻、记入名单后的轻开口（主路径有诚实失败即可）；对白不用「教」。 |

## 实现（步骤 · 编码时）

1. 白名单存储：空起步；读写 API；与 open/allow 共用。

## 风险与纪律

- 打开会抢焦点——确认与纯响应式不可破。  
- 意图 LLM 失败 → 当 neither 或问清，不默认执行。  
- 一次一包：不顺手 list_dir / write / together。  
- R 红线：不宣称现象体验；不客服腔。
