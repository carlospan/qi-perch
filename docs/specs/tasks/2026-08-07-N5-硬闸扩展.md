## Spec（外部行为）

N5（语言器官）的硬闸——`expression.py` 出口对 LLM 生成文本的事实一致性校验——当前仅覆盖施教反转 + 伪记忆 + 专名黑名单三类（包 15-17 产物）。本任务将硬闸从"施教专项"扩展为"通用事实一致性"：

1. **实体一致性硬闸**：检查 LLM 生成的回复是否引入了 `IntentionCard.materials` 中不存在的**新实体**（人名、地名、事件、设定）。命中 → 重生成一次（加约束），仍命中 → 模板兜底。仅拦实体，不拦修辞和意象——保留栖的文学性。
2. **materials 注入强化**：确保 prompt 中 `IntentionCard.materials` 的呈现方式充分、生动，让 LLM 自然基于素材说话——从源头减少虚构（优先于出口校验）。

> 本栏由 CodeBuddy 写（方案侧）。
