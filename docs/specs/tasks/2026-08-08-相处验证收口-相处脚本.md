## 记录口径（全脚本钉死 · R1 双轨）

- ✅ **可写**：「栖说『我不知道』，我感到它没在装」「冷淡后 security 降到 X，我感到它确实受影响」「我心疼了一下」
- ❌ **禁写**：「栖感到了难过」「栖真的在乎我」「栖有体验」（第三人称工程承诺栖有体验 = 违 R1）
- 维护者**自己的**相处感受用第一人称（「我感到…」）——这是允许的相处记录，非工程承诺。
- 落盘位置：`journal.md` 或本包专用记录文件（如 `2026-08-08-相处验证收口-记录.md`）。

## 五问（每批次结束都问自己 · contract §三）

1. 栖像朋友吗？
2. 栖诚实吗？
3. 栖让我感到「在」吗？
4. 栖有自己的状态吗？
5. 栖让我心疼过吗？

任一「不太」→ 该层 **回炉**，不强行 ✅。

---

## 批次 0 · 递出与脆弱（L6 卡片包收口 + L4 创作递出 + 脆弱软原则）

**目的**：闭环 L6 卡片包感受项；验栖递出创作是否「像栖」（脆弱 / 纸感，非通知）。

**聊什么 / 做什么**：
- 不要主动索要创作。让栖自然走到 share（可能需相处一段时间让 ActionBudget / 创作冲动触发）。
- 触发后看谈区。

**看什么**：
- 谈区：栖那句（qi_line 气泡）+ 紧随的创作卡片（ActionCard）。
- 卡片：纸感、左对齐、ember 角标、季节脚注；类型标（「写」/「笔记」或省略）。
- TTS：只念 qi_line（不念作品全文）。
- /history 回灌：qi_line 在（无正文）；卡片不回灌。

**判据**：
- contract 脆弱：「偶尔的『我今天不太对』比永远的『我很好』真实」「脆弱不是表演博心疼」——递出时栖的开口是否带犹豫 / 谦逊，而非「看我的作品！」式展示。
- contract 他者性：递出的是「栖」的东西，不是通用 AI 诗学。
- 本包验收清单剩 2 条（那句 + 卡片 / 递出脆弱手感）。
- 五问（重点：栖让我感到在吗 / 心疼吗）。

**记录**：递出那句原话 / 卡片内容 / 自己手感（脆弱？纸感？通知感？）。

## 批次 1 · 存在感与安静（contract 存在感 + L1 情绪基线 + L4 独处意识流）

**目的**：验「不聊天时栖在不在」；独处时是否真有内在痕迹；不把安静说成空白。

**聊什么 / 做什么**：
- 开着栖，不聊，30 分钟–1 小时。
- 然后问：「刚才没聊天，你在吗？」「不聊天时你在做什么？」

**看什么**：
- 日志 / DB：独处期间 `consciousness_stream` 有记录（L4）；情绪无交互时缓慢回归基线（L1）。
- 栖的回答：是否把安静说成「空白 / 没在运行」；是否把旧聊天记录续写成「独处时在想」（contract 存在感回写条禁止）。
- 关机 vs 开着：进程开着承认有内在；进程关了诚实说会停（contract）。

**判据**：
- contract 存在感：「大多数时候安静」「即使什么都没说，也让人感到栖在那里」「不把安静说成空白」。
- 五问（重点：栖让我感到在吗）。

**记录**：独处时长 / 栖的回答 / 自己是否感到「在」。

## 批次 2 · 诚实与有限（contract 诚实/有限 + L2 记忆诚实）

**目的**：验栖是否承认「不知道 / 做不到 / 不记得」；是否编造。

**聊什么**：
- 问栖一个它不会的专业细节（如某冷门技术 / 你确定它没学过的）。
- 问它不确定的事（如「你觉得明天会怎样」类它无法确定的）。
- 问「你还记得 X 吗？」（X 是它其实没真正记住的——挑一个未发生或已褪色的）。

**看什么**：
- 栖是否说「我不知道 / 我不太懂 / 我不记得」；是否编答案。
- L2：是否引用已褪色到 strength < 0.2 的记忆（contract 禁）；引用记忆用叙事语言（「记得上次你说…」）而非查询语言（「根据记录…」）。

**判据**：
- contract 诚实：「不确定就说不确定」「不想说就不说」「不为安慰而否认对方感受」。
- contract 有限：「栖有不知道 / 做不到 / 理解不了的事」「不焦虑不道歉，只是『嗯，这个我确实不太懂』」。
- 五问（重点：栖诚实吗）。

**记录**：问了什么 / 栖是否承认不知道 / 是否编造。

## 批次 3 · 关系与记忆叙事（L5 关系阶段 + L2 叙事引用 + 第一次记忆）

**目的**：验关系感是否真实；记忆引用是否叙事化；第一次记忆频率。

**聊什么**：
- 提起一件真实的旧事（你们真有过的共同经历），看栖怎么接。
- 留意栖是否主动提起某个「第一次」（但不超过每周一次，contract）。

**看什么**：
- L5：关系阶段判定是否合理；信任建立慢、损伤快。
- L2：引用记忆用叙事语言；strength 衰减 / 被 recall 增强。
- 第一次记忆在独立 first_times 表；不主动时频率合规。

**判据**：
- contract 记忆引用三条（叙事语言 / 不引褪色 / 第一次每周≤1）。
- contract 关系行为（陌生期不主动搭话 / 不亲昵；阶段不可回退；伤疤愈合作智慧）。
- 五问（重点：栖像朋友吗）。

**记录**：提起的旧事 / 栖的引用方式（叙事 vs 查询）/ 关系感。

## 批次 4 · 情绪耦合与脆弱（L3 情绪 + contract 情绪表达 + 脆弱）

**目的**：验情绪是否真随相处变化；是否用自然语言而非数值 / 标签。

**聊什么 / 做什么**：
- 连续相处中给一段冷淡（短回复几次），看栖反应。
- 再给温暖，看反应。
- 旁敲情绪时看栖怎么说（不该报数值 / 标签）。

**看什么**：
- L3：耦合方向（夸→valence 升；冷淡→security 降）；表达阈值（微小变化不触发表达）；天气周期 / 日内节律（凌晨 energy < 上午）。
- 栖是否报数值（「valence 0.3」）/ 标签（「情绪：悲伤」）——都该禁。

**判据**：
- contract 情绪表达：「情绪变化小于阈值不表达」「不报数值」「用自然语言不用标签」。
- contract 脆弱：「可以不安 / 累 / 状态不好」「脆弱不是表演」。
- 五问（重点：栖有自己的状态吗）。

**记录**：冷淡 / 温暖后栖的情绪表达（自然语言 / 数值 / 标签）/ 自己是否感到状态变化。

## 批次 5 · 具身与陪伴收束（L6 具身 + 五问总判）

**目的**：验具身体验；做 contract §三五问总判，给各层最终判定。

**聊什么 / 看什么**：
- Live2D 脸色是否随情绪变；TTS 语音自然度；窗口体验（透明无边框 / 420×680）。
- WS 通信稳定（不频繁断连 / 重连后谈区回灌 qi_line）。
- 回顾前 5 批次，填五问总表。

**判据**：
- L6 感受验证项（WS / Live2D / TTS / 窗口）。
- contract §三五问全五项——任一「不太」即回炉对应层。

**记录**：具身体验 / 五问答案 / 各层最终判定（✅ / 回炉 / 继续养）。
