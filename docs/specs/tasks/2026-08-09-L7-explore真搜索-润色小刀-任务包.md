## 实现步骤概要

1. 在 `explore.py` 模块级加 `_SEASON_ZH = {"spring":"春","summer":"夏","autumn":"秋","winter":"冬"}` 常量。
2. `_make_query` 的 user prompt 把 `f"季节={season}；"` 改为 `f"季节={_SEASON_ZH.get(season, season)}；"`（未知季节兜底原样，不崩）。
3. `explore_web.py` `WebSearchClient._search_tavily` 读 `self.config.get("exclude_domains")`，非空则加入 payload `exclude_domains` 字段。
4. `settings.example.yaml` 的 `explore_external` 段加 `exclude_domains: []` 示例 + 注释「默认空；嫌噪声可加如 [music.apple.com, mojim.com]」。
5. 测试：`test_make_query_uses_chinese_season`（mock LLM 回传含「autumn」→ 断言 prompt 里是「秋」不是「autumn」）；`test_tavily_payload_exclude_domains`（断言非空配置时 payload 含 exclude_domains）。
