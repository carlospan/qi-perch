## Spec（外部行为）

1. **第一次打开：先看见她在场**（存在页/微动），不强制先进设置或长向导。  
2. **无 key 时**：相处页一条**可关闭的轻提示条**（人话 + 去设置）；不挡看她、不多步向导。  
   - 无 key 即显示；用户关掉后**本会话**不再出；保存出 key 后自动消失；再开应用若仍无 key 可再出现。  
3. **卡点再问（缺钥匙发话）**：**前端先拦，不发出去**；人话提示 + 去设置；不进待办队列、不当她已收到。后端 `missing_key` 仍可作兜底。  
4. **不含**：安装包、多步 wizard、数据目录、导出、VRM、盘符、免费云脑、完整领养手册整页（手册可另刀）。
