## Spec（外部行为）

1. **用户可观测行为 Phase 1 不变**：open / look / disk / write / together / assist / delegate / irreversible 的触发顺序、白话入口、判断制与既有测试保持一致。
2. **架构方向（多阶段）**：
   - 每拍用户消息先形成 **`TurnUnderstanding`**（处境弱信号 + 关系调制 + perception 评估），再决定响应式路由或对话路径。
   - **`bonded` 等为横切调制**，禁止为单场景（如「还没睡」）叠专用 regex 路由包。
   - **冻结** `intention.py` 新增场景 regex；新需求走 perception 槽位 + 表达调制或 LLM 判别。
3. **Phase 1 交付**：模块落位 + 路由搬迁 + 建卡 extras 注入；**不**在本阶段合并全部粘性状态、**不**重写 `intention.py`。
4. **懂意思**：验收须含跨场景白话用例（见下），不得仅靠口令表。
