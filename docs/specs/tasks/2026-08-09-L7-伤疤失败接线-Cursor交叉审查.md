## 核对清单

### 1. R1：ActionLayer 是否持有 relationship / trust

| 项 | 事实 |
|----|------|
| `ActionLayer.__init__` | 仅 `db, config, narrative, llm`（`layer.py` L54–77）——**无** `_relationship` |
| brain 构造 | `ActionLayer(db, self.config, narrative=..., llm=...)`（`brain.py` L1160–1162）——**未注入** relationship |
| tick / execute_kind | 已接 `relationship_stage: str`，**无** `trust` 参 |

**结论（须写进 PR，非「编码时再猜」）**：HITL3 选 **(b) brain 传参**。  
- `tick` / `execute_kind` 加 `trust: float | None = None`（或必传 float，默认 0.5）。  
- brain 两处调用传 `trust=float(self.relationship.state.trust)`（`relationship is None` 时降级 0.5）。  
- `_maybe_save_scar` 用入参 `trust`，**不要**读 `self._relationship`（该属性不存在）。  
- **不要**为本包给 ActionLayer 挂 relationship 引用（扩耦合、非最小）。

## 必须整改（阻塞编码）

### B1. `result` 无 `outcome` 键——接线按 PR 会永远不触发

**现状**（抽查 return dict）：

| 行动 | return 含 outcome？ | outcome 去向 |
|------|---------------------|--------------|
| `share` | ✗（`type/creation_id/.../action_id`） | 仅 `insert_action(..., outcome=SUCCESS)` |
| `tend` | ✗ | 同上 |
| `explore.drift` | ✗（`type/found/summary/action_id/...`） | 同上 |
| `self_ops` | ✗ | 同上 |

**PR**：`_maybe_save_scar` 读 `result.get("outcome")` → 现网路径恒为 `None` → `outcome_creates_scar` 永不 True。  
方案 A「测试构造 outcome」若只 mock 整段 result 可过测，但 **assist 落地若只把 outcome 写入 DB、不写入 return dict，生产仍不通**——骨架语义未完成。

**须选一写入 PR（倾向 a）**：

| 选项 | 做法 | 评价 |
|------|------|------|
| **(a)** | 约定：凡可形成伤疤的行动，**return dict 必须带 `outcome`**；本包 layer 只读该键；测试构造带 outcome 的 result；任务包/PR 明文「assist 等触发源须在 result 带 outcome」 | 最小、与「只接骨架」一致 |
| (b) | layer 用 `result["action_id"]` 回查 DB 取 outcome | 多一次读、依赖 insert 已提交；可做但不必要 |
| (c) | 本包顺手给现有 action return 补 `outcome` 字段（仍 SUCCESS） | 扩 scope；可选非阻塞润色，不替代 (a) 约定 |

**裁定建议**：选 **(a)**。单测 mock `explore.drift` / 或直接调 `_maybe_save_scar` 时 result 带 outcome；PR 验收条加一句「result 缺 outcome → 不建疤（显式）」。

### B2. trust 接线伪代码与现码不符（R1 关闭方式）

PR `_maybe_save_scar` 写：

```python
if self._relationship is not None:
    trust_before = float(getattr(self._relationship.state, "trust", 0.5) or 0.5)
```

**现码无 `self._relationship`**。若编码照抄 → AttributeError 进 except → 恒降级 0.5（静默），或需先加挂载（偏离 A 最小面）。

**修订**：按上文核对清单 §1——brain 传 `trust`，layer 签名接参，`_maybe_save_scar(..., trust: float = 0.5)`。B2 与 HITL3 合并关闭。
