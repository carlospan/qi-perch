## B1 关闭：压力调制移到 force 之前

**核实**：[layer.py L311-319](file:///d:/qi-perch/qi/action/layer.py#L311) `execute_kind`（GWS 仲裁后执行）调 drift 时 `force=True`；[layer.py L248-255](file:///d:/qi-perch/qi/action/layer.py#L248) `tick`（legacy 路径）调 drift 不传 force（默认 False）。真机默认 GWS 启用，drift 走 `force=True`，PR 原写法（调制在 `if not force:` 内）GWS 路径完全跳过。

**裁定：选 (a) 执行前仍过软门**——理由：压力调制的语义是「累的时候少走神」，这个判断应在「是否走神」那一刻生效，而非「走神后是否执行」。GWS 仲裁选了 explore 候选 ≠ 必须每拍都飘出去；执行时仍应过压力软门（只是不归零，保留 contemplative drift 本质）。

**修订回写**（PR 方案 §3 `explore.py drift` 触发概率段）：

```python
# 原伪代码（错——force 路径跳过调制）
if not force:
    if curiosity < 0.65:
        return None
    warmth = max(0.0, (curiosity - 0.65) / 0.35)
    p = self.base_probability * max(0.0, season_scale) * (0.4 + 0.6 * warmth)
    if pressure is not None:
        p *= (1.0 - PRESSURE_THROTTLE_K * throttle)
        p *= (1.0 - PRESSURE_REST_K * rest)
    if random.random() > p:
        return None

# 改为：压力调制移出 if not force（curiosity 硬阈 + 时机随机仍在 force 分支内）
# force=True 时：跳过 curiosity 硬阈 + 时机随机，但仍过压力软门（不归零，只降概率）
# force=False 时：curiosity 硬阈 + 时机随机 + 压力软门（原逻辑）

if curiosity < 0.65 and not force:
    return None

if not force:
    warmth = max(0.0, (curiosity - 0.65) / 0.35)
    p = self.base_probability * max(0.0, season_scale) * (0.4 + 0.6 * warmth)
    if pressure is not None:
        throttle = max(0.0, min(1.0, float(getattr(pressure, "throttle", 0.0))))
        rest = max(0.0, min(1.0, float(getattr(pressure, "rest", 0.0))))
        p *= (1.0 - PRESSURE_THROTTLE_K * throttle)
        p *= (1.0 - PRESSURE_REST_K * rest)
    if random.random() > p:
        return None
else:
    # force=True（GWS 执行）：仍过压力软门，但概率下限不归零
    # 压力极高（throttle=1, rest=1）时仍保留 (1-0.5)*(1-0.6)=0.2 的飘出概率
    if pressure is not None:
        throttle = max(0.0, min(1.0, float(getattr(pressure, "throttle", 0.0))))
        rest = max(0.0, min(1.0, float(getattr(pressure, "rest", 0.0))))
        p_force = (1.0 - PRESSURE_THROTTLE_K * throttle) * (1.0 - PRESSURE_REST_K * rest)
        if random.random() > p_force:
            return None
    # pressure=None 或软门通过 → 继续 drift（原 force 行为）
```

> 注：force 路径软门下限 `p_force = (1-0.5*1)*(1-0.6*1) = 0.2`，即压力最高时仍有 20% 飘出概率——保留 contemplative drift 本质（累到极致也可能走神），非硬门控。

B1 已关闭。

    ...,
    pressure: "PressureResponse | None" = None,  # N3 新参
