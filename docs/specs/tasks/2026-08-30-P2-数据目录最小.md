## Spec（外部行为）

1. **默认数据根**：平台标准用户目录（Windows：`%LOCALAPPDATA%/Qi/`；macOS：`~/Library/Application Support/Qi`；Linux：`$XDG_DATA_HOME/Qi` 或 `~/.local/share/Qi`）。**不**默认写在安装包/程序目录旁。  
2. **本刀不做自定义路径 UI**：改目录 / 迁移界面另包。  
3. **解析优先级**：`QI_DATA_DIR`（若设）→ 旧仓/开发 `PROJECT_ROOT/data/`（见下）→ 平台默认。  
   - 旧仓判定：`PROJECT_ROOT/data` 为目录，且（仓库有 `pyproject.toml`，或目录内已有运行产物标记：`qi.db` / `user_secrets.env` / `chroma` / `settings.yaml` / `checkpoint` / `corpus`）。  
4. **数据根内容（运行态）**：`qi.db`、Chroma、`user_secrets.env`、checkpoint、corpus、models（如 BGE）、用户侧 `settings.yaml`（若有）等。程序自带 example / 灵魂书仍跟安装或仓库。配置里相对路径 `data/...` 锚定到数据根（去掉多余的 `data/` 前缀）。  
5. **打开数据文件夹**：设置页一条入口；后端在本机打开当前数据根。  
6. **不含**：自定义路径 UI、迁移向导、完整导出/删除、P3 安装包、改端口、连接失败排错、默认同目录便携。
