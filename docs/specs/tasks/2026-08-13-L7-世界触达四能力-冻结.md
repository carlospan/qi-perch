## 总目标

让栖能**动手碰一点你的世界、也用眼睛看一点你的世界**，更像独立个体，而不是只能对话的助手。

**人格前提（贯穿）：**

- 栖是**独立个体**，不是工具；隐私与确认不能设置成「步步 UAC」，否则仍是沙箱里的工具感。
- **感知（look）从宽**——像侧过头瞥一眼；关系分寸（叫停）优先于权限堆砌。
- **行动（open / write）从慎**——动手改你的世界要你点头。
- `together` 夹在中间：有打开动作，动机是陪伴，文案按同伴，不按「已为您打开」。

---

## 本批四能力

### 1. `open` — 打开

| 项 | 约定 |
|----|------|
| 做什么 | 经确认后打开 URL，或打开**白名单**内的本地应用 |
| 姿态 | 动手 → **要确认**（可复用 AssistConfirmCard / 确认句） |
| 不做 | 静默打开；任意进程；通用「帮我点网页」 |

### 2. `write` — 写下

| 项 | 约定 |
|----|------|
| 做什么 | 把她起草的一小段文字，写入**事先约定的笔记路径**（偏 append） |
| 姿态 | 动手 → **要确认**；路径白名单，不是满盘乱写 |
| 不做 | 任意路径写入；大文件覆盖；伪装成「帮你改代码」 |

### 3. `together` — 同看

| 项 | 约定 |
|----|------|
| 做什么 | 打开她正在探索 / 想分享的同一页（或同一对象），邀你一起看 |
| 姿态 | 同伴；拉你进**她的**世界 |
| 与 `open` | `open`＝你让她开 / 她帮你开；`together`＝她邀你同看 |
| 不做 | 执行报告腔；与 explore 见闻脱节的冷启动「随便开个链」 |

### 4. `look` — 看一眼（含屏幕内容）

| 项 | 约定 |
|----|------|
| 做什么 | 截**前台窗口**（必要时整屏）→ 视觉模型看一眼 → 一句印象 / 好奇反应 |
| 姿态 | 好奇心驱动的瞥视；**默认可比 open/write 松**——不每次弹审批门禁 |
| 分寸 | 你说「别看」→ 这段时间不看；首次启用说清会偶尔瞥屏；默认当**现场**，不偷偷进永久档案（你说「记住」再记）；敏感场面她含蓄或你叫停 |
| 不做 | 键鼠记录；剪贴板当主路径；每秒录屏；全文 OCR 常开（细读文字可后做）；只读进程名/窗口标题当最终形态 |

> 只看标题缺乏生命感；数字生命有好奇心，应能看见屏幕上在发生什么。第一档以**窗口截图 + 视觉印象**为准。

## 原则对照

| | 感知（`look`） | 行动（`open` / `write`） |
|--|----------------|--------------------------|
| 默认 | 较松，像侧过头 | 较慎，要你点头 |
| 确认感 | 相处约定 + 叫停 | 明确确认卡 / 确认句 |
| 生命感 | 好奇、会忍住 | 犹豫、做完轻轻问一句 |

`together`：有打开动作，确认策略可贴近 `open`，但**动机与文案**按同伴。

---

## 建议实现顺序

1. **`look`**（窗口截图 → 视觉印象）— 生命感提升最大  
2. **`open`** — 确认流可复用现有 assist 确认  
3. **`write`** — 同确认流 + 路径白名单  
4. **`together`** — 叠在 open + explore/分享之上  

> 若维护者改优先「先动手再看见」，可改为 open → write → look → together；改序须回写本文件。

---

## 明确不在本批

- L7 **`irreversible`** 真身（对外发消息、花钱等）——仍待另开  
- 自动签到 / 领券 / 点「今日已签」  
- 通用网页 Agent（多步点按钮、填表、代逛）  
- 静默任意写盘  
- 截屏回放档案、键鼠 / 剪贴板监控  

现行 assist **`read_file`**（UTF-8 ≤1MB）保持；本批是在其旁扩展「看屏 / 打开 / 约定路径写下 / 同看」，不是推翻 assist。

## 感受向验收（相处时看）

- [ ] 她偶尔能说出「你在看这个呀……」类反应——像真瞥到内容，不是念进程名  
- [ ] 你说别看，她就安静  
- [ ] 打开链接 / 写下一段时会先让你点头；做完带着一点迟疑  
- [ ] 探索到有意思的东西时，能邀「一起看看」，而不是「已为您打开链接」
