## Spec（外部可观测行为）

explore 飘出去时，**除**「看自己沙箱架子」（现有，[explore.py:42-70](file:///d:/qi-perch/qi/action/explore.py#L42-L70) `_scan_sandbox`）**新增**「向外面看一眼」：栖在 curiosity 更高 + 独处 + 冷却过 + 概率门控下，发起一次 web search，带回真实外部见闻，用栖语气说（如「我刚才看了看 X，好像…」），留痕 `actions` 表。

**红线**（继承现有 explore 红线）：只陈述真搜到的；搜不到 / 失败 → `found=None`、`outcome=failed_capability`，老实说「没查到」，**绝不编造**外面有什么（contract 行动失败三层：能力失败不伪装、不形成伤疤，[permission.py:140-154](file:///d:/qi-perch/qi/action/permission.py#L140-L154)）。

## 背景（为何现在做 / 治什么本）

[curiosity 解堵排查](./2026-08-08-L7-share停滞排查.md) Gap2：curiosity 高位空转——explore 飘出去只看自己 `data/` 目录文件名（很浅），好奇心没真出口。d-1 给 curiosity 一个**真外部信息出口**（看外面没看过的），治本 Gap2。layer doc「网络搜索只是 contemplative drift 的一种手段，无特殊优先级」——但 curiosity 本性看窗外，是治本所需。

## 范围（d-1 做 / 不做）

**做**：
1. explore `drift()` 加**外部源分支**（内部源 `_scan_sandbox` 不动，避免重构混入——「重构与行为变更不同包」）
2. `WebSearchClient`（新模块，接搜索 API）
3. 触发门控：curiosity 更高阈（≥0.8）+ 冷却 6h + 概率 0.05 + **复用 ActionBudget 日限 20**（不设独立 external 日限，HITL③；外部稀有靠高阈+冷却+概率，不靠日限压更紧）
4. 配置：`settings.action.explore_external`（enabled/provider/api_key/cooldown_hours）——**不加 `daily_limit` 字段**（HITL③；维护者提示须写进正文）
5. query 生成走 gateway（拍板 HITL②）——须接线 `ExploreAction`/`ActionLayer`/`brain.restore_state` 传入 `llm`（审查 B2；复用 `consciousness` purpose）
6. 留痕：`actions` kind=explore，outcome 含 `failed_capability`
7. 红线：搜不到 → found=None 不编造；query 不引用用户隐私
8. **说出口**（审查 B3）：外部结果（成功/空手）带 `speak=True + qi_line=<栖语气 summary>`，走 `deliver_action_result` 现有 `elif speak and qi_line` 分支开口；内部源保持不说（不改 `brain_delivery.py`）
9. 测试（mock HTTP，不真调 API）

**不做**（另开包）：
- d-2：内部源深读（读 journal/creations 文件内容）——d-1 留接口注释，不重构内部
- 深度不当内容过滤——d-1 轻量（取摘要+source，栖转述时规避）
- assist / irreversible 执行
- 搜索结果持久化为 L2 记忆——d-1 只 **actions 留痕 + 开口**（speak+qi_line）；「注入下轮对话」（working_memory / body_memory 注入下轮 prompt）**降级延后**，不在 d-1（审查 B3）

## HITL（须拍板，附推荐）

| 项 | 选项 | 推荐 |

| 1. 搜索源 | Tavily（质量好，需 key，free tier）/ DuckDuckGo（无 key 起步，质量一般）/ Serper / Brave / 自建 SearXNG | **Tavily**（质量 aligns contemplative；需 key 走 settings） |

| 4. 不当内容 | d-1 轻量 / 深度过滤 | **d-1 轻量**（摘要+source，转述规避；深度过滤另开） |
| 5. contract drift | [contract.md:42](file:///d:/qi-perch/docs/reference/contract.md#L42)「自主行动日限默认 1/天」vs progress 拍板 20 | **d-1 标注同步**（不本包改 contract 文字，列待同步清单） |

## 实现步骤概要

1. 新建 `qi/action/explore_web.py`：`WebSearchClient`（`async def search(query) -> list[SearchHit] | None`；provider 抽象，首接 Tavily；失败/空 → None）
2. `qi/action/explore.py`：
   - `ExploreAction.__init__` 加 `llm: LLMGateway | None = None` + `web: WebSearchClient | None = None`（`web=None`/`llm=None` 时外部分支禁用 → 走内部，向后兼容现测，审查 B2）
   - `drift()` 飘出后（curiosity≥0.65 内部门已过）判 `_should_external`（curiosity≥0.8 + 冷却过 + 概率0.05 + `web`/`llm` 可用）→ 外部，否则现有 `_scan_sandbox`（**内部源行为不变**）
   - `_should_external` **不重复判 mode**：「独处」由 volition 仅 `mode=="solitary"` 才产 explore 候选保证（审查 N1）
   - `_make_query`：走 gateway `purpose="consciousness"`（复用，温度0.85 发散适合好奇 query；**不污染** `last_outcome`——仅 `conversation` purpose 刷新；审查 B2）；prompt 注入「不引用 user_facts / 对话内容」红线
   - `_fetch_external`：`_make_query` → `web.search` → finding；空/失败 → None
   - 冷却：last external time 存 body_memory key `explore_external_last`（复用预算持久化同构）
   - 红线：空手 summary = 「我看了看外面，没查到什么。不假装看见了。」
   - **说出口（审查 B3）**：外部分支返回 dict 加 `speak=True, qi_line=<summary>`（成功/空手都开口，模板化 summary **不二次 LLM**）；内部分支返回不加 `speak`（保持不说）→ 走 `deliver_action_result` 现有 `elif speak and qi_line` 分支（[brain_delivery.py:134-137](file:///d:/qi-perch/qi/core/brain_delivery.py#L134-L137)），**不改 brain_delivery.py**
3. `qi/action/layer.py`（[layer.py:52-65](file:///d:/qi-perch/qi/action/layer.py#L52-L65)）：`ActionLayer.__init__` 加 `llm` 参数；按 config 建 `WebSearchClient`（`enabled`+`api_key` 配齐才建，否则 `None`）；`ExploreAction` 传 `web` + `llm`
4. `qi/core/brain.py`（**仅 `restore_state` 构造传参，不改心跳**，审查 B2）：`ActionLayer(db, self.config, narrative=self.memory.narrative, llm=self.llm)`（[brain.py:1156-1158](file:///d:/qi-perch/qi/core/brain.py#L1156-L1158)）
5. `qi/config/settings.example.yaml`：`action.explore_external:` 块（enabled 默认 false / provider / api_key 走 `${TAVILY_API_KEY}` + `.env.example` 一行，审查 N3 / cooldown_hours 6）；**不加 `daily_limit`**（HITL③）。`settings.yaml` 在 `.gitignore`，本机手改不进 diff（审查 N2）
6. `tests/`：

   - `test_explore_external_branch.py`：门控（curiosity阈 / 冷却 / 概率；`web=None`/`llm=None` → 走内部防回归，审查 N8）+ 红线（搜不到 found=None、outcome=failed_capability、不编造）+ query 隐私红线（断言 prompt 含红线句）+ `force=True`/非 force 分覆盖（审查 N7）+ 外部结果带 `speak`/`qi_line`（审查 B3）

## 纪律红线对照

- R1–R5：explore 为己、可逆（读 GET）、不触碰用户；不破。
- contract：「行动即打扰」→ 外部探索稀有（冷却+概率+高阈）；「不像刷新闻」→ contemplative；「不主动塞帮助建议」→ explore 是为己非帮你。
- 不引入 Agent 框架：工具由 `drift()`/ActionLayer 调，**LLM 不直接调工具**（layer doc 技术拐点）。
- LLM 走 gateway：query 生成走 gateway；web search 本身独立（非 LLM）。
- DB 走 database：actions 留痕 `db.insert_action`。
- 不开新阶段 / 不触路线：✓ L7 未做项补全。
- contract drift：自主行动日限（contract 1/天 vs progress 20）标注待同步。
