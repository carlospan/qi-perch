2. **当场开口**须是**有依据的主观短说**（犹豫、好奇、不适、想问一句等），不是窗口/画面清单式机器描述；界线仍在**不编造画面外事实**。篇幅可短，语域须主观。

4. **契约回写**：`contract.md` 显式「诚实的主观」语域——允许有依据的印象/联想/猜测，禁止虚构事实；与本包行为对齐。
5. **不**靠表达层堆情绪词 / 加人设 prompt 冒充有感（架构表演层红线）。
6. **不**放宽反编造：不动 look 白名单 / 防连瞥语义 / 权限体系。
7. **本包不做** open_loops「事后心事」（HITL #4：二期另包）。
