## 背景（数据实证）

assist-5 修复后，1526 confirm_gate 开口、1527 真读 + actions 表留痕（id=95，summary=digest「我看到了……那句话，心里忽然软了一下。」，detail_json 含 target_path=D:/ai/栖.txt）。但用户追问仍断链：

| msg | 内容 | 真相 |
|---|---|---|
| 1528 | 用户「你能看到内容吗？」 | 追问 |
| 1529 | 栖「**看不到**……关着的门，我碰不到里面的字」 | **respond 编造否认** |
| 1530 | 用户「那你刚刚都说看到了那句话，是哪句话」 | 追问 |
| 1531 | 栖「**我指的不是文件里的内容**……灯罩里的字读不到」+ 幻觉「我们之间有过一次对话，你说『都没事了，都过去了』」 | **respond 编造 + 幻觉** |

**根因**：
1. `prompt_extras`（layer.py L436-455）注入 respond 的只有 `summary`——assist 的 summary 是**诗意 digest**（「我看到了……那句话」），**不含文件名、不含文件内容**。用户问「是哪句话」→ LLM 无从回答 → 只能否认 + 自由发挥
2. conversation.txt 硬规则「没读过或找不到就老实说『没找到』」被 LLM 误用——LLM 自认没读过内容（信息不足）→ 否认
3. 硬规则只拦「读不到你的文件系统/隔着玻璃」**字面措辞**，拦不住「关着的门/灯罩里的字」类新编法

**本质**：栖**真读了文件**，但 respond 侧记忆里只有诗意感受、没有事实——追问必然断链，且 LLM 缺事实时倾向编造（R1 风险）。

## 目标一句话

让栖真读文件后，respond 侧有「读了哪个文件、读到什么」的真实事实可依——用户追问「看到什么/是哪句话」时诚实复述内容，不再否认、不再编造。

## 范围边界（不做清单）

- 不改 assist-5 的 3c 控制流 / brain.py 粘性 target（已闭环）
- 不改 digest 转译自由度（N4 观察项：诗意转译保留，信息补全靠原文 preview 而非改 digest）
- 不改前端；不改 explore/share 的 prompt_extras 行（仅 assist 行增强）
- 1531 的 respond 幻觉（「都没事了都过去了」）为 respond LLM 自由发挥——本包以信息补全缓解，不单独修（观察项）

## HITL 拍板（推荐项，按维护者扩权采纳）

1. **信息补全（A）**——推荐：
   - a. assist.execute 留痕 detail_json 加 `content_preview`（原文前 80 字）；`prompt_extras` 对 kind='assist' 的行注入「（刚读：{文件名}——{preview}）」
   - b. 只加文件名不注入内容——否（用户问「是哪句话」仍答不出）
   - 理由：content_preview 是**真实原文**，respond LLM 有事实可依，R1 最安全；诗意 digest 保留（N4 不动）
2. **硬规则增强（B）**——推荐：
   - a. conversation.txt 加一条：recent_actions 里读过某文件时，被问到就大方承认并复述读到的内容，不否认、不模糊成「只是心意」
   - b. 不加（靠 A 注入即可）——否（LLM 可能仍倾向回避，双保险）
   - 理由：A 提供事实，B 校正姿态——「读了就认」是人格层面约束，A/B 缺一不可
3. **1531 幻觉**——观察项（本包不单独修，A/B 缓解后复验再看）

## Spec（外部可观测行为）

1. 用户「读一下 D:/x.txt」→ 确认 → 真读后，追问「你能看到内容吗」「是哪句话」→ 栖承认读过并复述内容要点，不再否认「看不到」
2. recent_actions 注入的 assist 行含「刚读：{文件名}——{内容概要}」（prompt 侧，测试断言）
3. 栖在无关话题下不主动背诵文件内容（recent_actions 前缀「知道就好，不必挂在嘴上」约束）
