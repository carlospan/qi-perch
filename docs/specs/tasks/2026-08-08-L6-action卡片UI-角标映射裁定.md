# L6 · action 卡片 UI——角标映射裁定

> 裁定方：方案 Agent（Trae）
> 触发：Cursor 编码侧发现 `ActionCard.vue` 的 `TYPE_LABEL` 与后端 `_infer_type` 实际产出码不一致，请求裁定。
> 依据：[creativity.py](file:///d:/qi-perch/qi/inner_life/creativity.py#L64-L72) `_infer_type` + PR 方案 §D「类型标兜底省略」。

---

## 一、现状核实（已读后端，非转述）

`qi/inner_life/creativity.py::_infer_type` 实际只产出四码：

| 码 | 触发条件 |
|----|----------|
| `poem` | 有换行且 < 120 字 |
| `essay` | > 200 字 |
| `description` | 含「看见 / 画面 / 颜色 / 光」 |
| `note` | 默认 |

`ActionCard.vue` 现行 `TYPE_LABEL`：`note→笔记`、`poem/prose/story→写`、`journal→笔记`。
- **有、后端不产**：`prose` / `story` / `journal`（死映射）。
- **后端会产、映射缺**：`essay` / `description`（会走兜底 → 长度 ≤6 时原样显示英文，泄漏进中文 UI）。

## 二、裁定

**保持粗粒度（「写」vs「笔记」），不扩 scope，本包内修正，不开新包。**

理由：PR 方案 §D 已定「类型标（`creation_type` 有意义才显示，如「写」「笔记」；无意义则省略）」——角标是极小暗示，非分类体系；细角标（诗 / 随笔 / 画面）属 UI 口径变更，应另开包，本包不做。

### 精确映射（Cursor 据此改 `TYPE_LABEL`）

```typescript
const TYPE_LABEL: Record<string, string> = {
  note: "笔记",
  poem: "写",
  essay: "写",
  description: "写",
};
```

- 删除死映射 `prose` / `story` / `journal`。
- `essay` / `description` 归入「写」（与 `poem` 同粗粒度，符合方案）。

### 兜底收紧（顺带修正，对齐方案「兜底省略」）

```typescript
const typeLabel = computed(() => {
  const t = (props.card.creation_type || "").trim().toLowerCase();
  if (!t || t === "unknown") return "";
  return TYPE_LABEL[t] || "";   // 未知码一律省略，不原样显示英文
});
```

现行 `t.length <= 6 ? t : ""` 会让未知英文码泄漏进中文 UI——与方案「兜底省略」相悖，改为一律省略。

## 三、scope 与流程

- **本包内修正**（correctness：死映射 + 英文泄漏），非行为 / 架构变更，**不开新包、不扩 scope**。
- 细角标（诗 / 随笔 / 画面 …）若维护者想要 → **另开包**（动 UI 口径，需重新定标与相处验证）。
- 此为实施验收后发现的角标偏差：验收记录「无实质偏离」一语在此点**收回**。Cursor 改完，方案 Agent 仅复核 `ActionCard.vue` + 重跑 `npm run build` / `vue-tsc --noEmit`（不必全量重测），通过即更新验收记录。
