## B1 关闭：assist 在 awake 放行

**核实**：[layer.py L318-320](file:///d:/qi-perch/qi/action/layer.py#L318) `if mode == "awake": if kind not in _AWAKE_SELF_OPS: return None`。`_AWAKE_SELF_OPS` 是 archive/journal/budget_tune（自反操作）；assist 不在内 → awake 对话期 assist 恒 None。

但 assist 是**响应式协助**（用户开口请求），**awake 对话期是主要场景**——用户说「帮我看一下 X」时 mode=awake，若被门控堵死则 assist 永远无法触发。

**裁定**：assist 加入 awake 放行白名单。不直接塞 `_AWAKE_SELF_OPS`（语义不同——self_ops 是自反，assist 是响应式用户请求），而是改门控逻辑：

**修订回写**（PR 方案 §3 layer execute_kind 门控）：

```python
# 现 L318-320
if mode == "awake":
    if kind not in _AWAKE_SELF_OPS:
        return None

# 改为：awake 放行 self_ops + assist（响应式）
if mode == "awake":
    if kind not in _AWAKE_SELF_OPS and kind != "assist":
        return None
```

> 注：assist 在 awake 放行，但仍在 solitary/ambient 也放行（assist 不限 mode，只看用户请求 + permission）。dreaming/离线仍拦。

B1 已关闭。

## B2 关闭：assist 跳过 can_autonomous 总闸

**核实**：[layer.py L323-324](file:///d:/qi-perch/qi/action/layer.py#L323) `if not self.budget.can_autonomous(now): return None`。assist 响应式不占预算（budget.py L13/68 注释 + 本包不调 `budget.record`），但走 can_autonomous 总闸 → 日限满时 assist 进不去，与「不占预算」语义冲突。

**裁定**：assist 跳过 can_autonomous 总闸。

**修订回写**（PR 方案 §3 layer execute_kind 总闸）：

```python
# 现 L323-324
if not self.budget.can_autonomous(now):
    return None

# 改为：assist 响应式不占预算，跳过自主日限总闸
if kind != "assist" and not self.budget.can_autonomous(now):
    return None
```

> 注：assist 跳过总闸后，仍受 permission（friend+ 需确认）+ 伤疤阻断 + 用户请求触发（volition 候选桩）三层保护，不会失控。

B2 已关闭。
