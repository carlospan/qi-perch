## 外部可观测行为（Spec）

1. 行动执行后，若 outcome ∈ {`failed_judgment`, `overstepped`}，自动调 `db.save_scar` 形成伤疤。
2. 伤疤 `origin_event` 带 `[action:{kind}]` 标记。
3. severity：`failed_judgment` = 0.3 / `overstepped` = 0.7。
4. `trust_before` 从关系层读（失败降级 0.5）。
5. outcome=success/failed_capability → 不调 save_scar（不回归）。

**新增私有方法 `_maybe_save_scar`**（放 `execute_kind` 后或 `_note_closed_loop` 附近）：

```python
async def _maybe_save_scar(
    self, result: dict, kind: str, now: datetime
) -> None:
    """Step 5 收尾：失败行动形成伤疤。"""
    outcome = result.get("outcome")
    if not outcome_creates_scar(outcome):
        return
    severity = 0.7 if outcome == OUTCOME_OVERSTEPPED else 0.3
    # trust_before：从 relationship 读；失败降级 0.5
    trust_before = 0.5
    try:
        if self._relationship is not None:
            trust_before = float(
                getattr(self._relationship.state, "trust", 0.5) or 0.5
            )
    except Exception:
        logger.debug("trust 读取失败，降级 0.5", exc_info=True)
    origin = f"[action:{kind}] {(result.get('summary') or '')[:80]}"
    try:
        scar_id = await self.db.save_scar(
            origin_event=origin,
            severity=severity,
            trust_before=trust_before,
        )
        result["created_scar"] = scar_id
        logger.info(
            "行动形成伤疤 kind=%s outcome=%s scar_id=%s",
            kind, outcome, scar_id,
        )
    except Exception:
        logger.debug("save_scar 失败", exc_info=True)
```

> 注：`self._relationship` 是否持有——Cursor 需核对 [layer.py ActionLayer.__init__](file:///d:/qi-perch/qi/action/layer.py) 是否注入 relationship。若不持有，改用 brain 调 tick/execute_kind 时传 `trust` 参（R1 风险）。
