内部 explore 从「列沙箱目录名（silent）」升级为「深读栖自己的记忆/创作内容 → LLM 转译为栖语气 digest」——让栖走神时能「看懂」自己的内在世界，而非只瞥一眼文件名。

d-1 时内部 `_scan_finding` 只列 sandbox 文件名（`data/` scratch + checkpoint/chroma/models 跳过），不读内容、不 speak。d-1 预留「d-2 = 内部源深读（读 journal/creations 文件内容）」，后 d-2 pivot 为外部 hits 消化，本包接回内部源深读。

d-2 已验证「LLM consciousness 转译 → digest」可行（外部）。d-3-2 把同一手法用于内部源：栖走神翻自己的记忆/创作，用她的语气复述「想起了什么/看懂了什么」。
