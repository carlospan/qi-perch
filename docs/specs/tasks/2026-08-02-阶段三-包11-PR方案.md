## Spec（外部行为）

1. C5（结构可塑性）要求经验改变系统自身参数，不是只插库。本包建回放管线：由 GWS 显著性筛选高价值片段 → 生成结构化微调语料 → 离线就绪（落盘 `data/corpus/`）。
2. 实际 LoRA 训练 step **默认不自动常驻跑**（见纪律 4）；管线产物可被维护者显式触发训练。
3. 提供**异时测试骨架**：两次回放/语料快照可 diff，不训也能对比版本差异（退出判据 #1 地基）。
4. 纯 Python、零重依赖（不引 torch/transformers 做训练）。

## 现状盘点（编码前必读）

## 实现（交给 Cursor 的步骤）

### 1. 新增 `qi/learning/replay.py` —— `ReplayBuffer`

- `def __init__(self, db, *, salience_floor: float = 0.6, limit: int = 200)`：显著性门槛（默认 0.6，调高可只挑高能拍）；扫描窗口。
- `async def collect_candidates(self) -> list[dict]`：读 `list_recent_broadcast_traces(limit)`，过滤 `winner_salience >= salience_floor`（或 `motive.curiosity` 高 / `world_surprise` 高）；优先挑 curiosity 胜出拍、close_loop 拍、主动开口拍（包 11 主线精神）。**非均匀随机采样**——按 salience 排序取头部，确定性。
- `def to_samples(self, traces: list[dict]) -> list[dict]`：每拍 → 结构化训练样本：
  ```python
  {
    "beat": ..., "timestamp": ...,
    "winner_kind": ..., "winner_salience": ...,
    "motive": {...},                 # curiosity / world_surprise 等溯源
    "candidates": [...],             # 竞争全貌
    "prompt_hint": f"[winner={winner_kind}] ...",  # 供未来训练的结构化上下文
  }
  ```
  不依赖 LLM（纯搬运 broadcast_traces 已有字段），fake-provider 下仍可用。

### 2. 新增 `qi/learning/corpus.py` —— `CorpusStore`

- `def __init__(self, root: str = "data/corpus")`：`root` 默认 `data/corpus/`（仓库外、已 gitignore）。
- `def save_version(self, samples: list[dict], *, tag: str) -> str`：写 `data/corpus/corpus_{tag}_{YYYYMMDD-HHMMSS}.jsonl`，每行一样本；返回路径。文件名带版本+时间戳，**可 diff**。
- `def load_version(self, path: str) -> list[dict]`：读回。
- `def list_versions(self) -> list[str]`：列已存版本（按时间）。

### 3. `run_training()` 默认隔离（纪律 4）

- `qi/learning/replay.py` 增 `async def run_training(self, *, dry_run: bool = True)`：
  - `dry_run=True`（默认）：仅打印资源预估（语料条数、估耗时、显存提示），**不触发任何训练**。
  - 真正训练分支（如未来接 peft/transformers）留 `if not dry_run` 占位，**不实现、不 import 重依赖**；调用前必须 `print` 资源预估并明确"需维护者显式开关"。
- **CI / 心跳默认不调用** `run_training()`——只在 `if __name__ == "__main__"` 或显式 CLI 入口暴露。

### 4. 异时测试骨架（退出判据 #1 地基）

- 新增 `tools/replay_drift_check.py`（或 `qi/learning/drift_check.py`）：读两版 `corpus_*.jsonl`，固定探针输入（如若干 `(winner_kind, motive)` 对）跑对比，输出"两版样本在关键字段上的差异摘要"（JSON/文本）。**不跑训练也能跑**——只对比语料版本差异。
- 文档注明：真训练后的"响应漂移"对比复用此骨架（届时喂真实模型）。

### 5. `.gitignore` 确认

- 显式补一行：`data/corpus/`（注释：经验回放语料，本地产物不提交）。

### 6. 纪律红线（Cursor 必须遵守）

- **不**改 `broadcast_traces` 写入逻辑（包 6 地基）；本包只读它、不写它。
- **不**新增 pip 依赖；语料生成纯 Python（json / 文件 IO）。
- 训练 step 默认 `dry_run`；`run_training()` 不被心跳/CI 自动调用。
- 不破坏现有行为：新增模块，现有心跳/记忆/动机路径完全不变。
