## Spec（外部行为）

1. **失败走系统态，不走她的 speech**：缺 key / 模型不可达 / 空结果 / 前端等待超时，用系统提示告知用户；不把运维话塞进栖的气泡；不单用「……」冒充沉默。
2. **失败分级文案**（固定短句，可后续润色）：
   - 缺 key → 还没有可用的模型钥匙 + 请检查 API 密钥配置  
   - 不可达 → 这会儿连不上模型 + 可再试 / 查网络或配置  
   - empty → 这轮没接好 + 可再发一句  
   - 超时解锁 → 等太久了，先解开输入  
3. **typing/busy 约 60 秒**无结束则强制解锁；可出超时系统态；迟到的 speech 仍可显示。
4. **对话路径**：`unreachable` / `missing_key` 不交付 speech；`empty` 在非催答时不交付 speech（催答空仍可用催答模板，保留既有催答包）。
5. **不做（本包）**：流式/口型/TTS、发送 ACK、队列满告知、撤回/改信、设置页本体（文案可提配置，按钮可预留）。
