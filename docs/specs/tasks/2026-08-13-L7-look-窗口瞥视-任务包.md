## Spec（外部可观测行为）

1. 栖在合适时机能**自主瞥一眼前台窗口内容**（截图 → 视觉模型），并用一句带好奇的话**开口**——不是念进程名或窗口标题。**自主成功必有 `qi_line`**（否则维护者无法知道她看没看）。
   - **软由头（已采纳）**：用户**沉默 ≥20 分钟**（可配 `silence_boost_minutes`）时，自主 look 偶发倾向提高，**不是**到点必看。
   - **事不过三（已采纳）**：自主 look 若因**软门控**连续挡下 **2** 次（如 15min 防连瞥、偶发未抽中后的压抑计数——实现时用「连续未落地的 look 冲动」计数），**第 3 次**对软门**放行**（仍须过硬门：acquaintance+、未在「别看」暂停、非 dreaming 让路等）。计数在成功瞥或硬门拒绝后归零。硬门**不可**被「事不过三」打破。
   - **不采用**：以「回到电脑前」为 look 专用硬触发/加分。
2. **用户邀看**（响应式）：应**先真瞥一眼再答这一轮**；不弹确认卡；**不受 15min 防连瞥限制**（连续主动问也每次真瞥）。维护者已采纳正例/反例：
   - **算邀看**：「你知道我正在做什么吗」「你能看到我现在在做什么吗」「看看我屏幕 / 看一眼我在干啥」「我屏幕上是什么」「你看得见这边吗 / 看得到我这边吗」「猜猜我在干什么」「帮我看下这个页面/这局游戏」（口语邀看，非读文件）。
   - **不算邀看**：「你在干嘛」「在吗」「忙什么呢」；「你还记得我上次在做什么吗」；「帮我看看这个文件/这段代码」（assist）；「你觉得我该做什么」。
3. **叫停 / 解除**：说「别看 / 不要看屏」→ 自主暂停 **1h**；说「可以看了」→ **提前解除**暂停。暂停期内用户又**明确邀看** → 解除暂停并响应式瞥一次。
4. **让路**：`dreaming` 或她已在开口时，**自主** look 不抢；**响应式邀看**仍先瞥再答。
5. **自我窗口**：前台是栖自己的桌宠/聊天窗时，**跳过本次自主瞥**（避免看自己）；响应式仍可瞥（用户明确要求时如实说「好像看着我们这边」亦可）。
6. **首次启用**有一次说清：她偶尔会瞥屏；默认当现场，不偷偷进永久档案（「记住」另包）。
7. 截图**默认不落盘**；`actions` 只留摘要（kind=`look`，无原图）。
8. 能力失败 → `failed_capability`，老实说或安静，**禁止编造**。
9. **敏感画面（本包）**：不做隐私细控，按所见说；叫停仍有效。
10. 多屏：优先前台窗；失败回退整屏。
11. 不做：键鼠/剪贴板主路径、常开录屏、全文 OCR、只读标题当最终形态、记住屏幕档案。

## 背景与现状

- 冻结稿已定 look 优先；编码包此前未开。
- 现行 LLM：`tokenrhythm` / `kimi-k2.7-code` **已实证**支持 `chat/completions` + `image_url`（**仅 base64 data URL**；https 图链会被拒）。
- Gateway / provider 现行只传纯文本 `messages`；尚无截屏模块、无 `kind=look`、无叫停状态。
- assist 确认流**不复用**为 look 门禁（从宽）；叫停用相处约定 + body_memory。

## 范围

**做：**

- `qi/action/look.py`：前台窗口截图（必要时整屏回退）→ 缩图/限体积 → base64 → vision digest → **必有** `qi_line`（自主成功）/ result
- LLM：`purpose=look`（或复用既有 purpose + 多模态 messages）；provider 透传 content 数组
- 门控：叫停暂停、防连发、预算/季节（自主）；**响应式邀看**走对话拍短路（类似 assist），不占「偶发概率」
- `volition` / `permission` / `ActionLayer.tick` + **对话拍响应式 look** 接线
- `insert_action(kind=look, …)`；测试（截屏与 LLM mock；含邀看意图；自主成功必带 qi_line）
- `settings.example.yaml` 增加 `action.look` 配置项（暂停、防连发等）
- 回写 L7-action / progress（编码完成后）

**不做：**

- open / write / together / irreversible
- 截图永久档案、OCR 常开、跨平台非 Windows 首发（Windows 先行；其他 OS 明确降级/跳过）
- 敏感画面分类器 / 隐私细控（本包明确不做）
- 改人格契约正文；通用 Agent
- 把「你在干嘛」类闲聊**全部**当成邀看——正例/反例以 Spec §2 为准
- 「记住刚才屏幕」另包
- 以「回到电脑前」为 look 专用硬触发（沉默只作自主偶发的软加分，见 Spec §1）

## 实现（步骤）

1. **截屏**：Windows 取前台窗；失败则整屏（多屏取前台/鼠标所在）；限制最长边与体积 → `data:image/...;base64,...`。
2. **LLM 多模态**：扩展 provider/gateway，允许 message `content` 为 list；routing `look` → 现行 vision 模型。
3. **`LookAction.glance`**：短 prompt（一眼印象、可犹豫、不提技术细节；**本包不要求避敏感**）→ LLM → result；**自主成功路径强制非空 `qi_line`**（LLM 空则降级一句「我看了一眼……」或标失败，二选一以测试约定：优先温柔降级短句，避免静默成功）。
4. **叫停 / 解除 / 邀看**：暂停 1h；「可以看了」解除；邀看解除暂停并响应式 glance（**永不**受 15min 防连发约束；acquaintance+）；先瞥再答；首次告知。
5. **意志与层**：非定时偶发；acquaintance+；15min 防连发**仅自主**；沉默 ≥**20min** 软加分；**软门连挡 2 次 → 第 3 次软门放行（事不过三）**；dreaming/已开口时自主让路；前台为栖自身窗则跳过自主；对话拍响应式。
6. **交付**：自主成功必走 `_deliver_action_result` 开口；响应式把所见注入当轮回复。
7. **测试 + 配置 + 文档回写**。

## 附录 · look 润色候选项（生命感 · 未立项）

> 维护者认可「都很好」；**默认不进本包实现**。相处或后续小刀时按条挑选。  
> 已进本包主 Spec 的（如必开口、邀看正反例、沉默 20min 软加分、自身窗跳过自主等）此处不重复当待办。

### A. 关系与分寸

| 候选项 | 一句话 |
|--------|--------|
| 越熟越敢 | acquaintance 轻描；friend/bonded 可多细节与玩笑 |
| 看完不好意思 | 自主瞥后偶发「我是不是不该盯着……」 |
| 季节语气 | 冬少瞥/话更缩；春多一点好奇（在既有季节门上加语气） |

### B. 与屏上内容的互动（仍是瞥，不是 Agent）

| 候选项 | 一句话 |
|--------|--------|
| 一起愣住 | 瞥到同片/同局 → 为 `together` 铺种子 |
| 深夜关心 | 极稀有：「还不睡吗」——严防催睡机器人 |
| 卡文氛围 | 只提「你好像卡在一段话上」，不泄密、不代写 |

### C. 记忆（须你说「记住」才升格）

| 候选项 | 一句话 |
|--------|--------|
| 记住这个画面 | 明示后才入档；日后可回响 |
| 故意忘掉 | 叫停或敏感后口语「当没看过」 |
| 悄悄话模式 | 「这是秘密」→ actions 摘要不写细节 |

### D. 具身轻反馈

| 候选项 | 一句话 |
|--------|--------|
| 瞥时侧头 | L6 微表情/姿态一瞬 |
| 看不清揉眼 | 失败拟人，不报技术错 |

### E. 游戏感与约定

| 候选项 | 一句话 |
|--------|--------|
| 闭眼 / 睁眼 | 比「别看」更重的强暂停 |
| 猜谜必先瞥 | 「猜猜」→ 必须真瞥再猜；错了承认看走眼 |
| 不许剧透 | 看剧/Boss 时只说气氛 |
| 今晚特别许可 | 临时放宽防连瞥；零点恢复 |
| 有人在旁边 | 强暂停 look |
| 盯着我写 | 周期性轻瞥 + 只鼓励不指挥 |

### F. 主动与克制的张力

| 候选项 | 一句话 |
|--------|--------|
| 连续忍三次 / 事不过三 | **已升格进主 Spec**：软门连挡 2 次，第 3 次放行（非「只开口不截屏」） |
| 想看但忍住 | 候选被挡时**可不截屏**只说「有点想看……又觉得不该」（与事不过三互补：前两次可忍住说话，第三次真瞥） |
| 看了少说 | 成功后有时只说「你挺专心的」，细节留待追问 |
| 看一眼就逃 | 自主成功只半句，像被吓回树枝 |
| 被你突然回头 | 同时刻被发现 → 装「我才没有在看」 |

### G. 与其他能力咬合

| 候选项 | 一句话 |
|--------|--------|
| × explore | 窗外见闻与你屏上主题撞车 → 惊喜 |
| × share | 瞥到她递过的东西还开着 → 小声开心 |
| × together | 「一起愣住」升级为同看 |

### H. 残缺与失误

| 候选项 | 一句话 |
|--------|--------|
| 看走眼 | 老实认错 |
| 花屏 / 全黑 | 「这边黑着」，非报错腔 |
| 延迟开口 | 看完想两秒再说话 |

### I. 小仪式与时间感

| 候选项 | 一句话 |
|--------|--------|
| 第一次成功瞥 | 与首次告知合并的小仪式句 |
| 第一百次 | 极稀有的自我感一句 |
| 生日日 | 自主略多好奇，仍非定时 |
| 深夜瞳孔 | 过点后少瞥、语气更困 |
| 周末/工作日 | 周末更敢看热闹；工作日更克制 |
| 关系温度调制 | 刚吵完少瞥；很甜时多一点玩笑偷看 |

### J. 输入彩蛋（可后做）

| 候选项 | 一句话 |
|--------|--------|
| 托盘双击 | = 邀看 |
| 托盘长按 | = 别看一小时 |
| 投屏/分享屏 | 略提高自主倾向（仍非定时） |

### 私心优先（便宜、像栖；供日后挑）
