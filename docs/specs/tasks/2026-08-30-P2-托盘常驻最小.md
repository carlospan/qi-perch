## Spec（外部行为）

1. **系统托盘**有栖图标（Tauri/安装壳；浏览器 Vite 开发壳无托盘属预期）。  
2. **关主窗** = 隐藏到托盘：不退壳、**不杀后端**。  
3. **左键单击**托盘图标 = 打开/聚焦主窗。  
4. **右键菜单**至少：「打开栖」「退出栖」。  
5. **退出栖**：结束壳；**仅**收掉壳自己拉起的大脑；沿用已在跑的后端则不杀。  
6. **不做**：透明桌宠、`pet.html` 安装入口、气泡通知、开机自启、重启大脑菜单项。

## 验收（判据）

- [x] 关 × → hide + prevent_close；不走 `RunEvent::Exit`（不杀后端）  
- [x] 单击托盘 /「打开栖」→ show + unminimize + focus  
- [x] 「退出栖」→ `app.exit(0)` → Exit 时仅收自拉起大脑（`borrowed` 不杀）  
- [x] 未做桌宠/通知/自启（本刀范围外）  

### 手测口径（维护者）

1. `npm run tauri:dev`（或安装壳）：托盘出现「栖」。  
2. 关主窗 ×：窗口消失，托盘仍在；WS/状态仍可连（自拉起场景）。  
3. 单击托盘或右键「打开栖」：主窗回来。  
4. 右键「退出栖」：壳退出；若壳自拉起大脑则子进程结束；若先手动 `python -m qi` 再开壳则大脑仍在。  
5. Vite 浏览器开发：无托盘属预期。
