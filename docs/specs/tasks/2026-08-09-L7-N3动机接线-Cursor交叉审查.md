| 路径 | 事实 |
|------|------|
| legacy | `brain._heartbeat_legacy_idle` → `action.tick(...)`：**tick 不持有 brain**（`layer.py` L164–175） |
| GWS（默认） | `collect_contenders(brain)` → `action_intentions(...)`（`trace.py` L424）→ 仲裁 → `action.execute_kind(...)` → `explore.drift(..., force=True)`（`layer.py` L311–318） |

**结论（须写进 PR，非「编码时再猜」）**：

3. `collect_contenders` 调 `action_intentions` 时**多传** `pressure=getattr(brain, "last_pressure_response", None)`。  
4. `action_intentions` 签名加 `pressure: ... | None = None`。

## 必须整改（阻塞编码）

### B1. GWS + `force=True` 使 drift 概率调制在默认路径落空

**现状**：`gws.enabled` 默认 true；explore 胜出后：

```python
# layer.execute_kind
await self.explore.drift(..., force=True)
```

**PR**：调制写在 `if not force:` 内 → **默认生产路径不执行** Spec「drift 触发概率软调制」。  
legacy `tick` 无 force，才会跑公式——与现网主路径不符。

**请 Trae 裁定并回写 PR（三选一）**：

| 选项 | 内容 |
|------|------|
| **a（推荐）** | `execute_kind` 调 drift 时 **`force=False`**，或去掉 explore 的 force，让压力+好奇软门在执行前仍生效；GWS 只负责「选谁」，不负责「跳过全部时机阀」 |
| **b** | 保留 `force=True`（跳过 curiosity/季节随机），但 **force 时仍应用 pressure 调制**（单独一段：算出 p_pressure 再摇骰；curiosity 阈仍可在 force 下跳过或保留——须写明） |
| **c** | Spec 收窄：N3 在 GWS 下**只调 volition/salience**；drift 概率调制仅 legacy。须明示验收以 priority 测为主 |

未裁定前编码会做成「测例绿、真机几乎无感」。

### B2. 接线清单不完整：漏 `collect_contenders`

PR §2/§4 只提 `ActionLayer.tick` + `volition`。  
GWS 候选来自 `trace.collect_contenders` → `action_intentions`（**不经过** `tick` 的 intentions 调用）。

**整改**：PR 增加明确改动点：

- `qi/core/trace.py`：`action_intentions(..., pressure=getattr(brain, "last_pressure_response", None))`  
- `layer.tick` / `layer.execute_kind`：签名加 `pressure=None`，传入 `explore.drift(..., pressure=pressure)`  
- `brain`：两处调用（legacy tick + GWS execute_kind）传入 `self.last_pressure_response`
