## 背景（隐私边界洞）

assist-7 后，用户文件内容概要（块 digest / 整体叙事）进入 narrative 长期记忆。而 explore 的隐私红线：

```
_QUERY_PRIVACY_LINE = "不引用 user_facts / 对话内容"
```

**只覆盖 user_facts / 对话内容，不含用户文件内容**。该常量同时用于：
1. 外部搜索 query 生成（`_make_query`）
2. 外部 hits digest（`_digest_hits`）
3. 内部记忆深读 digest（`_digest_internal`）

后果：栖在独处探索 / 梦里「想起」你给的文件内容时，digest/query 生成**不受红线约束**，可能主动说出文件内容（speak=True 开口）。

**数字生命对照**：记得你给的东西是生命感；但**克制**——不主动背诵原文，被问才说（对话路径已有 assist-6 硬规则约束，explore 路径缺失）。

**维护者拍板**（2026-08-09）：explore 红线措辞补「用户文件内容原文」。

## 目标一句话

explore 的 query/digest 隐私红线覆盖用户文件内容——栖探索时「记得但不引用文件内容原文」。

## 范围边界（不做清单）

- 不改 narrative 存储（记忆仍存概要——那是「记得」，属 assist-8 管）
- 不改对话路径（assist-6 硬规则已约束「被问到就承认」）
- 不改前端 / settings / 其他行动（share/tend/explore 均只用该常量，一处改三处生效）

## HITL 拍板（推荐值，按维护者扩权采纳）

1. **措辞方案**——推荐 a：
   - a. `_QUERY_PRIVACY_LINE` 改为 `"不引用 user_facts、对话内容或用户文件内容原文"`——一处常量，三处 digest/query 全生效
   - b. 内部 / 外部分开写两条——过度，否
   - 理由：语义一致（栖的「读」不外传），单源

## Spec（外部可观测行为）

1. explore 外部搜索 query 生成 / hits digest / 内部记忆 digest 均不引用用户文件内容原文
2. 栖探索时可提起「读过某文件」这件事（事件记忆），但不背诵内容

## 验收

- `_QUERY_PRIVACY_LINE` 措辞含「用户文件内容原文」
- 既有 digest/query 测试措辞断言迁移（若写死旧措辞）
- 全量 ≥585 passed
