## Spec（外部行为）

1. Windows 安装/打包布局下，壳能拉起 **PyInstaller onedir** 的内置大脑（`qi-brain`），用户不必自装 Python / clone。  
2. 壳选脑优先级：① `127.0.0.1:9527` 已在听 → 沿用且退出不杀；② 旁有 bundled `qi-brain` → 起它；③ 否则仓库根 `python -m qi`；④ 都失败 → 现有失败可见路径（不静默）。  
3. 数据仍走既有数据根（LOCALAPPDATA / 旧仓兼容）；托盘「退出栖」仍只收壳自拉起的大脑。  
4. 仓库提供可重复的打脑脚本；本机能用 bundled 布局证伪「脑起来 + WS 可连」。  
5. **本刀不含**：BGE 打进包、默认 VRM、关于页/Releases、CI Release、macOS、静默更新、自定义数据目录 UI。
