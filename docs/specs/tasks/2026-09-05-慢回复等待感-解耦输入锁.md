# 慢回复等待感 · 解耦输入锁与等待提示

> 维护者拍板 **A + C（2026-09-05）**：按建议落码。

## Spec（外部行为）

1. **等待点 /「正在回你」**：从用户发出到栖的可见回复（首段 `speech` / `speech_delta`）或系统态 / 打断 / 断线之前，**保持**等待反馈；不因约 60s 到点而灭灯。
2. **约 60s**：仍按 P0「安静地坏掉」**解开输入强调**（composer 不再呈 busy 态），并可见超时系统态；文案说明她可能还在想、迟到气泡仍会显示。
3. **超时后仍在等**：形象旁状态改为更轻的「还在想」（不再用「正在回你」占满），等待点仍可显示。
4. **流式收回再重试**（`speech_retract`）：气泡收回后**重新点亮**等待反馈，避免空窗。
5. **本刀不含**：拉长硬超时到 120s、服务端 typing 心跳、改模型/流式策略。
