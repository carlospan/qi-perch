## Spec

栖对**外部 search 结果**进行"内部深读"——用 LLM 把搜到的 hits 转成栖的语气复述（digest）。开口 `qi_line = digest`（栖语气，不再只念 query）；DB `summary = digest`（栖语气叙事留痕）；`found.entries` 保留完整 hits 结构化溯源给 d-3。

## 背景

d-1 后栖能搜到外部内容（Tavily hits），但没"消化"——开口只念 query、留痕含 title、hits 进 `found.entries` 留后路。相处验证暴露：栖搜到了，但用户听不到她对搜到内容的理解——"看了一眼"没"看懂"。

d-1 B3 钉死"不二次 LLM"（模板化开口）；**d-2 解禁**——允许一次 LLM 转译 hits → 栖语气 digest。
