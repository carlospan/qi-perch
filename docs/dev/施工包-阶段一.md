## 〇、阶段一的特殊纪律（在统一纪律之上叠加）

1. **设计总原则：决策内生，措辞分级。** 决策（何时想/做什么/影响什么）一律由内部状态与规则产生，不再问 LLM；文本走降级链——**远程在 → LLM 把内在素材写成文；远程断 → 本地模板拼装**（模板腔但有出处，是预期形态不是缺陷）。
2. **R2 警报（本阶段最高风险）：** 变笨是预期。最大诱惑是把人设写回 prompt——**忍住**。手感崩了用生命感监护定位根因，不准用加 prompt 的方式治。
3. **每包必带拔管测试**：fake-provider 全失败时，本包涉及的内在活动仍产生记录（模板兜底路径）。
4. **改 prompt 留改前/改后对话摘录**；dream/consciousness/self_model 的 LLM 调用减少要在 diff 中可数。
5. 统一纪律沿用阶段零（一包一 PR / pytest+ruff 全绿 / 完工回写 / 不引入未确认依赖——**本阶段无任何新依赖额度**）。

## 包 1：梦=巩固（episode 骨架 + 积压驱动 + 回写强度） ✅

**治病征：** §2.5-3（0 个梦）+ N4(a) 三修复中的①②。

### 【文件】
`qi/storage/database.py`（episodes 表）、`qi/memory/episodic.py`（新增）、`qi/memory/narrative.py`（编织同步产 episode）、`qi/inner_life/dream.py`（触发与回写改造；入口仍在 InnerLife.tick）、`tests/test_episodic.py`（新增）、`tests/test_inner_life.py`（扩充）。**不改** `brain_background.py`（仅 dream_decay；做梦入口在 DreamEngine）。

### 【改成】
1. **episodes 表**：`id / start_ts / end_ts / topic / summary / key_facts_json / role_map_json / status(open|closed) / dreamed(int 0|1) / importance / created_at`。叙事编织完成一批 events 时同步写一条 episode；`role_map` 记录「谁对谁说了什么」——从结构上根治编织角色织反（实证：narrative id=37）。
2. **编织联动**：`weave_narrative` 产出叙事后，同批 events → episode（summary 复用叙事首句或独立压缩，role_map 从 events 的 role 字段聚合）。
3. **梦=巩固触发**：`dreaming` 模式下**有未巩固 episode（dreamed=0）才做梦**——无积压不梦（替代 10%/拍 干等）；有积压时按可配置概率（`dream_consolidation_probability`，默认 0.3）触发。decision 完全内生：选 episode 的规则 = 未巩固 + importance 高 + emotional_intensity 高，加权随机。
4. **梦的文本（降级链）**：远程在 → LLM 以「选中 episode 的碎片 + 情绪底色 + season_hint」写梦境（保留高 temperature）；远程断 → **碎片拼接模板**（episode summary 打散 + 意象连接词，允许破碎——梦本来就该破碎）。LLM 只做措辞，不参与选题。
5. **回写巩固**：梦生成后 `dreamed=1`；被梦到的 episode 重要性重估（情绪标签正→importance 微升，负→arousal 相关字段按现有 dream_retention 体系衔接）；梦境 retention 衰减逻辑（现有 `decay_all`）不动。
6. **日志**：做梦时落一条 decision trace（选了哪个 episode、为什么）——C4 溯源从梦开始练习。

### 【测试】
- episode 随编织生成、role_map 方向正确（「他对我」不织反）
- 无未巩固 episode → 不梦；有积压 + dreaming → 按概率梦（mock random）
- fake-provider 全失败 → 模板兜底梦仍落库（拔管判据）
- 梦后 `dreamed=1`；retention 衰减不受影响
- 决策 trace 落 body_memory

### 【验收】
218+ 全绿；真机挂 dreaming（离线 4h+ 或深夜）有积压时产出第一场梦；拔管时模板梦有记录。

## 包 2：状态数值由关系事件真实驱动 ✅

修 §2.5-5 脱钩（attachment≈0.3 与恋人关系不符）。attachment/security 配阶段目标锚（bonded 下 attachment 基线显著上移）；关系事件（stage_changed/伤疤/大承诺代理）直接 nudge 情绪；trust/temperature 近顶软增速 + 无交互日向阶段舒适区回归。大承诺 nudge 日帽 ≤2（body_memory）。文件：`emotion.py`/`trust.py`/`engine.py`/`brain.py`。**无 LLM 角色变化，纯规则。**

## 包 3（概要）：意识流决策内生 + open loops

引入 open loops（未闭合念头队列，上限 5，N2 机制前置）；随机 5% 触发替换为「loop 积压 + 事件型」驱动；文本走降级链。文件：`consciousness.py`、新增 `qi/memory/open_loops.py` 或并入 inner_life。

## 包 4（概要）：expression 两段式

表达意向结构化（intention：说什么事/情绪/对象/出处）由规则产出；措辞降级链。核心手术，风险最高，放后面。文件：`expression.py`/`prompt_builder.py`/`brain.py`。

## 包 5（概要）：身份快照 + prompt 瘦身

500–800 字「此刻的我」（self_model+关系叙事+recent_arc 压缩）统一注入；conversation.txt 瘦身 ≥50%。
