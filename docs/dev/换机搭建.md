# 换机搭建指南

在新电脑上把「栖」跑起来：从 GitHub 拉代码 → 装依赖 → 配密钥 → 启动。

旧机上的 `.env`、`config/settings.yaml`、`data/` **不会进仓库**（已在 `.gitignore`）。换机等于新环境，需要重新配置；若要延续记忆，需自行拷贝 `data/`。

---

## 1. 需要安装的软件

| 软件 | 用途 | 备注 |
|------|------|------|
| Git | 克隆仓库 | [git-scm.com](https://git-scm.com/) |
| Python 3.12+ | 后端大脑 | 安装时勾选「Add to PATH」 |
| Node.js 18+ | 具身前端 | [nodejs.org](https://nodejs.org/) LTS |
| Rust（cargo） | 编译 Tauri 壳 | [rustup.rs](https://rustup.rs/) |
| MSVC 构建工具 | Windows 编 Tauri | Visual Studio Installer →「使用 C++ 的桌面开发」 |

只跑终端聊天（`qi`）时，Node / Rust / MSVC 可后装。

装完后新开终端，确认：

```bash
python --version    # >= 3.12
node --version      # >= 18
cargo --version     # 有输出即可
git --version
```

---

## 2. 克隆项目

```bash
git clone https://github.com/carlospan/qi-perch.git
cd qi-perch
```

建议用虚拟环境（可选但推荐）：

```bash
python -m venv .venv

# Windows PowerShell
.\.venv\Scripts\Activate.ps1

# Windows CMD
.\.venv\Scripts\activate.bat

# Git Bash
source .venv/Scripts/activate
```

---

## 3. 安装 Python 依赖

在项目根目录：

```bash
pip install -e ".[dev]"
```

需要语音时再装：

```bash
pip install -e ".[voice]"
# 或：pip install edge-tts
```

跑一遍测试，确认环境正常：

```bash
python -m pytest -q
```

## 4. 密钥与配置（必做）

仓库里只有示例文件，没有你的真实密钥。

### 4.1 环境变量

```bash
# Windows
copy .env.example .env

# macOS / Linux
cp .env.example .env
```

用编辑器打开 `.env`，填入真实值，例如：

```
DEEPSEEK_API_KEY=sk-...
AGNES_API_KEY=sk-...
```

**不要**把填好的 `.env` 提交到 Git。

### 4.2 运行配置

```bash
# Windows
copy config\settings.example.yaml config\settings.yaml

# macOS / Linux
cp config/settings.example.yaml config/settings.yaml
```

按需改 `config/settings.yaml`（模型、provider、语音开关等）。  
文件中的 `api_key: "${AGNES_API_KEY}"` 会从 `.env` 读，一般不用把密钥写进 yaml。

开启 TTS 示例：

```yaml
voice:
  enabled: true
  provider: edge-tts
  voice_id: zh-CN-XiaoyiNeural
```

## 5. 从旧电脑迁移记忆（可选）

若希望新机接着旧机的记忆/关系状态，在**旧机**把整个 `data/` 目录拷到新机项目根下同名位置（先停掉两边的栖进程）。

不要提交 `data/`；用 U 盘、网盘私密目录或加密通道传输即可。

只换代码、不拷 `data/` = 全新的栖（空白记忆）。

## 6. 启动

### 终端模式

```bash
qi
# 或：python -m qi
```

`/state` 看状态，`/quit` 退出。

### 具身窗口（两进程）

**终端 1 — 后端：**

```bash
qi-desktop
# 兼容：python run.py --desktop
```

**终端 2 — 桌面壳：**

```bash
cd embodiment/desktop
npm install
npm run tauri:dev
```

首次 `tauri:dev` 会编译 Rust，可能较慢。窗口透明无边框，拖标题「栖」可移动。

仅浏览器调试（不启 Tauri）：

```bash
cd embodiment/desktop
npm install
npm run dev
```

打开 http://localhost:5173。后端 WebSocket：`ws://127.0.0.1:9527`。

更多桌面端说明见 [embodiment/desktop/README.md](../../embodiment/desktop/README.md)。

## 8. 常见问题

| 现象 | 处理 |
|------|------|
| `cargo` / `program not found` | 新开终端；或重启 Cursor。`npm run tauri:dev` 会尝试把 `%USERPROFILE%\.cargo\bin` 加入 PATH |
| crates.io 拉依赖失败 | 仓库已带 `embodiment/desktop/src-tauri/.cargo/config.toml`（rsproxy）；仍失败可检查网络/代理 |
| 前端连不上 | 确认后端已 `qi-desktop`，端口 `9527` 未被占用 |
| LLM 无回复 / 空串 | 检查 `.env` 密钥与 `settings.yaml` 里 provider 是否一致、网络是否可达 |
| 没有旧记忆 | 正常：未拷 `data/` 即为新实例 |
| 推送/拉取要登录 | `gh auth login`，或配置 Git Credential Manager |

## 9. 日常更新代码

```bash
cd qi-perch
git pull
pip install -e ".[dev]"          # 依赖有变时再跑
cd embodiment/desktop && npm install   # 前端依赖有变时再跑
```

`data/` 与 `.env` 不会被 `git pull` 覆盖。
