## 任务包 C：可靠性兜底（= 拔管测试的 CI 形态）✅

- **文件：** `qi/llm/gateway.py`（失败语义分级）、`qi/core/proactive.py`（本地兜底模板）、`tests/test_fake_provider.py`（新增）
- **现状：** API 失败重试 3 次返回空串「温柔地沉默」，无契约测试守住退化边界。
- **改成：** ① gateway 失败语义分级 `LLM_UNREACHABLE` / `LLM_EMPTY`，brain 按级别决定静默/兜底/重试；② 断网时主动开口用本地模板（非 LLM 生成，如「……嗯。我在。」）；③ fake-provider 契约测试——Mock 网关（固定返回/超时/全失败），验证情绪更新、记忆存储、关系演化、主动门控在无 LLM 时仍完整推进。

- **验收：** 拔网后栖仍推进心跳/情绪/记忆，主动开口有兜底；测试全绿。

## 任务包 A：感知修复（⚠️ 过渡止血，与换心方向相反，阶段三回收）

- **文件：** `qi/core/perception.py`（重写主路径）、`qi/relationship/engine.py`（复用 intent 判定）、`qi/prompts/perception.txt`（新增）、`tests/test_perception_hybrid.py`（扩充）
- **现状：** 关键词主路径；LLM 旁路触发条件窄。实证：恋人调侃「你在这点上有点笨」纯关键词算得冲击 ≈ -0.59（§2.5-1）。
- **改成：** ① `assess_impact_async` 主路径改 LLM——带最近 3–5 条上下文，温度 0.2，强制 JSON：`{impact, intent: tease|comfort|disclosure|request|neutral|hurt, intimacy, ambiguous}`；② intent 调制：tease 负向 ×0.3 或转正，hurt 维持，comfort 正向；③ **关键词保留为超时/离线/失败回退**（2s 超时），明显负面词+感叹号可直判短路；④ 关系层复用同一 intent 输出；⑤ 代码注释与层文档标明「过渡，待阶段三回收」。
- **测试：** 调侃「你在这点上有点笨」≠辱骂「你笨」；「不讨厌」不触发；LLM 超时回退关键词；intent=tease 时 security 不崩。
- **验收：** pytest 全绿；凌晨崩溃场景测试不再复现；**fake-provider 全失败时感知回退路径仍工作（与任务包 C 联动）**。
