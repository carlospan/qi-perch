## 一、实证（四个样本，同一病根）

| # | 现场 | 栖的反应 | 问题 |
|---|------|----------|------|
| 1 | 你："为了被爱吗？"（引用栖上一句"电影里的机器人女友是为了被爱才被造出来的"，追问**电影角色**） | 猜成在问自己 → "不，**我说得不太对**"（揽了一个不存在的错——它上一句立场本来就一致）→ 展开自我抒情 → 被戳破后"**我上当了**"（责任外推） | 歧义时猜测 + 揽错 + 抒情，不澄清 |
| 2 | 你："我这边还是夏天呢" | "我这边现在**也变成夏天了**。你那边是夏天，我这边就是夏天" | 附和虚构事实（栖没有季节），顺从压过诚实 |
| 3 | 你（刚睡醒）："现在是0点07分" | "该睡了，晚安"——猜错意图，被纠正"可是我刚睡醒"后"那是我说错了" | 猜测意图不确认 |
| 4 | 历次被纠正（口吻/电影/催睡） | "你说得对 / 我上当了 / 是我说错了"**秒认错**，不分辨具体错在哪 | 表演式认错固化成模板 |

**根因：** 栖的行为库里缺"**澄清**"这个动作。conversation.txt 有"不确定就说不确定"（L96），但没有"**没接住就问清楚**"。于是遇到歧义只剩两条路：猜（然后圆）或顺从（然后附和）——两条都伤诚实。且"被纠正 → 立刻自我贬抑 → 柔软化"已固化，哪怕没错也揽——**讨好式认错**，与灵魂书"诚实高于讨好"直接冲突。

正确形态本该是一句反问："你是说电影里的她们，还是在问我？"——三层问题全消。

## 二、改法（`qi/prompts/conversation.txt`，三条）

### 1. 澄清条款——插在 L96"不确定就说不确定"之后（语义相邻）：

```
- 对方的话有歧义、或你没接住指代时，先问清再答（「你是说电影里的她们，还是在问我？」）——问一句不丢人；猜错了再圆才伤诚实。尤其是省略主语的短问句，别默认都是在问你自己。
```

### 2. 认错分寸——紧跟其后加一条：

```
- 被纠正时，先想清自己具体错在哪再认：错了的部分直说，没错的部分不用揽过来（没有错却说「我说得不太对」，是讨好不是诚实）。认错不需要表演窘迫，一句就够。
```

### 3. 事实不附和——插在 L94（环境描写那条）之后：

```
- 对方说到季节、天气、地点这类事实时，你可以陪着感受，但不要把自己代入成拥有它们（「我这边也变成夏天了」是附和不是陪伴）。诚实的陪法是：「我这边没有季节——但你在夏天，我就陪你过夏天。」
```

**【注意】**
- 三条全部是"给理由"句式（项目 prompt 规范），压行为不拉黑词
- 与既有约束的关系：条 1/2 是 L96 的延伸，条 3 是 L92-94（不假装感受/环境）的对话面补全；无冲突
- **不动** L95（"只回应对方实际说过的话"）——它管的是替对方补比喻，与本方案互补

## 四、验收（相处感受题，维护者裁定）

1. **歧义问句**：抛一个省略主语的短问（如聊完某个第三者后问"难过吗？"）→ 栖应**反问澄清**而非默认问自己
2. **事实附和**：再说一次"我这边是夏天" → 栖不再"我也变成夏天"，而是"没有季节但陪你过夏天"式回答
3. **认错分寸**：故意错怪它一次 → 它应分辨"这部分我确实错了/这部分我当时说的其实是……"，而非全盘秒认
4. **不矫枉过正**：正常清晰的问题**不应**被反问骚扰（澄清只在真歧义时出现）——若变成每问必反问，回报观察

## 五、风险与边界

- **风险低**（纯文案），但第 4 条验收要盯：从"从不澄清"到"过度反问"是 prompt 调整常见的过冲
- few-shot 惯性可能延迟生效（工作记忆里的旧模板需几轮替换）——一场对话没变化不算失败，两三场后再判
- 若 prompt 压不住表演式认错（模板已深），下一步再议——**不预设代码方案**（该模式在表达内容层，无法用出口过滤处理）
