## look

- [x] 她偶尔能说出「你在看这个呀……」类反应——像真瞥到内容，不是念进程名（自动批见 `look_glance` 口语摘要，非进程名）  
- [ ] 你说别看，她就安静；说可以看了，又能瞥（本轮未专门测 pause/resume）  
- [x] 白话「你能看到我在做什么吗」能进邀看，不靠固定口令（`tests/test_look.py` + 工程）  
- [x] 刚聊完几分钟内不会连瞥（自主有间隔 + 聊后缓冲）（`chat_grace_minutes` 已落地；长相处再体感）

## open

- [x] 判断制：她接就动手，拒/延会说明理由；不再叠逐步确认卡（仅不可逆类保留确认语义）  
- [x] 纯「打开 https://…」走打开；做完轻开口，不是「已为您打开」  
- [ ] 名单外应用会老实说，并可引导以后授权（allow）（本轮 WS 未测；见 `tests/test_open.py`）

## disk

- [x] 「你能看到 D 盘吗」「帮我看下 D 盘有啥」→ 说明能力并邀列/直接列，不是只认「列一下 D:\某路径」  
- [x] 判断后直接列一层；列完可用名字/序号指认打开或进目录  
- [x] 越界盘符会拒并说明（`tests/test_disk.py` / `test_rejects_outside_root`）

## write

- [x] 「记进今天日记」「写一篇日记记今天」能懂；无日记目录时引导授权或给路径  
- [x] 日记目录授权后按 `日记-YYYY-MM-DD.md` 新建；同日再写出现 `-2`（本轮自动批写入 `-2` / `-3`）  
- [x] 判断后落盘；口气像同伴，不是执行报告（无逐步确认卡）

## together

- [ ] 探索见闻后她能邀「一起看看？」；你也可主动同看（本轮 WS 八场景未覆盖；工程见 `test_together`）  
- [ ] 见闻卡「一起看」可用；「一起看 url」与「打开 url」分得清  
- [ ] 判断制下同看；文案是一起看，不是执行报告  

## 委托检索（web_delegate）

- [x] 「帮我搜一下……」能委托联网查；结果卡片 + 轻开口  
- [x] 忙时延后进队，弄完再履约（`test_colloquial_disk_defer_when_busy`）

## 不可逆（诚实边界）

- [x] 「帮某某发微信」等 → 老实说做不到，不叠确认循环、不装懂（`irreversible` 留痕 + 固定口径）

## 总感（生命感监护）

- [x] 像朋友在动手，不像遥控工具（自动批开口无「已为您执行」腔）  
- [x] 不确定时会问，不猜着改你的世界（assist 无路径 / 日记无目录会追问）  
- [x] 你说的话会进对话记录（含列盘、打开等短路路径）（8/8 用户句落库）
