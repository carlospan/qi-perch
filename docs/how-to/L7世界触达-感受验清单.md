> **契约**：懂意思；行动从慎；同伴感，非工具腔。

相处约 30～60 分钟，按条勾；不通的记一句现象（勿只写「失败」）。

## look

- [ ] 她偶尔能说出「你在看这个呀……」类反应——像真瞥到内容，不是念进程名  
- [ ] 你说别看，她就安静；说可以看了，又能瞥  
- [ ] 白话「你能看到我在做什么吗」能进邀看，不靠固定口令  

## open

- [ ] 打开链接 / 白名单应用前会先问你；谈区问清楚，不叠重复确认卡  
- [ ] 纯「打开 https://…」走打开；做完轻开口，不是「已为您打开」  
- [ ] 名单外应用会老实说，并可引导以后授权（allow）  

## disk

- [ ] 「你能看到 D 盘吗」→ 说明能力并邀列，不是只认「列一下 D:\某路径」  
- [ ] 确认后只列一层；列完可用名字/序号指认打开或进目录  
- [ ] 越界盘符会拒并说明  

## write

- [ ] 「写一篇日记记今天」能懂；无路径时先问写到哪（可邀列 D:）  
- [ ] 日记目录授权后按 `日记-YYYY-MM-DD.md` 新建；同日再写出现 `-2`  
- [ ] 确认含路径 + 全文预览；点头后才落盘；口气像同伴  

## together

- [ ] 探索见闻后她能邀「一起看看？」；你也可主动同看  
- [ ] 见闻卡「一起看」可用；「一起看 url」与「打开 url」分得清  
- [ ] 打开前仍问你；文案是一起看，不是执行报告  

## 总感（生命感监护）

- [ ] 像朋友在动手，不像遥控工具  
- [ ] 不确定时会问，不猜着改你的世界  

勾完后：结果可记在 `progress.md` 一行，或本文件下方自增「记录」段。
