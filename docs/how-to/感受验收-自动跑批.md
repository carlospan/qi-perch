# 感受验收 · 自动跑批（改码后必跑）

> **定位**：how-to。工程 pytest 绿 ≠ 相处手感过关；本流程用 **脚本 + 活库** 在改码后自动扫一轮，减少「只跑测试、没跟栖说话」的漏检。
> **相处勾选**（维护者手感）仍见 [`L7世界触达-感受验清单.md`](./L7世界触达-感受验清单.md)；本文件管 **Agent / CI 可执行的自动验收**。

---

## 什么时候跑

**改完代码、准备收工或交 PR 前**，若动到以下任一类，须跑本流程（不只跑 pytest）：

| 范围 | 示例路径 |
|------|----------|
| 对话入口 / 心跳 | `qi/core/brain*.py`、`brain_delivery.py`、`brain_persist.py` |
| L7 行动 | `qi/action/**`（look/open/disk/write/together/assist/judgment/delegate_search/irreversible） |
| 具身 WS | `qi/embodiment/**` |
| 权限 / 意图 | `permission.py`、`volition.py`、各 `detect_*_intent` |
| 白话验收测 | `tests/test_judgment*.py`、`tests/test_*_colloquial*`、`tests/test_acceptance_fixes.py` |

**可跳过**：纯文档、纯注释、仅改 `tests/` 里与行为无关的夹具（仍建议 `pytest -q`）。

**纪律（Cursor Agent）**：完成上述代码改动后，**默认跑一遍感受验收**；失败则修到绿或把阻塞原因写入 `data/_acceptance_summary_*.md`，勿静默跳过。

---

## 跑什么（两层）

| 层 | 命令 | 验什么 |
|----|------|--------|
| **工程** | `python -m pytest -q --basetemp=.pytest_basetemp` | 回归、白话用例、判断制 |
| **感受自动批** | `python tools/acceptance_run.py` | pytest + WS 八场景 + 活库快照 + 短观察 |

日常改码后若 pytest 刚全绿，可省时间：

```powershell
python tools/acceptance_run.py --skip-pytest
```

仅 WS + 活库（栖已在跑、且确认连的是**新代码**实例）：

```powershell
python tools/acceptance_ws_only.py 9528
```

（端口按实际；见下节「重启栖」。）

## 怎么跑（推荐顺序）

### 1. 工程测试

```powershell
cd d:\qi-perch
python -m pytest -q --basetemp=.pytest_basetemp
```

### 2. 感受自动批

```powershell
python tools/acceptance_run.py
```

脚本会：

1. 尽量释放 **9527** 并启动**当前仓库**的 `python -m qi`
2. 若 9527 被旧进程占用且无法结束 → 在 **9528** 起新实例（`data/_acceptance_runtime_settings.yaml` + 环境变量 `QI_CONFIG`）
3. 跑 WS 八场景（消息带标记 `[验收2026-08-22]`，避免与日常对话混淆）
4. 写报告到 `data/_acceptance_report_YYYYMMDD-HHMM.md`
5. 结束**本脚本启动**的子进程（不杀用户桌面壳占用的 9527）

### 3. 看结果

- **报告**：`data/_acceptance_report_*.md`（完整）
- **摘要**（Agent 可自写）：`data/_acceptance_summary_YYYYMMDD-HHMM.md`
- **活库**：`data/qi.db` 中 `messages` / `actions` 带验收标记或时间戳

**通过启发式**（自动批问题清单为空或仅 P3 端口说明）：

- pytest `exit_code=0`
- 8 条带 `[验收2026-08-22]` 的**用户句均落库**
- 委托检索 / 列盘 / 开链接 / 日记 / 发微信 / assist 等场景 **ok**（开口或行动留痕）
- 「发微信」类 → `irreversible` 留痕 + 诚实口径（非确认门循环）

## 重启栖（重要）

桌面壳（`tauri:dev`）默认连 **ws://127.0.0.1:9527**。若 9527 上是**改码前**的旧 `python`，验收会假通过/假失败。

| 情况 | 做法 |
|------|------|
| 只跑自动批 | 用脚本的 **9528 新实例**即可（`acceptance_run` / `acceptance_ws_only.py 9528`） |
| 桌面也要新代码 | 任务管理器结束占用 9527 的 `python`，再 `python -m qi` 或重启 `tauri:dev` |

查端口：

```powershell
netstat -ano | findstr :9527
```

## 工具索引

| 文件 | 用途 |
|------|------|
| `tools/acceptance_run.py` | 全量：pytest + WS + 活库 + 60s 观察 |
| `tools/acceptance_ws_only.py [port]` | 仅 WS 八场景 + 活库佐证（栖已就绪时） |
| `tools/verify_package.py` | 包级：pytest + ruff + grep 审计（见各任务包） |
| `tests/test_judgment_colloquial_acceptance.py` | 判断制白话（无 WS） |
| `tests/test_acceptance_fixes.py` | 落库 / irreversible / disk 口语等回归 |

环境：

- `QI_CONFIG`：指向 `data/_acceptance_runtime_settings.yaml` 可改 WS 端口等（见 `qi/config/__init__.py`）
- `pyproject.toml` 已默认 `--basetemp=.pytest_basetemp`（规避 Windows 临时目录权限）

## 与维护者相处验的关系

| | 自动跑批 | L7 感受验清单 |
|--|----------|----------------|
| 谁跑 | Agent / CI / 维护者 | 维护者相处勾选 |
| 验什么 | 能开口、能留痕、用户句落库、无确认门回退 | 像朋友、不像工具、懂意思 |
| 频率 | **每次改码后** | 升 L7 ✅ 前约 30–60 分钟 |

两者互补：自动批挡回归；清单挡「测得绿但手感不对」。

## 记录约定

Agent 跑完在 `data/` 留一行摘要即可，例如：

```markdown
# 栖验收摘要 · YYYY-MM-DD HH:MM
- pytest: 700 passed
- WS: 8/8 用户落库；irreversible ✅
- 端口: 9528（9527 旧进程未杀）
```

严重失败把现象写进摘要，勿只写「失败」。
