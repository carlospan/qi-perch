# 感受验收 · 自动跑批

> **定位**：how-to。工程 pytest 绿 ≠ 相处手感过关；本流程用 **脚本 + 活库** 做可重复的自动扫批。  
> **相处勾选**（维护者手感）仍见 [`L7世界触达-感受验清单.md`](./L7世界触达-感受验清单.md)。  
> **回写(2026-08-29)**：全感受批改为**维护者明示才跑**；日常刀默认 pytest + 针对本刀短验。

---

## 什么时候跑什么

| 档 | 何时 | 跑什么 |
|----|------|--------|
| **日常刀（默认）** | 改完运行时行为、收工 | 相关或全量 **pytest** + **只针对本刀**的验收（单测 / Spec 勾选 / 1～2 句手测口径） |
| **全感受自动批** | 维护者**明示**要求（「跑感受批」「acceptance_run」等） | `python tools/acceptance_run.py`（WS 八场景 + 活库 + 短观察） |
| **可跳过感受相关** | 纯文档、纯注释、与行为无关的测试夹具 | 不跑全批；有改测则仍跑相关 pytest |

涉及面广时（对话入口 / L7 / 具身交叉）Agent **可提醒**「是否要跑全感受批」，**不得**未经明示自行开跑。

## 跑什么（两层）

| 层 | 命令 | 验什么 |
|----|------|--------|
| **工程（默认）** | `python -m pytest -q --basetemp=.pytest_basetemp` | 回归、白话用例、判断制 |
| **全感受自动批（明示）** | `python tools/acceptance_run.py` | pytest + WS 八场景 + 活库快照 + 短观察 |

明示后若 pytest 刚全绿，可省时间：

```powershell
python tools/acceptance_run.py --skip-pytest
```

仅 WS + 活库（栖已在跑、且确认连的是**新代码**实例）：

```powershell
python tools/acceptance_ws_only.py 9528
```

（端口按实际；见下节「重启栖」。）

## 怎么跑全批（维护者明示后）

### 1. 工程测试（若尚未跑）

```powershell
cd d:\qi-perch
python -m pytest -q --basetemp=.pytest_basetemp
```

### 2. 感受自动批

```powershell
python tools/acceptance_run.py
```

脚本会：

1. 尽量释放 **9527** 并启动**当前仓库**的 `python -m qi`
2. 若 9527 被旧进程占用且无法结束 → 在 **9528** 起新实例（`data/_acceptance_runtime_settings.yaml` + 环境变量 `QI_CONFIG`）
3. 跑 WS 八场景（消息带标记 `[验收2026-08-22]`，避免与日常对话混淆）
4. 写报告到 `data/_acceptance_report_YYYYMMDD-HHMM.md`
5. 结束**本脚本启动**的子进程（不杀用户桌面壳占用的 9527）

### 3. 看结果

- **报告**：`data/_acceptance_report_*.md`（完整）
- **摘要**（Agent 可自写）：`data/_acceptance_summary_*.md`
- **活库**：`data/qi.db` 中 `messages` / `actions` 带验收标记或时间戳

**通过启发式**（自动批问题清单为空或仅 P3 端口说明）：

- pytest `exit_code=0`
- 8 条带 `[验收2026-08-22]` 的**用户句均落库**
- 委托检索 / 列盘 / 开链接 / 日记 / 发微信 / assist 等场景 **ok**（开口或行动留痕）
- 「发微信」类 → `irreversible` 留痕 + 诚实口径（非确认门循环）

## 重启栖（重要）

桌面壳（`tauri:dev`）默认连 **ws://127.0.0.1:9527**。若 9527 上是**改码前**的旧 `python`，验收会假通过/假失败。

| 情况 | 做法 |
|------|------|
| 只跑自动批 | 用脚本的 **9528 新实例**即可（`acceptance_run` / `acceptance_ws_only.py 9528`） |
| 桌面也要新代码 | 任务管理器结束占用 9527 的 `python`，再 `python -m qi` 或重启 `tauri:dev` |

查端口：

```powershell
netstat -ano | findstr :9527
```

## 工具索引

| 文件 | 用途 |
|------|------|
| `tools/acceptance_run.py` | 全量：pytest + WS + 活库 + 60s 观察（**明示才跑**） |
| `tools/acceptance_ws_only.py [port]` | 仅 WS 八场景 + 活库佐证（栖已就绪时） |
| `tools/verify_package.py` | 包级：pytest + ruff + grep 审计（见各任务包） |
| `tests/test_judgment_colloquial_acceptance.py` | 判断制白话（无 WS） |
| `tests/test_acceptance_fixes.py` | 落库 / irreversible / disk 口语等回归 |

环境：

- `QI_CONFIG`：指向 `data/_acceptance_runtime_settings.yaml` 可改 WS 端口等（见 `qi/config/__init__.py`）
- `pyproject.toml` 已默认 `--basetemp=.pytest_basetemp`（规避 Windows 临时目录权限）

## 与维护者相处验的关系

| | 全感受自动批 | L7 感受验清单 |
|--|----------|----------------|
| 谁跑 | 维护者明示后 Agent / 维护者 | 维护者相处勾选 |

## 记录约定

明示跑完全批后，Agent 可在 `data/` 留一行摘要，例如：

```markdown
# 栖验收摘要 · YYYY-MM-DD HH:MM
- pytest: 700 passed
- WS: 8/8 用户落库；irreversible ✅
- 端口: 9528（9527 旧进程未杀）
```

严重失败把现象写进摘要，勿只写「失败」。
