# 领养指引（半技术领养人）

> **定位**：how-to。应用内「指引」页同源真源；安装版不靠浏览器也能读。  
> **产品边界**：领养包 · 数据本地 · 自带模型钥匙。不做代管云脑。

---

她住在你这台电脑里。记忆和对话留在本地，不靠我们替你托管大脑。

## 三步开始

1. **先看见她**  
   打开应用，进入「相处」——她已经在那儿。不必先找 `.env`。

2. **给她一把钥匙**  
   点左下角**齿轮**打开设置，粘贴你的 API 密钥（可选填接口地址、模型名）。  
   保存后可点**试一下**，确认通了再回去。

3. **回去说话**  
   返回相处页，跟她说点什么。  
   若还没钥匙就发话，会提示你先去设置；连不上模型时也会用人话说明。

## 记住

- 不做免费代管云脑；钥匙由你自己申请、自己保管。  
- 随时可再点左下角齿轮改配置。  
- 更细的开发/换机说明见仓库其他 how-to；日常养她，这三步够用。
