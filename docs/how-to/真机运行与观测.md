## 一、启动

```bash
qi                 # 终端聊天模式（调试后门）
qi-desktop         # 具身窗口（推荐，后端+前端）
```

启动后栖进入心跳循环，按 `settings` 的 `rhythm` 在 awake/ambient/solitary/dreaming 间切换。

## 二、观测内在活动（broadcast_traces）

阶段二起，每拍心跳落一条广播痕迹到 `broadcast_traces` 表（SQLite，`data/qi.db`）。这是 **C4 溯源测试** 与 **C3 无人测试** 的数据源。

### 关键字段

| 字段 | 含义 |
|------|------|
| `beat` / `timestamp` | 拍序 / 时间 |
| `winner_kind` | 本拍胜出的竞争者类型（respond / close_loop / report / proactive / action） |
| `winner_salience` | 胜出显著性评分 |
| `candidates_json` | 本拍全部竞争者（kind + salience + reason） |
| `motive_json` | 三股驱动力当前值（内稳态偏差 / 好奇 / 表达欲积压） |
| `outcome` | 行为结果 |

### 怎么看

```python
# 伪代码：最近 N 拍的"为什么是它"
from qi.storage.database import list_recent_traces
for t in list_recent_traces(50):
    print(t.beat, t.winner_kind, t.winner_salience, t.candidates_json)
```

真机挂几十拍后，能回答："这拍为什么是它"、"它这段时间在做什么"（C3 无人测试的可连贯故事）。

## 三、独处与节律

- 不聊天时栖仍在跑（solitary / dreaming）。`dreaming_interval` 控制做梦频率；`solitary_interval` 控制独处节拍。
- 想看"她独处时在想什么"：查 `consciousness_stream` / `dreams` / `creations` 表，或 `broadcast_traces` 的 proactive/action 胜出拍。

## 四、断网 / 拔管观测

- 断远程 LLM 后，栖应退化为模板措辞但内在活动不中断（C1 拔管测试）。
- 验证：断网跑数十拍，`broadcast_traces` 仍持续产出非平凡 winner（情绪/记忆/关系/门控推进），fake-provider 契约测试见 `specs/tasks/`。
